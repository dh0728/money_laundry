# ATM-GAD: Adaptive Temporal Motif Graph Anomaly Detection for Financial Transaction Networks

[원문 링크](https://arxiv.org/html/2508.20829v1)


## 추상적인
수십억 달러 규모의 자금을 보호하기 위해서는 금융 사기 탐지가 필수적이지만, 현대 금융 시스템의 복잡하게 얽힌 주체들과 빠르게 변화하는 거래 행태는 기존의 머신러닝 모델을 무력화시키는 경우가 많다. 최근 그래프 기반 탐지기들은 거래를 네트워크로 표현함으로써 어느 정도 진전을 이루었지만, 여전히 시간에 기반한 두 가지 사기 특징을 간과하고 있다.
1. 시간적 모티프(의심스러운 자금 흐름이 전개되는 과정을 보여주는 반복적이고 특징적인 부분 그래프)와 
2. 계좌별 이상 활동 기간(사기가 각 주체에 고유한 짧은 기간 동안만 나타나는 현상)이다. 

이러한 두 가지 신호를 모두 활용하기 위해, 본 논문에서는 금융 이상 탐지를 위해 시간적 모티프를 활용하는 적응형 그래프 신경망인 **ATM-GAD**를 제안한다. 시간적 모티프 추출기는 각 계좌의 거래 내역을 가장 유용한 모티프로 압축하여 위상과 시간적 패턴을 모두 보존한다. 추출된 모티프는 이중 어텐션 블록을 통해 분석된다. IntraA는 단일 모티프 내의 상호 작용을 분석하고, InterA는 여러 모티프에 걸쳐 증거를 통합하여 다단계 사기 수법을 밝혀낸다. 이와 동시에, 미분 가능한 적응형 시간 창 학습기(Adaptive Time-Window Learner)는 각 노드에 맞게 관찰 창을 조정하여 모델이 가장 의미 있는 시간 구간에 정확하게 집중할 수 있도록 한다. 4개의 실제 데이터셋에 대한 실험 결과, ATM-GAD는 기존 방법들이 놓쳤던 사기 패턴을 찾아내며, 7개의 강력한 이상 탐지 기준 모델보다 일관되게 우수한 성능을 보였다.
