# 모델 학습 노트: 트리 모델 vs GNN, 클래스 불균형 대응 (지원)

AML 탐지 모델 A(거래 이진분류) 선택 근거가 되는 학습 내용 정리

## 1. 결정 트리

- if-else 질문을 계층적으로 쌓은 구조. 예: `in_degree_3d > 5?` → `pass_through > 0.9?` → 세탁 확률.
- 분기는 사람이 아니라 데이터가 결정: 매 분기마다 **모든 피처의 모든 임계값 후보를 경쟁**시켜
  클래스 분리가 가장 좋아지는 질문을 선택.
- 따라서:
  - 판별력 없는 피처는 트리 전체에서 **한 번도 선택되지 않을 수 있음** (예: 엔티티 유형).
  - 같은 피처가 한 경로에서 다른 임계값으로 **여러 번** 쓰일 수 있음 → 깊이는 피처 개수와
    무관하며, `max_depth`(XGBoost) / `num_leaves`(LightGBM) 같은 규제와 데이터가 제한.
- 피처 중요도 = 각 피처가 분기 경쟁에서 이긴 횟수·개선량 집계.

## 2. 그래디언트 부스팅 (XGBoost / LightGBM)

- 트리 하나는 약함 → 수백 개를 **순차적으로** 쌓되, 각 트리는 이전까지의 앙상블이
  틀린 부분(잔차·gradient)을 전담 학습. 최종 예측 = 트리들의 합.
- XGBoost와 LightGBM은 이 알고리즘의 고속 구현체. LightGBM은 잎 우선(leaf-wise) 성장 +
  히스토그램 분기로 대용량에서 더 빠름.
- 강점: 피처 단위 제각각이어도 됨(정규화 불필요), 임계값성 패턴에 강함, 학습 빠름,
  피처 중요도·SHAP으로 해석 가능.
- **한계: 입력이 고정 길이 피처 벡터여야 함.** 그래프 구조를 직접 볼 수 없어
  이웃 맥락을 사람이 컬럼으로 요약해줘야 함 (= 우리 피처 엔지니어링의 역할).

## 3. GNN (Graph Neural Network)

- 데이터를 표가 아니라 그래프(노드=계좌, 간선=거래+속성) 그대로 입력.
- **메시지 패싱**: 각 노드가 이웃들의 벡터를 받아 자기 벡터와 섞어 갱신.
  k층 반복 → 각 계좌의 임베딩이 k-hop 이웃 구조를 요약. 간선(거래) 분류는
  양끝 노드 임베딩 + 간선 속성으로 판정.
- 즉 사람이 만들던 "이웃 요약"을 모델이 스스로 학습.
- **주의: 표준 GNN은 방향과 시간 순서를 잘 못 봄.** CYCLE(시간순 방향 순환) 같은 AML
  패턴은 기본 메시지 패싱으로 감지 불가 → AML용 개조(ego-ID, 역방향 메시지 패싱,
  port numbering; Egressy et al. AAAI 2024)가 있어야 성능이 나옴.

## 4. 비교와 우리의 선택

| | GBT (XGBoost/LightGBM) | GNN |
|---|---|---|
| 입력 | 피처 벡터 (표) | 그래프 자체 |
| 그래프 정보 | 사람이 피처로 주입 | 메시지 패싱으로 자동 추출 |
| 학습 비용 | 수백만 행도 분 단위 | GPU + 이웃 샘플링 등 무거움 |
| 해석 | 중요도·SHAP 직접 확인 | 임베딩에 숨어 어려움 |
| AMLworld 성능(문헌) | 그래프 피처 + GBT F1 ~60% | 비슷 (~60%, 개조 GNN 다소 위) |

- 본질은 동일: "거래 주변의 시공간 이웃 구조를 숫자로 요약". 요약을 사람이 하느냐(GBT)
  모델이 하느냐(GNN)의 차이. 요약이 좋으면 그릇은 덜 중요 (IBM 벤치마크에서 둘 동급).
- **선택: GBT + 수동 그래프 피처 먼저.** 피처를 직접 설계하며 어떤 구조 신호가 판별력
  있는지 이해 확보 → GNN은 GBT 베이스라인 대비 실측 비교하는 2차 실험.

## 5. 극단적 클래스 불균형 (양성 0.1%) 대응

핵심 인식: 0.1%라는 비율보다 **절대 개수와 겹침**이 문제. 양성 5,177건(Small)~22만 건
(Large)은 학습에 부족하지 않음. 불균형이 치명적인 건 정상과 겹쳐 보일 때
→ **제1 대응은 리샘플링이 아니라 분리력 있는 피처** (그래프·시간창·pass-through).

채택:
1. `scale_pos_weight` (클래스 가중치) — 기본 적용, 배율은 val에서 조정
2. 음성 언더샘플링 — 양성 전량 + 음성 표본(양성의 50~100배). 실험 회전 수십 배 개선.
   확률 눈금은 왜곡되나 우리는 순위(Recall@k) 평가라 무방. 임계값 캘리브레이션만
   원분포 val에서 수행
3. hard negative mining — 1차 모델이 헷갈린 음성 위주로 재학습 (1차 결과 보고 도입 결정)

제외:
- SMOTE류 합성 오버샘플링 — 피처 공간 보간으로 만든 가짜 양성은 대응하는 실제 그래프
  구조가 없어 무의미. AML 문헌에서도 미사용
- 단순 양성 복제 — 가중치와 수학적으로 동일, 메모리 낭비

평가 시 필수 진단:
- **패턴 유형별 recall 분해.** 양성은 8패턴+배경 세탁의 혼합이라 난이도가 제각각
  (FAN-IN은 in-degree로 쉽게, CYCLE은 순환 피처 없이는 불가). 전체 recall만 보면
  쉬운 유형만 잡아도 좋아 보이는 착시 발생. 정답 블록이 있어 유형별 분해가 가능하며,
  이는 피처 보강의 나침반 역할 (예: CYCLE recall 낮음 → 순환 피처 보강).

## 6. 트리 모델 사용 시 우리 데이터 주의점

- 양성이 극소수라 노이즈 피처가 우연히 소수 양성을 분리하는 "가짜 승리" 분기 발생 가능
  → 근거 있는 피처 후보만 투입, 중요도는 val 성능 변화로 교차 검증.
- 피처는 반드시 인과적(예측 시점 이전 정보만). 전 기간 집계는 미래 누수 + 버스트 희석으로
  이중 실격 (계좌 프로파일 분석에서 실증: 단변량 정밀도 2~10%).
