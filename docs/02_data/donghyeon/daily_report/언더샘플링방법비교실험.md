
# 언더샘플링방법비교 실험

## 1. 분석목표
각 언더샘플링 방법이
1. 정상거래를 얼마나 줄였는가
2. 적용 후 최종 불균형비가 어떻게 변했는가
3. 처리시간이 얼마나 걸렸는가
4. 원래 정상거래 분포를 얼마나 보존했는가

## 실험 제약조건
- 데이터 : HI-Small
- 목표 비율양성 : 음성 1:10
- 실행 방식 : full (필요할 때만 pilot로 계산 가능성 확인)
- 클래스 가중치단독 적용 모델은 class_weight=None
- 임계값검증 : 데이터의 F1 최적 임계값
- 랜덤 시드우선 42 : 선정된 방법만 3개 시드 재실험
- 언더샘플링은 train 정상거래에만 적용한다.
- 양성 거래는 제거하거나 변경하지 않는다. 양성 거래 보존은 평가 지표가 아니라 필수 무결성 조건으로 확인한다.
- 검증·테스트 데이터는 언더샘플링하지 않고 원래 클래스 비율을 유지한다.
- 현재는 패턴이 등록되지 않은 자금 세탁 탐지이므로
  - 양성(target=1): Is Laundering == 1 AND Patterns.txt에 없는 거래
  - 음성(target=0): Is Laundering == 0인 정상거래
- Patterns.txt에 존재하면서 Is Laundering == 1인 거래는 이번 실험에서 제외한다.
- 중복 거래는 제거한다.
- Reinvestment는 초기 잔액 설정 성격이므로 481,056건 제외
- 학습 1~7일, 검증 8일, 테스트 9~10일 (축약 효과는 학습 데이터인 1-7일에 대해서만 측정)

## 피처 생성 시점
- 이력 피처는 샘플링 전에 원래 시간순 데이터로 계산해야 한다.
- 패턴 자금세탁 거래는 모델 학습 행에서는 제외하지만 피처 계산시에는 포함

```
중복 및 Reinvestment 제거
→ USD 변환
→ 전체 시간순으로 이력 피처 생성
→ target 생성
→ 시간 분할
→ train 정상거래에만 언더샘플링
```

### 최초 송금 계좌의 결측값 처리

현재 송금 계좌의 최초 송금에서는 이전 송금이 없으므로 아래 두 피처를 계산할 기준이 없다.

- `hours_since_sender_prev_log`: 직전 송금 시각이 없어 경과시간을 계산할 수 없음
- `amount_vs_sender_history_usd`: 과거 송금액 평균이 없어 현재 금액과 비교할 수 없음

따라서 `is_new_sender`를 추가해 과거 송금 이력이 없는 계좌를 표시하고, 두 피처의 결측값은 0으로 채운다.

```python
is_new_sender = (sender_prev_count == 0).astype("int8")
hours_since_sender_prev_log = hours_since_sender_prev_log.fillna(0)
amount_vs_sender_history_usd = amount_vs_sender_history_usd.fillna(0)
```

롤링 및 그래프 피처는 현재 거래를 제외한 `[현재 시각 - 24시간, 현재 시각)` 범위의 거래만 사용한다.

## 비교할 언더샘플링 방법

| 계열 | 방법 | 특징 |
|---|---|---|
| 무작위 | RUS | 정상거래 무작위 제거 |
| 경계 정리 | Tomek Links | 클래스 경계에 붙어 있는 정상거래 제거 |
| 이웃 정리 | ENN | 주변 라벨과 다른 정상거래 제거 |
| 반복 정리 | RENN | ENN을 반복 수행 |
| 이웃 정리 | NCR | 소수 클래스 주변의 방해되는 정상거래 제거 |
| 대표 표본 | CNN | 분류 경계를 유지하는 일부 정상거래 선택 |
| 결합 방식 | OSS | Tomek Links와 CNN 계열을 결합 |
| 거리 기반 | NearMiss 1·2·3 | 양성에 가까운 정상거래를 중심으로 선택 |
| 군집 기반 | ClusterCentroids | 정상거래를 군집 중심점으로 대체 |
| 군집 기반 | K-medoids | 군집 중심에 가까운 실제 거래 선택 |
| 제안 방식 | C0: CSSMC-KLD | 논문 방식대로 KLD가 가장 작은 군집별 표본 선택 |
| 변형 방식 | C1: CSSMC-KS-PSI | 동일한 후보 중 KS와 PSI 순위합이 가장 작은 표본 선택 |

### C0와 C1 비교 기준

C0와 C1은 동일한 정상거래 K-means 군집과 동일한 후보 subset을 사용한다. 두 방법의 차이는 최종 후보 선택 기준뿐이다.

```text
C0: 다변량 정규분포를 가정한 KLD가 가장 작은 후보 선택
C1: 피처별 평균 KS와 평균 PSI의 순위합이 가장 작은 후보 선택
```

- 군집 수: 30개
- 후보 subset 수: 10개
- 각 후보의 정상거래 수: 학습 양성 수 × 10
- C0 KLD 계산 시 공분산 역행렬의 안정성을 위해 작은 정규화 값을 더한다.
- C1은 KS와 PSI의 값 범위 차이로 한 지표가 지배하지 않도록 두 지표의 순위합을 사용한다.
- 논문에는 후보 subset 반복 횟수가 명확히 제시되지 않아 후보 10개는 본 실험의 구현 결정이다.
- C1은 논문 원본 CSSMC가 아니라 AML 데이터에 맞춰 추가한 변형 비교군이다.

## 분류 모델 및 실행 방식

- 언더샘플링 방법 비교에는 동일한 `LightGBM` 분류기를 사용한다.
- 각 언더샘플링 방법은 다른 방법과 결합하지 않고 단독으로 적용한다.
- 언더샘플링 효과와 클래스 가중치 효과가 섞이지 않도록 단독 적용 실험에서는 `class_weight=None`, `is_unbalance=False`, `scale_pos_weight=1.0`을 사용한다.
- 검증 데이터인 9월 8일에서 F1이 가장 높은 Threshold를 선택하고, 9월 9~10일 테스트 데이터에 적용한다.
- 검증·테스트 데이터는 언더샘플링하지 않는다.
- 실행시간보다 전체 데이터 결과를 우선하므로 `RUN_MODE="full"`을 기본값으로 사용한다.
- 최근접 이웃 기반 방법은 전체 데이터에서 메모리 부족이 발생할 수 있으므로 방법별로 독립 실행하고 결과를 즉시 저장한다. 필요할 때만 `RUN_MODE="pilot"`으로 계산 가능성을 먼저 확인한다.

```python
MODEL_NAME = "LightGBM"
RUN_MODE = "full"
TARGET_NEGATIVE_RATIO = 10
RANDOM_STATE = 42
```
