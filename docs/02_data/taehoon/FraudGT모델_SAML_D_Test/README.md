# SAML-D Test 보고서 공유 묶음

2026-11-06까지 완료된 Multi-FraudGT의 SAML-D 평가·원인 분석·결측 처리 실험을 공유하기 위한 **보고서 전용 자료**입니다.

## 먼저 열어볼 파일

- **[보고서.html](보고서.html)**: 브라우저에서 읽는 버전입니다. 목차와 그림을 포함하며, 이 HTML 파일만으로도 본문을 읽을 수 있습니다.
- **[보고서.md](보고서.md)**: Git에서 확인하고 수정하기 위한 Markdown 버전입니다.

보고서는 최초 평가 → 결측 영향 검증 → 대체 방식 3종 → 패턴별 결과 → 현재 결론과 후속 계획 순서로 정리했습니다. 사기 17종·정상 11종의 탐지/오탐 표와 기본 피처 34종의 전체 입력 비교도 포함합니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `reports/` | 단계별 상세 보고서와 피처 대응 설명 |
| `results/` | 전체 지표·HI 대조·패턴별 결과·입력 통계 CSV/JSON |
| `figures/` | 보고서에서 직접 사용하는 PNG 그림 |
| `metadata/` | 실험 조건·검증 기록·입력 파일 명세 |
| `MANIFEST.json` | 포함 파일의 경로·크기·원본 해시·묶음 내 해시 |
| `PACKAGE_CHECK.json` | 내부 링크·포함 파일·원본 결과 보존 검증 |

이 폴더 전체를 Git 저장소의 원하는 위치에 넣으면 상대 링크가 유지됩니다. Markdown만 따로 옮기면 그림·근거 자료 링크가 끊어지므로 폴더 구조를 함께 유지하세요.

## 포함 범위

최종 보고서가 참조하는 문서·그림·작은 결과표와 검증 근거만 포함했습니다. 원본 거래 데이터, 모델 가중치, 거래별 예측 배열, 학습 캐시, 배치별 결과, 실행 로그, 학습·추론 스크립트, 노트북은 포함하지 않았습니다. 따라서 이 묶음은 결과 검토용이며 모델을 다시 실행하는 패키지가 아닙니다.

상세 문서에 코드 표시로 언급된 `.npy`, `.npz`, 체크포인트·로그 등의 이름과 JSON의 원래 작업 경로는 원본 실행 환경의 기록입니다. 해당 파일은 이 묶음에 없지만, 문서에서 클릭할 수 있는 로컬 링크는 묶음 내부 파일로 연결됩니다. 실행 코드로 향하던 링크는 설명 문구로 바꿨습니다.

CSV·JSON·PNG는 원본 그대로 복사했고, 문서의 링크만 공유 폴더 구조에 맞춰 수정했습니다. `metadata/07_report_provenance/검증.json`은 원본 보고서를 생성했을 때의 검증 기록이므로 원래 파일명·해시를 유지합니다. 이 묶음 파일의 해시는 `MANIFEST.json`에서 확인하세요.
