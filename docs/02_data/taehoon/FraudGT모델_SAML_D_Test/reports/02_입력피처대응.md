# HI 학습 피처를 SAML-D에 대응한 방법

이 평가는 HI에서 선택한 Multi-FraudGT 가중치를 고정한 외부 평가이다. SAML-D 정답으로 피처나 임계값을 선택하지 않았다. 기존 SAML 전처리 캐시의 숫자값을 사용하며, 71개 캐시 열 전부를 모델에 넣는 것은 아니다.

기본 피처는 **34종 = 계좌 19종 + 거래 숫자 14종 + 결제방식 1종**이다. 결제방식은 `ACH, Bitcoin, Cash, Cheque, Credit Card, Reinvestment, Wire, Unknown`의 8차원 one-hot으로 표현한다. 구조 정보인 Ego와 Port를 별도로 추가하므로 실제 모델 입력은 **노드 20차원(19+Ego 1)**, **관계별 엣지 23차원(14+결제방식 8+Port 1)**이다. Multi는 정방향·역방향 두 관계를 사용한다. 양끝 계좌에 동일한 19종 스키마를 적용하며 이를 서로 다른 38종으로 세지 않는다. SAML에서 값이 없는 열도 입력 차원을 유지하기 위해 남겨 둔다.

| 입력 | 적용한 값 | 의미와 제한 |
|---|---|---|
| 거래 숫자 14개 | 캐시 열 `0,1,2,3,4,5,6,7,9,10,12,13,14,15` | HI와 동일한 선택 순서. 시간 이력·금액·통화 등의 기존 계산 규칙 유지 |
| 결제형태 | 캐시 열 17 → HI 7종 + Unknown one-hot | ACH, Cheque, Credit card, Cash Deposit/Withdrawal의 기존 대응 사용. Debit card/Cross-border는 Unknown |
| 계좌 행동 10개 | 마지막 활동일의 누적 노드 상태 | 거래 수·고유 상대계좌 수·금액 통계·통화 수·활동일 수 등. 전체 기간 말 그래프 기준 |
| 계좌 유형 6개 | 모두 숫자 0 | SAML에 HI 계좌 유형 정보가 없어 선택된 유형이 없는 형태로 입력. 해당 유형이 실제로 거짓이라는 검증 결과가 아님 |
| 소유 엔터티 통계 3개 | 모두 숫자 0 | SAML에 같은 정의의 소유관계 정보가 없음. 관측된 실제 0과 구분하는 별도 신규 mask를 추가하지 않음 |
| `same_known_country` | 숫자 0 | 두 계좌가 같은 알려진 소유국가라는 근거가 없음 |
| `both_countries_known` | 숫자 0 | 두 계좌의 소유국가를 모두 아는 상태가 아니라는 뜻. 이 기존 열은 국가 정보 가용성의 단서를 제공함 |
| Port | SAML 거래의 시간순 최초 상대계좌 순번 | 원본 포트 구현 재사용. HI 계좌 ID나 포트를 SAML 계좌에 그대로 복사하지 않음 |
| Ego | 현재 공유 배치의 query 양끝 계좌 = 1 | 기존 Multi 구현과 동일 |

**숫자 0은 null/NaN이 아니다.** 특히 `same_known_country=0` 한 열만 보면 다른 국가와 정보 부재를 구별할 수 없지만, 함께 입력하는 `both_countries_known=0`에서 국가 정보가 없다는 단서를 얻을 수 있다. 다만 전체 결측 피처를 일관되게 구분하는 새 mask를 추가하거나, 이번 결측 처리에 맞춰 재학습·보정하지는 않았다. 모델의 다른 구조나 입력 차원을 바꾸면 기존 가중치의 고정 평가가 아니게 된다.

지원하지 않는 결제통화 159,771건의 금액 z-score는 기존 전처리 규칙대로 0이다. 이때도 평균 수준 금액의 z-score 0과 구분하는 신규 mask가 없다. 결제형태 Unknown은 2,946,034건이다. SAML의 은행 위치를 HI의 계좌 소유국가로 임의 치환하지 않았다.

이 대응에 따른 도메인 차이와 결측 영향은 결과에 함께 존재한다. 이번 한 번의 외부 평가로 각 원인이 성능에 미친 영향을 따로 확정할 수는 없다. `protocol.json`의 missingness 설명에서 별도 표시가 없다는 표현은 새 공통 결측 mask를 추가하지 않았다는 뜻이며, 위 국가 가용성 열은 유지한다.
