# 결합 학습 방법과 해석

## 결합 순서

1. HI-Large에서 이미 학습한 GNN과 HGB의 가중치를 고정한다. 결합 실험에서 기반 모델을 다시 학습하지 않는다.
2. HGB의 3클래스 확률을 `[1,100,100]`으로 한 번 나누고 재정규화한 뒤 사기 두 클래스의 확률을 합쳐 logit으로 바꾼다.
3. 거래 ID로 정렬한 두 입력 `[HGB corrected logit, GNN raw logit]`에 StandardScaler를 적용한다.
4. `LogisticRegression(C=0.1, solver='lbfgs', max_iter=1000, tol=1e-7)`를 학습한다. 추가 class_weight, sample_weight, IPW, logit 보정을 사용하지 않는다.
5. Validation으로 보조 임계값을 고정하고 Test에 적용한다. 주 비교는 0.5다.

| 구간 | 날짜 | 거래 수 | 역할 |
|---|---|---:|---|
| fusion_fit | 2022-10-05~10-08 | 7,315,599 | 결합기 학습, 사기 9,637건 |
| Validation | 2022-10-09~10-13 | 8,551,015 | 지표 및 보조 임계값 선택 |
| Test | 2022-10-14~10-31 | 33,429,507 | 고정 조건 평가 |

HGB는 기존 `41종` 실험 묶음에 있는 모델이지만 **HGB 자체 입력은 22종/36열**이다. GNN에 41종을 모두 넣은 실험이라는 뜻이 아니다.

## 저장된 결합식

아래는 표준화를 풀어 쓴 식이다. 재실행 코드는 저장된 scaler와 표준화 계수를 사용해 반올림 오차를 줄인다.

```text
A3+HGB: sigmoid(-0.2408879742 + 0.8485208332*HGB_logit + 0.1479158804*A3_logit)
Multi+HGB: sigmoid(-0.4412511869 + 0.6739111692*HGB_logit + 0.3509453330*Multi_logit)
```

| 결합기 | 학습 시드 | 반복 횟수 | 로지스틱 fit 시간 | HI Validation 선택 확률 임계값 |
|---|---:|---:|---:|---:|
| A3+HGB | 20261107 | 24 | 8.44초 | 0.2633538290 |
| Multi+HGB | 20261108 | 22 | 7.36초 | 0.1949978440 |

위 시간은 기반 모델 점수 생성이 끝난 뒤 로지스틱 회귀 fit만의 시간이다. 전체 GNN 추론 시간과 구분한다.

## 결과 해석

0.5에서 Multi+HGB는 Multi 단독보다 F1 70.14%→70.88%, AP 66.88%→69.75%, FP 3,078→1,435로 개선됐지만 Recall은 57.78%→56.68%로 감소했다. A3+HGB는 A3 단독보다 F1 67.39%→70.44%, AP 65.61%→68.91%로 개선됐다.

보조 임계값은 각각의 HI Validation에서 선택한 값이므로 서로 다른 임계값이다. 같은 임계값 비교와 Validation별 선택값 비교를 분리해서 읽는다. Test 임계값 스윕은 탐색용 표이며 그 표에서 새 임계값을 골라 독립 Test 성능이라고 주장하지 않는다.

## 기반 모델 차이와 한계

- A3: 완료된 6에폭 모델, 별도 Monitor(09-26~10-04)에서 선택. 일별 마감 그래프.
- Multi-FraudGT: 284에폭까지 완료한 모델 중 HI Validation F1로 epoch280 선택. 기간 말 누적 그래프. 기반 모델 선택 Validation(09-26~10-13)이 결합 fit/비교 Validation과 겹친다.
- 두 시스템의 그래프와 학습·선택 절차가 다르므로 구조 하나의 인과 효과 비교가 아니다.
- 결합 지표는 `>= threshold` 판정이다. 원래 Multi의 `>0` 결과와 비교할 때 정확히 0인 logit이 없음을 원본 검증에서 확인했다.
