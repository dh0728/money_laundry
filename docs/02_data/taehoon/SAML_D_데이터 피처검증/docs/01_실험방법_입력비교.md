# 실험 방법과 입력 비교

## 질문과 모집단

HI-Large에서 성능이 높았던 Multi-FraudGT가 SAML-D로 옮겨졌을 때 왜 성능이 낮아지는지 조사했다. 학습 모델·입력 매핑 검증 → HI 동일 거래에 결측 주입 → 대체값 검증 → SAML-D 전체 평가 → 공통 입력만으로 재학습 순서다. SAML-D 라벨은 학습·에폭 선택·임계값 선택에 사용하지 않았다. 이미 결과를 반복 확인한 탐색 실험이며 완전히 새로운 외부 holdout이라고 주장하지 않는다.

| 항목 | HI-Large | SAML-D |
|---|---|---|
| 원본 Multi 학습 | 2022-08-01~09-25, 102,505,233건 | 학습 없음 |
| 기반 모델 Validation | 09-26~10-13, 모집단 34,491,749건 | 에폭 선택 없음 |
| 최종 평가 | 10-14~10-31, 33,429,507건, 사기 44,103건 | 2022-10-07~2023-08-23 전체 9,504,852건, 사기 9,873건 |
| 최종 readout | all_targets, 전체 거래 | all_targets, 전체 거래 |
| Multi 그래프 | 각 split 말 누적 그래프 | 전체 기간 누적 그래프 |
| 주 임계값 | 기존 고정 0.5 | 같은 고정 0.5 |
| 패턴 | HI 라벨 정의 유지, 무패턴 사기도 포함 | 사기 17종, 정상 11종 |

학습 에폭은 전체 1억 건을 매번 모두 통과하는 뜻이 아니다. 에폭당 256 seed batch를 사용한다. 중간 Validation도 256 batch의 표본/official readout이며 최종 전체 Test와 구분한다. 기간 말 그래프는 평가 시점 이후의 같은 기간 거래를 포함할 수 있으므로 실시간 인과적 탐지 실험이 아니다. SALT는 일별 그래프를 사용하므로 두 시스템 비교는 모델 구조만의 비교가 아니다.

## 34종과 23종의 의미

| 입력 묶음 | 기존 34종 | SAML 관측 가능 | 공통 23종 학습 |
|---|---:|---:|---:|
| 계좌 행동 피처 | 10 | 10 | 10 |
| 계좌 타입 | 6 | 0 | 0 |
| 소유주 연결 정보 | 3 | 0 | 0 |
| 거래 수치 피처 | 14 | 12 | 12 |
| 결제 방식 | 1 | 매핑 일부 불일치 | 1 |
| 합계 | 34 | 23 | 23 |

SAML에서 없는 것은 계좌 9종과 국가 관련 거래 2종, 합계 **11/34=32.35%**다. 이는 피처 종류 비율이고 전체 셀의 NaN 비율이나 결측 거래 비율이 아니다. 모델 입력에는 주로 0으로 채워져 있으므로 `isna()`만으로 관측 불가능성을 찾을 수 없다. 동시에 0은 실제 0회, one-hot 비해당, 조건 거짓을 나타낼 수도 있다. `same_known_country=0`은 두 나라가 다르거나 국가를 모르는 경우가 섞일 수 있으므로 `both_countries_known`과 함께 읽어야 한다.

[34종 포함·제외 목록](../results/common23/피처_포함제외.csv). 공통23의 실제 노드 열은 행동10+ego1=11, 거래 열은 수치12+결제one-hot8=20이며 각 방향 port1을 붙이면 edge encoder는21열이다. 피처 종류 수와 인코딩 후 열 수를 혼동하지 않는다.

## 결제 방식

두 데이터 모두 원본 7종이지만 이름과 의미가 같지 않다.

| 데이터 | 원본 범주 |
|---|---|
| HI-Large | ACH, Bitcoin, Cash, Cheque, Credit Card, Reinvestment, Wire |
| SAML-D | ACH, Cash Deposit, Cash Withdrawal, Cheque, Credit card, Cross-border, Debit card |

Cash Deposit/Withdrawal은 Cash, Credit card는 Credit Card로 맞췄다. Debit card/Cross-border는 기존 HI 어휘에 없으므로 Unknown으로 유지했다. 기존 학습 모델에는 HI 7종+Unknown=8열 one-hot을 이미 사용한다. 원본 범주 개수가 같다는 이유로 열 순서대로 대응시키지 않는다. SAML Unknown은 2,946,034건(30.995%)이며, 위 32.35% 피처 종류 결측과 서로 다른 수치다. 공통23 실험에서도 이 인코딩은 바꾸지 않았다.
