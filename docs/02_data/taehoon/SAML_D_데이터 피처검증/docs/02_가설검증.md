# 가설에서 검증까지

## H1. SAML에 없는 입력을 0으로 채우는 것이 성능 하락에 영향을 준다

원래 34종 모델 가중치를 고정하고 **동일한 HI Test 표본 262,144건(사기 332건)**에 피처별 결측을 주입했다. 거래 ID, 그래프, 샘플링 조건을 맞춘 paired 비교다. 이 표본 수치는 전체 HI Test 점수와 구분한다.

| condition | AP | precision | recall | F1 | FP |
| --- | --- | --- | --- | --- | --- |
| baseline | 69.15% | 90.50% | 60.24% | 72.33% | 21 |
| node_type_zero | 69.34% | 88.55% | 60.54% | 71.91% | 26 |
| node_owner_zero | 62.58% | 10.22% | 73.49% | 17.95% | 2143 |
| country_zero | 68.93% | 90.95% | 60.54% | 72.69% | 20 |
| missing11 | 61.34% | 7.08% | 78.31% | 12.98% | 3413 |
| unknown31 | 68.31% | 91.24% | 59.64% | 72.13% | 19 |
| missing11_unknown31 | 56.80% | 6.97% | 74.10% | 12.75% | 3281 |

소유주3종을 0으로 만들었을 때 FP 21→2,143, F1 72.33%→17.95%로 크게 나빠졌다. 없는11종 전체를0으로 만들면 AP69.15%→61.34%, 여기에 결제Unknown31%를 더하면56.80%다. **결측 입력에 민감하다는 근거는 있다.** 하지만 SAML의 AP2.04%까지의 하락을 HI 결측 주입만으로 재현하지는 못했다. AP 차이를 빼서 “결측이 하락의 몇%를 설명한다”고 계산할 수 없다.

[전체 paired 지표와 CI](../results/20261106/결측_분포진단_20261106/control_metrics.csv). CI는 이 표본의 불확실성이며 하나의 데이터셋·모델 조건을 넘어서는 인과 증명이 아니다.

## H2. HI 학습 분포로 소유주3종을 대체하면 외부 성능을 회복한다

기존 가중치는 그대로 두고 소유주3종만 바꿨다. 타입6종과 국가2종은 계속0이다. 대체값은 HI Train에서만 추정하고 결측을 주입한 HI Validation 표본 262,144건(사기340건)에서 먼저 비교했다.

| 대체법 | 내용 | 결측 주입 HI Val AP | 전체 SAML AP |
|---|---|---:|---:|
| zero | 기존0 | 58.55% | 2.0363% |
| train_median | HI Train 중앙값 | 68.21% | 0.1610% |
| degree_median | 연결도 조건부 중앙값 | 68.05% | 0.1715% |
| behavior_donor | 관측 행동이 비슷한 HI donor 값 | 67.46% | 0.2321% |

HI Validation에서 회복돼도 SAML에서는 세 방법 모두 AP와 F1이 낮아졌다. HI의 소유주-행동 관계를 SAML에 옮기는 대체는 이 조건에서 지지되지 않는다. “중앙값 대체 실패=결측은 무관”도 아니다. 관측되지 않은 속성의 실제값을 이 실험에서 알 수 없기 때문이다.

[대체 검증 표](../results/20261106/대체값_추가실험_20261106/validation_metrics.csv) · [전체 SAML 표](../results/20261106/대체값_추가실험_20261106/saml_metrics.csv)

## H3. GNN과 HGB의 보완성이 외부에서도 유지된다

HI에서 학습된 기반 모델과 결합기를 모두 고정해 SAML 9,504,852건에 적용했다. HGB 3클래스 보정과 StandardScaler+로지스틱 결합식은 HI 실험 그대로다. 주 임계값0.5와 HI Validation에서 미리 선택한 보조 임계값을 분리한다. SAML에서 새 임계값을 최적화하지 않았다.

HI Test에서는 Multi+HGB AP69.75%로 향상됐지만 SAML에서는2.24%로 HGB단독2.28%보다 낮았다. A3+HGB는1.04%다. **HI에서의 결합 이득이 외부 성능 회복으로 이어진다는 가설은 지지되지 않았다.** [원본 전체 성능 및 보조 임계값](../results/fusion_generalization/전체성능.csv).

## H4. 관측할 수 있는 23종으로 처음부터 학습하면 더 일반화된다

11월9일 완료. 기존 모델 추론 시11종을 지운 것이 아니라, HI 학습과 SAML 추론 양쪽에서 동일한11종을 제외하고 새로 학습했다.

| 고정 항목 | 조건 |
|---|---|
| 시드/초기화 | seed42 fresh 초기화 후 입력 열을 물리적으로 축소; 공통/후단 초기 가중치와 RNG 보존; 학습 가중치 warm start 없음 |
| 학습량 | 기존과 같은284에폭, 에폭당256 batch |
| LR | AdamW 0.001, warmup5, **500에폭 cosine horizon 유지** |
| 손실/업데이트 | pos_weight6, weight_decay1e-5, clip1, seed batch2048, accumulation8 |
| 그래프/샘플링 | 기존CPU PyG shared2048, fanout[50,50], 정·역방향, 비복원 균일 샘플링 |
| 속도 최적화 | 입력 피처 GPU조회만 사용; 그래프 샘플링 조건은 동일 |
| 선택 | HI Validation official readout F1, epoch1/4/8/.../284 중 strict improvement, epoch280 선택 |
| 최종 평가 | 기존과 동일한 전체 거래 순서·all_targets, HI33,429,507건/SAML9,504,852건 |

| scope | model | AP | precision | recall | F1 | FP |
| --- | --- | --- | --- | --- | --- | --- |
| hi_test | original_34 | 66.88% | 89.22% | 57.78% | 70.14% | 3078 |
| hi_test | common_23 | 66.17% | 88.87% | 57.46% | 69.80% | 3174 |
| saml | original_34 | 2.04% | 0.44% | 45.69% | 0.87% | 1018255 |
| saml | common_23 | 1.21% | 0.53% | 31.62% | 1.05% | 580586 |

SAML에서 FP는1,018,255→580,586으로 줄고 고정 임계값 F1은0.87%→1.05%로 올랐다. 그러나 AP2.04%→1.21%, Recall45.69%→31.62%로 낮아졌다. **오탐 감소는 지지되지만 순위 성능 회복은 지지되지 않았다.**

단일 seed, 입력 차원/파라미터 수 감소, 이미 관찰한 Test라는 한계가 있다. 결제 범주 불일치·패턴·행동·그래프 차이는 남아 있다. 결측만의 인과 효과를 완전히 분리하거나 “결측 때문이 아니다”라고 단정하지 않는다. 상세 조건은 [plan](../results/common23/plan.json), 선택은 [frozen_selection](../results/common23/frozen_selection.json), [에폭 기록](../results/common23/training/epoch_metrics.csv)을 본다.
