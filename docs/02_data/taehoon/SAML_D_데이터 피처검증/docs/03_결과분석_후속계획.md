# 결과 분석과 후속 계획

## 확인된 사실

1. 기존 34종 모델은 HI 전체 Test AP66.88%이지만 SAML 전체 AP2.04%다. 이는 SAML에서 0.5 임계값만 부적절한 문제가 아니라 점수 순위 성능도 크게 변한 상황이다.
2. HI 동일 거래에서 소유주 피처를 제거하면 오탐이 크게 늘었다. 결측 입력 의존성은 실제로 관찰된다.
3. HI 기반 중앙값·조건부 중앙값·donor 대체는 SAML에서 개선되지 않았다.
4. 공통23종 재학습으로 전체 FP는 줄었지만 사기 탐지도 줄고 AP도 낮아졌다. 고정 임계값 F1의 소폭 개선만으로 일반화 회복이라고 판단할 수 없다.
5. 이번 SAML 표에서는 HGB단독 AP2.28%, F1 1.57%가 가장 높다. HI에서 성능이 좋았던 GNN+HGB가 SAML에서도 가장 좋지는 않았다.

SAML 사기 비율은 약0.104%다. 낮은 사기 비율에서 수십만 오탐이 발생해 Precision이1% 미만으로 내려간다. AP·Recall·FP/FPR·패턴별 탐지를 함께 봐야 한다. AP는 sklearn average_precision_score이고 사다리꼴 PR-AUC와 동일한 정의로 섞지 않는다.

## 공통23종 패턴별 변화

| 패턴 | 거래 수 | 기존34종 | 공통23종 | 의미 |
|---|---:|---:|---:|---|
| Cash_Withdrawal(사기) | 1,334 | TP0 | TP0 | 탐지 실패 유지 |
| Smurfing(사기) | 932 | TP0 | TP0 | 탐지 실패 유지 |
| Structuring(사기) | 1,870 | TP1,384, Recall74.01% | TP1,388, Recall74.22% | 거의 유지 |
| Deposit-Send(사기) | 945 | TP333, Recall35.24% | TP171, Recall18.10% | 악화 |
| Normal_Group(정상) | 528,351 | FP403,879, FPR76.44% | FP517,664, FPR97.98% | 전체 FP 감소와 반대로 악화 |

전체 FP는437,669건(약43.0%) 줄었지만 정상 패턴마다 효과가 다르다. 정상 패턴의 탐지율은 사기 Recall이 아니라 오탐률이다. 패턴 하나의 positive만 놓고 계산한 AP를 전체 AP와 비교하지 않는다.

[34/23종 28개 패턴 전체표](../results/common23/evaluation/saml/pattern_metrics.csv) · [결합모델 패턴표](../results/fusion_generalization/SAML_패턴별_탐지.csv). 패턴의 의미·관측 방식이 두 데이터에서 완전히 같은지는 아직 검증되지 않았다.

## 결론의 범위

“결측 처리 하나를 고치면 해결된다”는 설명은 충분하지 않다. 관측 불가능 피처 의존성 외에도 범주 의미, 정상/사기 패턴 구성, 관측 기간, 계좌 행동과 그래프 구조의 차이가 함께 존재한다. 현재 증거로 각 요인의 기여율을 정량 분해할 수 없으며, 실제 운영 데이터의 성능도 보장하지 않는다.

## 아직 수행하지 않은 후속 계획

| 우선순위 | 검증할 내용 | 제안 설계 | 판단 지표 |
|---|---|---|---|
| 1 | 결제 범주 불일치 | 학습 시 공통 의미 범주로 새로 정의하고 HI/SAML 동일 인코딩; 기존23종 대비 단일 변경 | AP, 고정 임계값 Recall/FP, Unknown 구간별 |
| 2 | 소수 패턴 실패와 정상군 과탐 | Cash_Withdrawal/Smurfing/Normal_Group의 금액·시간·차수·반복 구조를 표본과 전체 집계로 대조 | 패턴 Recall/FPR, 전체 경보량 |
| 3 | 그래프 관측 차이 | 같은 피처/seed에서 기간 말 누적과 과거 정보만의 시간 인과 그래프 비교 | 전체/패턴 AP, 계산량 |
| 4 | 재학습 변동성 | 34종/23종 동일 여러 seed, 고정 평가 순서로 반복 | 차이 분포와 CI |
| 5 | 확률/임계값 보정 | 새로 확보한 SAML 개발 구간에서만 보정하고 별도 시간 Test를 끝까지 보존 | 경보 예산별 Recall, Precision, calibration |

위 항목은 예정이며 이번 결과에 포함되지 않는다. 현재 SAML 전체를 개발에 사용했다면 새 holdout 없이 그 전체를 독립 Test라고 다시 부르지 않는다. HGB 결합기만 다시 조정해 결측 원인을 해결했다고 해석하지 않는다.
