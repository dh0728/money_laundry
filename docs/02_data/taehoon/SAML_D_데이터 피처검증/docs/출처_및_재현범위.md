# 출처와 재현 범위

이 묶음은 사용자의 기존 실험 코드와 완료된 결과를 정리한 연구 자료다. 외부 저장소로 업로드하거나 Git commit/push를 수행하지 않았다.

- `reference_source/`는 당시 실행한 코드의 보존본이다. 원본 워크스페이스 이름과 `/workspace/...` 경로, 데이터/캐시/체크포인트 의존성을 유지한다. 이 디렉터리만으로 원본부터의 전체 학습이 바로 되는 독립 배포 프로그램은 아니다.
- `notebooks/`와 `src/`는 패키지 안의 상대 경로를 사용하는 결과 검토 및 점수 수준 실행 코드다. 기본 실행에는 원본 데이터·GPU·체크포인트가 필요 없다.
- 외부 입력 없이 표시되는 성능표는 원래 전체 모집단에서 완료한 결과의 사본이다. 작은 예제나 테스트를 전체 성능으로 표시하지 않는다.
- 재학습·추론은 실제 데이터, 피처/그래프 캐시, 기반 모델 가중치, 동일한 입력 명세가 필요하다. 이들은 ZIP에서 제외했다. 원본 경로와 해시는 JSON 및 `SOURCE_PROVENANCE.json`에서 확인한다.
- 원본 `plan.json`의 “SALT paused”와 체크포인트 해시는 해당 실험 당시 상태다. SALT는 그 후 재개됐으므로 현재 실행 상태로 해석하지 않는다. 보존본을 재실행하려면 별도 실험 디렉터리와 새 조건 기록을 사용하며, 과거 고정 결과를 덮어쓰지 않는다.
- FraudGT 수식의 출처 커밋은 원본 프로토콜의 `f88db9dc003a6f521a90631c4741541686043119`다. 원본 코드의 저작권·출처 표시는 유지했다. 이 묶음은 외부 코드·데이터에 새로운 사용권을 부여하지 않는다.

Python/GPU 의존성은 `requirements.txt`, `requirements-gpu.txt`를 참고한다. CUDA 확장 모듈은 실행 머신의 PyTorch/CUDA ABI와 맞아야 한다.
