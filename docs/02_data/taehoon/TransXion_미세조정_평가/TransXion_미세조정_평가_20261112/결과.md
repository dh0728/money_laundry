## 학습 방법

- GNN: Multi-FraudGT 280에폭 가중치에서 시작해 전체 파라미터를 900스텝 미세조정했다(배치 2048, AdamW, 학습률 0.0003, 양성 가중치 6.0). 검증 AP가 가장 높은 900스텝 체크포인트를 골랐다.
- GNN 검증 AP 추이: 0스텝 0.22%, 150스텝 10.91%, 300스텝 15.60%, 450스텝 17.85%, 600스텝 19.28%, 750스텝 19.93%, 900스텝 20.11%.
- HGB: 트리 모델은 가중치 미세조정이 안 되므로 같은 36열과 같은 하이퍼파라미터로 1~8월에 다시 학습했다. 이진 라벨만 있어 이진 분류다.
- 결합: HGB·GNN 점수 두 개의 로지스틱 회귀를 9~10월 검증에서 다시 맞췄다.
- 그래프와 계좌 피처는 각 구간 종료일까지만 누적했다(학습 8/31, 검증 10/31, Test 12/31). HGB 피처는 거래일 종료 기준이다.
- 결제방식은 Card→Credit Card, Transfer→Wire, Mobile→Unknown으로 넣어 네 범주를 구분했다. HI 고정 GNN도 같은 입력으로 채점했다.

## 한계

- 시드와 설정은 하나씩이며 하이퍼파라미터 탐색은 하지 않았다.
- 거래 발생 시점까지만 쓰는 실시간 평가가 아니라 구간 종료일 그래프를 쓴 사후 평가다.
- 체크포인트 선택과 결합기 학습에 같은 검증 구간을 썼다.
- TransXion 논문의 공식 분할·성능과 맞춘 것이 아니다.
