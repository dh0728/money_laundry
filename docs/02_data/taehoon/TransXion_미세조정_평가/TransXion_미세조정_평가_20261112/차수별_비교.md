# 수신 계좌 차수별 비교: HI-Large vs TransXion

HI-Large에서 학습·평가한 모델과, TransXion Test(2025-11-01~12-31)에서의 HI 고정 모델·재학습 모델을 수신 계좌 차수 구간별로 나란히 놓았다. 저장된 점수의 재집계이며 새 학습·추론은 없다.

## 집계 기준

- 차수: 수신 계좌가 받은 거래 수(반복 포함), 각 데이터의 전체 기간 누적 그래프 기준. 구간은 기존 HI 차수 보고서와 같다.
- HI-Large: 전체 Test 33,429,507건, HI 학습 280에폭 GNN과 결합 모델의 기존 집계. HGB 단독과 구간별 AUC는 그 집계에 없다.
- 임계값: HI-Large와 'HI 고정'은 HI 검증에서 정한 값, '재학습'은 이 데이터 검증 구간에서 F1이 최대인 값이다.

## 요약

- HI 고정 모델은 모든 구간에서 Recall 0~21%, Precision 9% 이하다. GNN과 결합 모델의 구간 내 AUC는 대부분 0.5 아래이고 차수가 클수록 낮다.
- 재학습 결합 모델은 차수 5–99에서 Recall 77~87%, 100 이상에서 40.4%다. 100 이상 구간에서 재학습 GNN은 세탁 240건 중 1건, HGB는 113건을 잡는다.
- 50–99 구간은 세탁 비율이 5.12%로 다른 구간보다 훨씬 높다. 1–4 구간은 세탁이 11건뿐이라 수치가 불안정하다.
- HI-Large는 Precision이 구간과 무관하게 85~94%다. Recall의 구간 차이(46~81%)는 무패턴 세탁 비중 차이에서 나오며, 패턴이 있는 세탁은 모든 구간에서 95% 이상 탐지된다.

## 한계

- 두 데이터의 모집단·세탁 정의·차수 분포가 달라 같은 구간이라도 같은 종류의 계좌가 아니다.
- 차수는 전체 기간 누적값이라 거래 시점 이후의 거래도 포함한다.
- 임계값이 데이터마다 달라 운영점이 다르다. 시드는 하나다.
