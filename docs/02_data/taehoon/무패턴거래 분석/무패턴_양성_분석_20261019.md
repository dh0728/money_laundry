# 무패턴 양성 거래 분석 정리

작성일: 2026-10-19  
대상: 이번에 진행한 무패턴 양성의 시각화·연결성·fan-out·정상 거래 비교·수신 후 흐름 분석

## 먼저 전달할 핵심

> 무패턴 양성은 패턴이 없는 거래가 아니라, 기존 패턴 블록에 매핑되지 않은 양성 거래입니다. 연결된 거래를 확인하니 fan-out 형태가 많았고, 그 대부분이 15개 송신 계좌에 집중되어 있었습니다. 기존 패턴 fan-out과는 거래 속도·결제 방식 등이 크게 달랐지만, 같은 계좌의 정상 거래와 비교하면 그 차이가 대부분 사라졌습니다. 수신 후 출금과 같은 소유주의 다른 계좌까지 살펴봐도, 이번에 확인한 피처와 진단 모델로는 정상·양성을 유용하게 구분하기 어려웠습니다.

## 1. 분석의 출발점과 공통 정의

질문은 **“이진 모델에서 탐지하기 어려운 무패턴 양성에는 어떤 특징이 있는가?”**였습니다. 바로 피처를 추가하기 전에 거래를 직접 보고, 연결 구조와 정상 거래와의 차이를 확인했습니다.

| 용어 | 이번 분석에서의 의미 |
|---|---|
| 양성 | 원본 정답 라벨이 양성인 거래. 모델이 양성으로 예측했다는 뜻과 다름 |
| 무패턴 양성 | 양성이지만 기존 패턴 블록에 매핑되지 않은 거래 |
| 계좌 | 그래프의 개별 노드. `node_id`로 구분 |
| 엔티티 / 소유주 | 계좌를 소유한 개인·법인 등의 주체. `entity_id`로 구분 |
| 패턴 블록 | 기존 패턴 자료에서 하나의 패턴으로 지정한 거래 묶음 |
| fan-out 형태 | 한 송신 계좌에서 서로 다른 여러 수신 계좌로 보내는 형태 |
| fan-in 형태 | 서로 다른 여러 송신 계좌에서 한 수신 계좌로 모이는 형태 |

기본 분석 대상은 **2022-08-01~2022-10-31의 무패턴 양성 82,260건**입니다. 정확히 중복된 거래와 구조 부적합 패턴 거래를 제외한 기존 정제 기준을 유지했습니다.

| 구간 | 무패턴 양성 |
|---|---:|
| Train | 46,617건 |
| Val | 17,436건 |
| Test | 18,207건 |
| 전체 | 82,260건 |

한 엔티티는 여러 계좌를 가질 수 있습니다. 따라서 **같은 계좌인지**, **같은 소유주인지**, **같은 은행인지**는 서로 다른 조건입니다.

## 2. 무패턴 양성은 모두 단건 거래인가?

### 확인한 이유

초기 시각화에서는 주변 양성이 거의 보이지 않아, 무패턴 양성이 대부분 단독 거래인지 확인할 필요가 있었습니다. 일부 화면에서는 표시 제한 때문에 실제 연결이 빠져 보이는 문제도 확인했습니다.

### 전수 확인 결과

| 연결 기준 | 해당 거래 | 무패턴 양성 전체 중 비율 |
|---|---:|---:|
| 전체 관찰 기간에 다른 무패턴 양성과 계좌를 공유 | 49,556건 | 60.24% |
| 전후 24시간에 다른 무패턴 양성과 계좌를 공유 | 25,356건 | 30.82% |
| 거래 간격 24시간 이내에 시간·방향이 이어지는 `A→B→C` 연결에 참여 | 1,048건 | 1.27% |

전부 단건 거래는 아니었습니다. 다만 **같은 계좌를 공유하는 연결**과 **시간·방향이 이어지는 송금 경로**는 다릅니다. `A→B→C`가 관측되어도 같은 돈이 이동했다는 뜻까지 보장하지는 않습니다.

시각화는 무패턴 양성 전부를 중심 거래로 선택할 수 있도록 확장했고, 주변 정상 거래를 함께 보는 기능도 추가했습니다. 현재 조회 창 안에서는 거래 수 제한 없이 확인할 수 있습니다.

## 3. 같은 소유주 안에서 보내는 거래가 많은가?

송신 계좌와 수신 계좌의 `entity_id`가 같은지 확인했습니다.

- 해당 거래는 **240건**, 전체 무패턴 양성의 **0.292%**였습니다.
- 모두 **같은 소유주의 서로 다른 계좌 간 거래**였습니다.
- 해당 소유주는 **31개 엔티티**였습니다.
- 같은 계좌로 보내는 거래는 0건이었고, 이 집계에서 소유주 정보 누락도 없었습니다.

따라서 동일 소유주 내부 이체가 무패턴 양성의 대부분을 설명하지는 않았습니다.

## 4. 시각적으로 보이는 별 모양은 fan-in인가, fan-out인가?

중심 계좌를 가운데 두고 주변 계좌를 원형으로 배치하면 두 형태가 비슷하게 보입니다. 화면 모양에 더해 실제 송금 방향을 집계했습니다.

각 거래의 **과거 24시간~해당 시각**을 확인했습니다. 중심 거래와 같은 분의 거래도 포함했습니다. 이 범위에서 다른 무패턴 양성과 연결된 거래는 **24,186건**입니다.

| 형태 | 조건 | 해당 거래 | 연결된 24,186건 중 비율 |
|---|---|---:|---:|
| Fan-out | 같은 송신 계좌가 서로 다른 수신 계좌 2개 이상으로 송금 | 23,025건 | 95.20% |
| Fan-in | 서로 다른 송신 계좌 2개 이상에서 같은 수신 계좌로 송금 | 818건 | 3.38% |

두 조건에 모두 해당하는 거래는 8건입니다. **패턴 블록 수가 아니라, 해당 형태에 참여하는 거래 수**입니다.

결과적으로 이 시간 범위에서 연결된 무패턴 양성은 fan-out 쪽이 많았습니다. Fan-out 23,025건은 무패턴 양성 전체 82,260건의 **27.99%**입니다.

전후 24시간을 보는 2절의 25,356건과, 과거 24시간 및 해당 시각만 보는 여기의 24,186건은 조회 범위가 달라 숫자가 다릅니다.

## 5. 기존 패턴 fan-out과 무패턴 양성 fan-out은 어떻게 다른가?

### 같은 시간 조건으로 비교

기존 패턴으로 지정된 fan-out 전체는 **10,185건**입니다. 여기에 무패턴과 동일한 “과거 24시간에 서로 다른 수신 계좌 2개 이상” 조건을 적용하면 **2,237건**이 남습니다.

| 비교 항목 | 패턴 fan-out · 동일 24시간 조건 | 무패턴 양성 fan-out · 24시간 |
|---|---:|---:|
| 거래 수 | 2,237건 | 23,025건 |
| 송신 계좌 수 | 843개 | 125개 |
| 24시간 수신 계좌 수 중앙값 | 2개 | 54개 |
| 직전 같은 집단 송금과의 간격 중앙값 | 11시간 25분 | 24분 |
| ACH 비중 | 100% | 0.47% |
| 상위 15개 송신 계좌가 차지하는 비중 | 5.81% | 99.52% |

여기서 거래 간격과 상대 수는 **각 집단의 양성 거래끼리** 계산했습니다. 정상 거래까지 합친 전체 이력은 아닙니다.

기존 fan-out 블록의 관측 기간 중앙값은 약 **25.6일**, 수신 계좌 수 중앙값은 **6개**였습니다. 여러 날에 걸친 패턴이므로 24시간만 보면 전체 패턴 거래 중 일부만 조건을 충족합니다. 관찰 종료일에서 잘린 블록도 있어 원본 블록 전체의 완료 기간과는 다릅니다.

### 큰 차이는 15개 송신 계좌가 만들고 있었다

무패턴 fan-out 23,025건 중 **22,914건, 99.52%**가 15개 송신 계좌에서 나왔습니다.

- 15개 계좌는 모두 데이터상 **은행 ID 70**에 속합니다.
- 은행 이름은 `National Bank of Indianapolis`입니다.
- 소유주 매핑상 **서로 다른 15개 엔티티**입니다. 같은 은행이라는 사실이 같은 소유주라는 뜻은 아닙니다.
- 관찰 범위에서 이 15개 계좌가 보낸 기존 패턴 fan-out 거래는 0건이었습니다.

15개 계좌를 제외하면 무패턴 fan-out은 **111건**이 남습니다. 이 중 **97.3%가 ACH**, 24시간 수신 계좌 수는 모두 2개여서 기존 패턴 fan-out과 훨씬 비슷했습니다.

**해석:** 무패턴 fan-out 전체를 하나의 성격으로 보기보다, 15개 계좌에 집중된 큰 집단과 나머지 작은 집단을 나눠 볼 필요가 있었습니다.

## 6. 그 15개 계좌의 정상 거래와는 구분되는가?

### 비교 대상을 다시 잡은 이유

양성끼리만 묶어 본 fan-out 특징이 실제 탐지에 도움이 되려면, 같은 계좌의 정상 거래와도 달라야 합니다.

15개 계좌는 **Train 기간의 무패턴 fan-out 상위 계좌**로 다시 선정했고, 앞서 확인한 목록과 같았습니다. 이후에는 해당 계좌의 모든 정상·양성 송금을 포함했습니다.

| 전체 기간 비교 대상 | 거래 수 |
|---|---:|
| 정상 | 16,199,387건 |
| 무패턴 양성 | 22,979건 |

양성이 22,914건에서 22,979건으로 늘어난 것은, 앞선 양성 fan-out 조건을 충족하지 않던 **65건도 이번에는 포함했기 때문**입니다. 정답 라벨을 사용한 fan-out 선별 조건을 실제 탐지 실험에 그대로 가져오지 않았습니다.

### 정상 거래와의 차이는 작았다

| 항목 | 정상 | 무패턴 양성 |
|---|---:|---:|
| USD 송금액 중앙값 | $967.54 | $933.77 |
| 수표 비중 | 47.84% | 51.05% |
| 카드 비중 | 30.37% | 32.29% |
| 현금 비중 | 19.65% | 15.02% |
| Bitcoin 비중 | 2.15% | 1.63% |

수표·카드는 양성에서 조금 많고 현금은 조금 적었지만, 같은 결제 방식의 정상 거래가 압도적으로 많았습니다. 금액도 크게 겹쳤습니다.

검증 기간의 과거 이력도 비슷했습니다. 아래는 정상·양성을 합친 전체 송신 이력으로 계산한 거래별 중앙값입니다.

| 과거 이력 | 정상 | 무패턴 양성 |
|---|---:|---:|
| 송신 계좌의 과거 24시간 거래 수 | 약 41,539건 | 약 42,628건 |
| 송신 계좌의 전날 서로 다른 수신 계좌 수 | 14,637개 | 14,637개 |
| 해당 송신→수신 계좌쌍의 이전 거래 수 | 121건 | 120건 |

**해석:** 정상 거래도 같은 계좌에서 많은 상대에게 반복 송금하고 있었습니다. 기존 패턴 fan-out과 다르다는 사실만으로 정상·양성을 구분할 수는 없었습니다.

시각·송수신 계좌·금액·통화·결제 방식이 완전히 같은데 라벨만 다른 거래쌍은 0건이었습니다. 다만 이것만으로 원본 라벨의 정확성이나 생성 원인을 입증한 것은 아닙니다.

## 7. 수신 후 재송금과 같은 소유주의 다른 계좌까지 보면 다른가?

### 확인 범위를 확장

| 확장 대상 | 규모 |
|---|---:|
| 수신 계좌 | 153,439개 |
| 수신 계좌의 소유주 | 139,975개 |
| 해당 소유주가 가진 전체 계좌 | 806,390개 |
| 전체 네트워크에서 확보한 관련 거래 | 91,465,142건 |

다른 송신자와 주고받는 거래도 포함했습니다. 정상과 모든 유형의 양성을 함께 사용했고, 양성 라벨을 피처로 쓰지 않았습니다.

아래 결과는 **Test 기간인 2022-10-14~10-31의 정상 3,115,138건, 양성 4,472건 전부**를 기준으로 합니다. 입금 이후 7일을 끝까지 관찰하려고 관련 거래를 2022-11-07까지 확보했습니다.

### 이후 외부 엔티티로 송금하는 비율도 비슷했다

| 관찰 범위 | 입금 이후 | 정상 | 무패턴 양성 |
|---|---|---:|---:|
| 수신 계좌 · 동일 통화 | 1시간 | 3.70% | 3.29% |
| 수신 계좌 · 동일 통화 | 24시간 | 37.30% | 37.57% |
| 수신 계좌 · 동일 통화 | 7일 | 53.90% | 54.54% |
| 같은 소유주의 전체 계좌 · 모든 통화의 건수 | 1시간 | 11.83% | 11.38% |
| 같은 소유주의 전체 계좌 · 모든 통화의 건수 | 24시간 | 56.82% | 57.04% |
| 같은 소유주의 전체 계좌 · 모든 통화의 건수 | 7일 | 73.52% | 73.95% |

‘외부’는 다른 엔티티로 보내는 거래입니다. 금액은 통화별로 계산했고, 모든 통화를 합친 경우에는 거래 건수만 비교했습니다.

**수신 계좌에는 출금이 없지만 같은 소유주의 다른 계좌에서 출금한 경우**도 확인했습니다. 동일 통화의 24시간 외부 출금 기준으로 정상 **17.31%**, 양성 **16.79%**였습니다.

입금 뒤 출금이 있다는 것은 시간상 후속 거래가 관측됐다는 뜻입니다. 기존 잔액이나 다른 입금도 있으므로, **방금 받은 돈이 그대로 재송금됐다는 자금 추적 증거는 아닙니다.**

### 같은 수신 계좌·가까운 시각의 정상 거래와 짝지어 봐도 비슷했다

양성 4,472건 중 **3,974건, 88.86%**에서 수신 계좌·수취 통화가 같고 ±1시간 이내인 가장 가까운 정상 거래를 찾았습니다. 시간 차이 중앙값은 **7분**이었습니다.

이 거래쌍은 수신 계좌의 이후 24시간 외부 출금 발생 여부가 **99.80% 일치**했습니다.

이는 가까운 시각에 같은 계좌로 들어온 거래들이 이후 관측 창과 출금 거래를 많이 공유한다는 뜻입니다. 독립적인 거래쌍 실험이나 개별 자금의 귀속을 입증한 것은 아닙니다.

## 8. 실제 분류 실험에서는 개선됐는가?

### 실험 방식

이번 모델은 피처의 구분력을 빠르게 확인하기 위한 **진단용 분류기**입니다. 주력 GNN의 재학습 성능표와 구분해서 설명해야 합니다.

| 구간 | 기간 | 사용 방식 |
|---|---|---|
| Train | 2022-08-01~09-25 | 정상 약 5% 표본 491,817건 + 양성 13,866건 |
| Val | 2022-09-26~10-13 | 정상 3,270,588건 + 양성 4,641건 전부 |
| Test | 2022-10-14~10-31 | 정상 3,115,138건 + 양성 4,472건 전부 |

- HistGradientBoosting의 반복 수 100회, 최대 리프 15개 등 설정을 고정했습니다.
- 거래 정보, 소유주 특성, 송신·수신 계좌 및 소유주 전체의 과거 이력을 단계적으로 비교했습니다.
- 검증 성능으로 모델과 임계값을 선택하고 테스트에 고정 적용했습니다.
- 계좌 ID·엔티티 ID·은행 ID·거래 ID는 모델 입력에 사용하지 않았습니다.
- 과거 피처는 현재 거래보다 엄격히 앞선 거래로 계산하고 같은 분의 다른 거래도 제외했습니다.
- 이후 7일 정보를 쓰는 모델은 별도의 **사후 분석**으로 평가했습니다. 거래 발생 즉시 사용할 수 있는 모델과 섞지 않았습니다.

### 테스트 결과

오탐률이 검증에서 0.1% 이하가 되도록 정한 임계값을 고정했을 때의 결과입니다.

| 모델 | ROC-AUC | AP | 탐지 양성 / 4,472건 | 오탐 정상 | 실제 테스트 오탐률 |
|---|---:|---:|---:|---:|---:|
| 이전 거래 정보 모델 | 0.5321 | 0.1559% | 6건 | 3,077건 | 0.0988% |
| 수신 계좌·소유주 전체의 과거 이력 추가 | 0.5300 | 0.1580% | 4건 | 2,811건 | 0.0902% |
| 이후 7일 흐름 요약까지 추가 · 사후 분석 | 0.5267 | 0.1544% | 6건 | 2,630건 | 0.0844% |

ROC-AUC의 무작위 기준은 **0.5**입니다. AP는 양성을 얼마나 앞쪽에 모아 놓는지 보는 지표이며, 무작위 순위의 기준은 대략 해당 구간의 양성 비율입니다. 테스트 양성 비율은 **0.1434%**였습니다.

과거 이력 추가 모델에서 AP는 조금 올랐지만, ROC-AUC와 낮은 오탐률에서의 탐지 건수는 개선되지 않았습니다. 이후 7일 흐름 요약을 보더라도 실용적인 개선은 확인되지 않았습니다.

이후 정보를 쓰는 실험은 **1시간·24시간·7일의 횟수·금액·간격 요약**을 추가한 것입니다. 미래의 모든 거래 경로나 실제 자금 흐름을 완전히 분석한 모델은 아닙니다.

또한 기존 테스트 구간을 재사용한 후속 탐색이므로, 새로운 독립 최종 검증으로 해석해서는 안 됩니다.

## 9. 지금까지 확인한 내용과 남은 질문

### 확인한 내용

1. 무패턴 양성은 전부 단건 거래가 아니며, 일부는 다른 무패턴 양성과 연결되어 있습니다.
2. 과거 24시간에 연결된 거래에서는 fan-out 형태가 많았습니다.
3. 그 fan-out의 대부분은 15개 송신 계좌에서 나왔습니다.
4. 이 집단은 기존 패턴 fan-out과 크게 달랐지만, 같은 계좌의 정상 거래와는 단건 특성·거래 이력·수신 후 활동이 많이 겹쳤습니다.
5. 이번에 확인한 피처와 진단 모델에서는 유용한 분리 성능을 얻지 못했습니다.

### 아직 결론 낼 수 없는 내용

- 모든 무패턴 양성이 탐지 불가능하다는 결론은 아닙니다. 자세히 비교한 15개 계좌의 양성 22,979건은 전체의 **27.93%**입니다.
- 양성 라벨이 틀렸다거나 정상으로 바꿔야 한다는 근거는 확보하지 않았습니다.
- 원본에서 왜 이 거래들이 양성으로 생성됐는지는 아직 확인하지 않았습니다.
- 단순한 입출금 요약에서 차이가 작다는 결과가, 정확한 다단계 경로·순환 구조에도 차이가 없다는 뜻은 아닙니다.

### 추가 확인 후보

다음 항목은 아직 수행 결과가 없는 제안입니다.

1. 원본 데이터의 양성 라벨 생성 조건과 패턴 매핑 과정을 확인합니다.
2. 이번 15개 계좌 집단을 제외한 **나머지 무패턴 양성 59,281건**을 나눠 분석합니다.
3. 필요하면 시간·방향·금액 조건을 가진 구체적인 다단계 경로나 순환을 확인합니다.
