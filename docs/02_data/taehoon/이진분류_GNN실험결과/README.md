이 폴더는 문서에 연결된 노트북 8개, 그림 24개, 실제 실험 결과 CSV와 감사 기록을 함께 제공하는 Git 업로드용 패키지입니다. 원본 데이터와 모델 가중치는 포함하지 않습니다.

## 실행

Python 3.11/3.12와 Jupyter를 준비하고, 통합 노트북에서 첫 실행 시 라이브러리를 설치하세요. 기본 `DEMO=True`는 가상 거래로 전처리부터 6종 학습·증강·시각화까지 확인합니다. 실제 데이터는 `DEMO=False`로 바꾸고 원본 3개 파일의 폴더를 지정합니다. 자세한 내용은 통합 설명서에 있습니다.

## Git에 올리기

이 폴더의 **전체 구조를 유지한 채** 저장소에 복사하세요. `.gitignore`와 `.gitattributes`도 포함합니다. 기존 저장소가 있다면 이 폴더만 추가하면 됩니다. 원격 저장소 생성이나 업로드는 이 패키지에서 수행하지 않았습니다.

통합 노트북에는 예제 실행 출력과 그림을 보존했습니다. 출력에 나타나는 임시 폴더는 제작 시 실행 위치이며 실행 코드가 그 경로에 의존하지 않습니다. 문서의 그림은 `문서_그림/` 상대 경로를 사용합니다.

`.gitignore`는 기본 데이터·실행 출력·캐시·가중치 등을 제외합니다. 실제 데이터를 다른 이름의 폴더에 넣었다면 해당 폴더도 제외 목록에 추가하세요.

기존 실제 데이터 성능과 새 인공 데이터 데모를 구분했습니다. 기존 성능은 검증셋 결과이고 독립 테스트셋 성능이 아닙니다. 근거 자료의 과거 시각화 스크립트는 원래 실험 캐시가 필요한 보관용 코드이며, 새 실행에는 통합 노트북을 사용합니다.
