이 패키지에는 원본 거래 CSV/TXT, 거래별 그래프 배열, 학습 가중치, 실제 거래별 예측 파일을 포함하지 않았습니다. 성능은 검증셋 결과이며 독립 테스트셋 성능이 아닙니다.
