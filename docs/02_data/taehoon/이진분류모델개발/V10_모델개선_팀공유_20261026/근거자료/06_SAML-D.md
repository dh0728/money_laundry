# SAML-D 외부 일반화 성능 검증 — 2026-10-25

HI-Large에서 학습한 두 모델의 가중치·피처 선택·정규화·임계값을 고정하고 SAML-D 전체를 평가했다. SAML-D 재학습이나 임계값 조정은 하지 않았다.
**두 후보 모두 HistGradientBoosting 모델이다. V10 GNN 가중치의 외부 평가 결과로 해석하면 안 된다.**
**최근 25종 후보의 직접 호환 평가는 불가능하다.** 필요한 KYC와 별도 수취액이 없어 40개 입력 중 13개를 0으로 대체한 조건부 이식 평가다. 29종 대조군은 기존 HI 실험에서 이미 학습한 모델이며 KYC·수취액 피처를 쓰지 않는다. 대조군에도 지급 방식/통화 스키마 차이와 Amount 의미 가정은 남는다.

## 3. 스키마 차이와 대체 정책

- SAML-D에는 별도 KYC 소유자 ID·유형과 수취 금액이 없다. 은행 소재지를 소유자로 간주하거나 지급 금액을 수취 금액으로 복제하지 않았다.
- 노드는 원본 계좌 ID를 기준으로 구성했다. 은행 소재지는 개별 은행 ID가 아니므로 이를 붙여 계좌를 분할하지 않았다. 별도 은행 식별자가 없어 이 정책에는 원본 ID가 계좌를 식별한다는 가정이 있다.
- Amount를 지급 통화의 금액으로 간주했다. 제작자 자료는 이를 거래 금액으로 설명하며 지급/수취 중 어느 쪽 단위인지 명시적으로 확정하지 않는다. 이 가정은 검증 한계다.
- Cash Deposit/Withdrawal은 HI의 Cash 범주로 통합했다. ACH, Cheque, Credit card는 이름을 대응했다. Debit card를 신용카드로, Cross-border를 Wire로 추정하지 않았다. 두 범주는 -1을 넣어 기존 sklearn 범주 결측/미관측 처리로 전달했다.
- HI에 직접 대응하지 않는 지급 방식: 2,946,034건 (31.00%).
- HI 금액 정규화 계수가 없는 지급 통화: 159,771건 (1.68%). 해당 금액 표준화 값만 0으로 대체했다. 행동 이력에서는 서로 다른 통화를 합치지 않았다.
- HI 통화 정규화·금액 평균/표준편차를 그대로 사용했다. SAML 전체나 평가 구간에서 새 정규화 계수를 학습하지 않았다.
- 25종 후보의 13개 대체 열: `same_entity`, `src_log_entity_observed_accounts`, `src_log_entity_out_diversity`, `src_log_entity_in_diversity`, `dst_log_entity_observed_accounts`, `dst_log_entity_out_diversity`, `dst_log_entity_in_diversity`, `src_day_ccy_flow_balance`, `src_day_ccy_log_matching_in_amount`, `dst_day_ccy_flow_balance`, `dst_day_ccy_log_matching_in_amount`, `dst_prior_ccy_amount_seen`, `dst_prior_ccy_amount_vs_mean`.
- 0은 결측 전용으로 학습된 토큰이 아니다. 따라서 25종 결과에는 데이터 분포 변화와 피처 누락 대체의 영향이 함께 포함되며, 두 영향을 인과적으로 분리한 결과가 아니다.
- SAML의 원본 17개 양성 유형을 평가 후 집계했다. HI의 8패턴/무패턴 구분과 동일한 라벨이 없어 무패턴 Recall을 임의로 만들지 않았다.

데이터 스키마와 유형 체계 참고: [제작자 README](https://github.com/BOztasUK/Anti_Money_Laundering_Transaction_Data_SAML-D/blob/main/README.md), [제작자 논문](https://eprints.bournemouth.ac.uk/40982/).

## 4. 검증과 누수 차단

- 소스 모델 학습 종료는 2022-09-25, SAML 최초 거래는 2022-10-07이다. 타임스탬프를 포함한 학습 거래 중복은 0건이다. 계좌 네임스페이스와 이력은 두 데이터 사이에서 합치지 않았다.
- SAML은 이 프로젝트의 다른 실험에서 이미 열람·평가한 데이터다. 이번 두 모델의 학습에는 쓰이지 않았지만, 완전히 새로운 미열람 데이터라고 주장하지 않는다.
- 입력 전용 Parquet와 평가 라벨 Parquet를 분리했다. 피처 생성 함수는 허용된 관측 컬럼만 읽는다. 정답·세탁 유형은 피처에 들어가지 않는다.
- 하루 마감 피처는 당일 전체를 포함하고 다음 날 이후는 제외한다. 과거 금액 이력은 전날까지, 거래 간격/시간창은 엄격히 이전 분까지다.
- 합성 8건에서 미래 거래 제거, 라벨 주입/변경, 같은 분 문맥, 이전 분 이력을 검증했다.
- HI 원래 입력: 8개 대상, 관련 관측 767건, 사용 가능한 44개 열이 기존 검증 캐시와 최대 절대 오차 0으로 일치했다.
- SAML 원본 24개 대상의 이력·계좌·분 단위·금액 피처를 독립 SQL로 재계산했다. 2022-10-09까지 실제 데이터만 남겨 다시 계산한 전체 71열도 전체 파일에서 계산한 동일 거래 입력과 비트 단위로 일치했다.
- 원본 관측값 완전 중복은 0건이다. 분 단위 반올림 시 충돌하는 1쌍은 초가 다른 거래이므로 둘 다 보존했다. `02_same_minute_retained.csv`에 기록했다.
- 두 모델의 점수 변환이 기존 구현과 일치하고 배치 크기 변경에 불변임을 확인했다. 950만 건의 예측이 모두 유한하며 일별·월별·유형별 합계가 전체와 일치한다.
- 모델·임계값·정규화 파일과 원본 CSV의 SHA-256을 실행 전후 비교했다. 기존 아티팩트는 변경하지 않았다.

## 6. 피처 누락 영향의 HI 내부 대조 실험 (37번)

외부 평가에서 성능 하락을 확인한 뒤, 같은 25종 모델에 같은 HI 전체 검증 거래를 넣고 SAML에서 없는 13개 입력만 0으로 바꿨다. 나머지 입력·가중치·임계값은 동일하다. SAML 결과를 보정하거나 새 후보를 선택하는 데 사용하지 않았다.

| HI 검증 조건 | Precision | Recall | TP | FP |
|---|---:|---:|---:|---:|
| 원래 입력 | 70.11% | 63.01% | 7,670 | 3,270 |
| 동일 13개 입력 0 대체 | 74.09% | 59.34% | 7,223 | 2,526 |

이는 HI 분포 안에서 입력 대체의 영향을 측정한 대조다. 외부 데이터의 전체 하락분을 같은 크기의 피처 누락 효과와 데이터 분포 효과로 분해할 수 있다는 뜻은 아니다. 원래 HI 검증 예측과 입력 결합이 일치하는지도 확인했다. 상세 기록은 05_source_missing_control.json에 저장했다.
