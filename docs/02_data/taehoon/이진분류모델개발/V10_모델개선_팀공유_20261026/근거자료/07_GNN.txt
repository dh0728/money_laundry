V10 실제 GNN 검증 결과 (2026-10-25)

모델: 양방향 2층 TransformerConv GNN. HGB를 사용하지 않음.
기준: 기존 19 노드 + 17 거래 피처 = 36종. 확장: 신규 9종 추가 = 45종.
추가 9종은 송수신 역할을 펼치면 14개 원시 입력 열이다. 결제방식은 임베딩으로 입력한다.
신규 입력은 그래프 임베딩과 함께 분류층에 결합한다. 메시지 전달에는 기존 노드 19종과 거래 17종을 사용한다.
두 모델은 같은 공유 파라미터 초깃값에서 새로 학습했다. 기존 체크포인트로 성능을 대신 보고하지 않았다.

original36_daily는 별도 기준선이다. 기존 V10 체크포인트를 그대로 두고 수정된 일 마감 입력/그래프로 평가했으며, 기존 필터·기존 입력의 지표와 구분한다.
이 기준선은 학습 당시의 구 전처리를 사용한 모델이므로, 수정 전처리로 새로 학습한 모델로 표현하지 않는다.

평가 범위와 해석
정밀도는 정상 표본에 일별 모집단 가중치를 적용한 추정치다. 전수 평가 정밀도가 아니다.
양성은 검증 12,173건, 역사적 테스트 44,103건, SAML-D 9,873건 전부 평가했다. 해당 데이터 재현율은 정확한 전수 양성 재현율이다.
95% 구간은 정상 표본의 가중 유효표본수로 계산한 근사 Wilson 구간이다. 검증 임계값 탐색의 선택 불확실성은 포함하지 않는다.
역사적 테스트와 SAML-D는 프로젝트 이전 실험에서 이미 사용한 데이터다. 새로 확보한 미지의 외부 홀드아웃으로 표현하지 않는다.

학습과 임계값
전체 학습 양성 101,515건(무패턴 46,617건) + 클러스터 정상 표본에서 일별로 추가 추출한 정상 100,000건. 두 단계 추출 확률을 모두 손실에 반영. 실제 학습 6회, 최대 6회로 사전 고정.
주변 그래프는 전체 관측 거래에서 추출한다. 정상 표본/라벨/패턴 정제 여부로 주변 거래를 제거하지 않는다.
모델 회차 선택: 9/26~10/4 표본 가중 AP. 임계값: 10/9~13 표본 가중 정밀도 70% 이상에서 재현율 최대화. 각 모델의 임계값을 별도로 고정.
역사적 테스트와 SAML-D 결과로 모델 또는 임계값을 다시 맞추지 않았다.
정상 학습 표본을 줄인 6회 이내 진단 비교다. 전체 정상 표본·긴 학습·여러 시드까지 검증한 GNN의 최종 성능 한계가 아니다.

초기 중간검증 후 두 모델 모두 논리 배치를 2048에서 512로 줄여 업데이트 수를 늘렸다. 변경은 epoch 2, 일자 커서 11의 저장 상태에서 적용했다. 이전 코드·조건·체크포인트를 보존했다.
그래프/입력 배열의 비트 단위 동일성을 확인한 후 계좌 인덱스 조회 최적화와 2개 입력 준비 작업자를 적용했다. 모델 구조·학습 표본·그래프 선택 규칙은 그대로다.

전처리/누수 검증
일 마감 이후 거래 제외. 같은 분의 모든 주변 거래를 두 단계 이웃 모두에서 보존. 다른 분의 거래만 계좌·방향별 100건 한도.
클러스터 표본 때문에 주변 거래를 제거하지는 않는다. 다만 2홉·다른 분 100건 한도 자체의 정보 손실이나 최적성까지 입증한 것은 아니다.
표본 우선순위는 v3 고정 hash(eid,node,42)다. 이전 v2의 일자 포함 해시와 다른 샘플러이며, 두 비교 모델에는 동일하게 적용했다.
전체 원본 SQL과 실제 그래프 2건 일치. 거래 밀집 사례의 그래프는 91,008건, 동일 분 거래는 692건이었다.
미래 거래 제거 전후 그래프 동일, 타깃 배치 변경과 주변 그래프 독립, 첫/둘째 홉 동일 분 한도 초과 거래 보존 검사 통과.
SAML-D 실제 같은 분 거래 4,569,017번 및 4,569,029번 모두 보존.
연산 최적화는 모델의 메시지 계산 결과를 유지한다. 원 구현 대비 float64 출력·기울기 최대 차이 약 5.33e-15, GPU 허용오차 검사 통과.
기존 피처의 독립 SQL 검증 결과를 재사용하고 해당 검증 파일 해시를 기록했다. 피처/그래프 입력에는 정답·패턴 라벨이 없다.
실제 GNN 입력 경로를 수정 전처리 캐시와 대조했다: HI 92일 2,944건, SAML-D 64건 통과. 학습/검증 ID와 추가 피처 행 정렬도 모두 일치한다.
학습·검증 주변 거래 136,996,982건 전체의 거래 피처 존재 여부를 검사했고 누락은 0건이었다. 테스트 33,429,507건은 별도의 수정 피처 캐시로 처리한다.
HI의 정적 KYC에 제공 시점 기록이 없어 그 부분의 미래누수는 완전히 인증할 수 없다.
SAML-D는 KYC와 수취 금액이 없으므로 관련 입력을 0으로 처리했다. 은행 소재지를 고객 국가로 대신 넣지 않았다. 이 차이와 데이터 분포 차이를 함께 고려해야 한다.

목표 판정
세 모델 모두 고정 임계값에서 HI 테스트 양성 전수 재현율이 65%에 미달했다. 따라서 정밀도 표본 오차와 무관하게 이번 운영점의 목표는 미달이다.
재현율이 이미 미달하므로 이번 후보들의 정상 거래 전수 추론은 시행하지 않았다. 정밀도는 표본 가중 추정치로만 보고한다.
Precision >=70%, Recall >=65%의 전수 최종 인증은 이 표본 평가만으로 주장할 수 없다.
45종 - 재학습 36종의 테스트 변화: 무패턴 TP +160건, 패턴 TP -1,597건, 전체 TP -1,437건, 재현율 -3.258%p.
SAML-D에서는 세 모델 모두 정밀도 추정치가 1% 미만이었으며, 일반화 목표도 충족하지 못했다.
새 피처 9종의 개별 필요성은 아직 제거 실험으로 입증하지 않았다. 36종/45종 묶음 비교 결과로만 해석한다.
