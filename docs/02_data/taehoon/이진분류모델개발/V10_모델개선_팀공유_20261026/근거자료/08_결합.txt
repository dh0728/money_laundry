V10 트리 + GNN 결합 검증 — 2026-10-25

결론: 이번 점수 결합 실험은 P >= 70%, R >= 65% 목표를 달성하지 못했다.
결합 후보 9개 + 트리 대조군 3개를 비교했다. 검증 기준 전체 1위는 트리 단독이었다.
선택된 결합은 HGB25 점수 + 재학습 GNN36 점수를 받는 로지스틱 회귀다.
과거 테스트에서는 오탐 추정치가 줄었지만 무패턴 탐지와 전체 재현율이 낮아졌다.
따라서 이번 결합을 기존 모델의 성능 개선판으로 채택하지 않는다. 기존 모델 파일은 변경하지 않았다.

평가 기준 및 한계
목표는 precision 70% 이상과 recall 65% 이상을 같은 고정 임계값에서 동시에 충족하는 것이다.
하루 마감 일괄 판정: 당일 종료까지의 관측은 허용하고 다음 날 관측은 금지한다.
기본 모델 가중치 학습: 2022-09-25까지. 재학습 GNN 체크포인트 선택: 09-26~10-04.
결합층 학습: 10-05~10-08 (115,830건, 양성 9,637건).
후보/임계값 선택: 10-09~10-13 (양성 전수 12,173건 + 정상 표본 124,080건).
과거 테스트: 10-14~10-31 (양성 전수 44,103건 + 정상 표본 99,999건).
SAML-D: 양성 전수 9,873건 + 정상 표본 100,005건. HI에서 정한 임계값 그대로 적용.
정상 표본은 날짜별 역확률 가중치로 원래 거래 비율을 복원했다.
이하 표의 P는 정상 표본 가중 추정치, R과 무패턴 R은 해당 구간 양성 전수 값이다.
이전 프로젝트에서 검증/테스트/SAML을 이미 여러 번 사용했으므로 새로운 미공개 홀드아웃 검증이 아니다.
원본 GNN 체크포인트는 과거 검증 구간으로 선택된 이력이 있다. 이번 최상위 결합은 별도 모니터 구간으로 선택한 재학습 GNN36을 사용한다.
검증 표본에서 목표를 충족한 후보가 없으며 선택 모델의 테스트 R도 65% 미달이므로, 이번 결합의 정상 전수 추론은 하지 않았다.

왜 무패턴 개선에 실패했는가
기존 트리가 놓쳤으나 결합이 잡은 양성은 333건, 반대로 기존 트리만 잡은 양성은 498건이다. 양성 TP는 -165건 변했다.
무패턴은 결합이 새로 잡은 269건보다 놓치게 된 472건이 많아, TP가 -203건 변했다.
정상 표본의 오탐은 기존 트리 41건, 결합 33건이었다. 이 표본에서는 오탐 감소와 무패턴 미탐 증가가 함께 발생했다.
단순 OR/AND도 검증했다. 각 기본 모델의 기존 고정 임계값에서 얻은 결과이며, 모든 가능한 결합의 상한을 뜻하지 않는다.

피처 수와 누수 검증
선택 결합층 입력은 HGB의 이진 log-odds와 GNN의 logit 두 개다. 이 두 값을 만들기 위한 원천 피처는 45종이다.
HGB25: 원천 25종 / 스칼라 40열. GNN36: 노드 19종 + 거래 17종. 중복 원천 16종을 빼면 25+36-16=45종이다.
추가한 원천 피처 종류는 이번 실험에서 0개다. 기존 45종 중 조합만 바꿨다. 45종 GNN 결합도 원천 합집합은 동일하다.
타깃 거래 표시용 ego 비트와 임베딩 차원은 도메인 피처 종류 수에 포함하지 않는 기존 계산법을 유지했다.
패턴/무패턴으로 나눈 결합 후보의 입력도 HGB가 예측한 클래스 점수이며 실제 패턴 정답값이 아니다.
학습·모니터·결합층 학습·검증·테스트 간 타깃 ID 중복 0건을 확인했다. 결합층 정규화는 결합층 학습 구간만 사용했다.
검증 12개 + 테스트/SAML 6개 = 18개 저장 점수 재실행 및 혼동행렬 재계산이 정확히 일치했다.
기본 체크포인트 해시는 실험 전후 동일하다. 선택된 결합이 실제 두 예측 점수를 모두 사용함도 확인했다.
거래 피처와 그래프의 시간 경계/동일 분 보존은 선행 GNN 검증 결과를 이어 사용했다. 이번에 과거 관측으로의 새로운 역류나 정답 피처 추가는 없다.
클러스터는 학습 타깃 표본에 영향을 주고 주변 그래프의 거래 자격을 제한하지 않는다. 다만 GNN은 다른 분의 이웃을 노드/방향별 100개로 샘플링하고, 타깃과 같은 분 이웃은 별도로 보존한다.
따라서 주변 거래를 모두 매번 메시지 전달에 사용한다는 뜻은 아니다. 이 결합 실험은 이웃 샘플링 방식의 모든 대안을 검증하지 않았다.
정적 KYC 원천의 당시 가용 시점 기록이 없어 이 부분의 미래누수 부재는 완전히 인증할 수 없다.
새 결합층의 라벨/시간 분리 확인과 기존 원천 자료의 미확인 사항을 구분해야 한다.

해석 및 다음 실험 방향
현재 검증 근거에서는 피처를 25종에서 45종으로 늘리는 비용을 정당화할 recall 개선이 없다.
점수 결합은 GNN이 이미 만든 한 개 위험 점수만 추가한다. GNN의 중간 임베딩을 트리에 넣거나 트리 출력을 메시지 전달에 반영하는 공동 학습은 이번에 실행하지 않았다.
따라서 이번 결과만으로 모든 트리-GNN 결합이 효과 없다고 결론내릴 수 없다.
다음 우선순위는 무패턴 전용 대조 학습 또는 관측 자금 흐름 피처가 기존 점수에 없는 구별 정보를 주는지, 적은 피처부터 별도 시간 구간에서 확인하는 것이다.
테스트/SAML 결과에 맞춰 이번 임계값을 다시 바꾸지 않았다. 출력 JSON의 max_recall_at_precision70/max_precision_at_recall65는 사후 곡선 진단값이며 운영 성능으로 사용하지 않는다.
