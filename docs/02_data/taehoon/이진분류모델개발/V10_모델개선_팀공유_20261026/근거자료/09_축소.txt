V10 결합 모델 피처 축소 검증 — 2026-10-25

결론: 45→25종(44.44% 감소)으로 구현할 수 있으나, 과거 테스트 P 추정치는 71.5588%→67.4517%, R은 62.8529%→62.7508%였다.
16종 결합의 과거 테스트 R은 58.4881%로 손실이 더 컸다. 두 축소안 모두 P70/R65 목표 미달이다.
25종은 경량화 후보로 남기되 성능 유지가 확인된 운영 대체 모델로 채택하지 않는다. 16종의 일괄 축소는 현재 결과에서 권장하지 않는다.
P는 표본 추정치이고 신뢰구간이 겹치므로 정밀도 하락의 통계적 유의성을 입증했다는 뜻은 아니다. R65 미달은 양성 전수로 확인했다.

기존 45종 결합과 비교해 25종/16종 결합을 실제로 재학습했다.
목표는 같은 임계값에서 Precision >=70%, Recall >=65%이며 피처 수를 적게 쓰는 것을 선호한다.
피처를 적게 쓰는 것과 성능 목표를 달성하는 것은 별도 판정이다.

축소 방법
기존 45종 = 트리25 + GNN36 - 공통16.
25종 결합 = 기존 트리25 유지 + 공통16종만 입력받도록 재학습한 GNN16.
16종 결합 = 트리16 재학습 + 같은 GNN16. 트리와 GNN이 같은 종류를 써도 GNN은 주변 거래 그래프의 값을 함께 처리한다.
GNN16은 노드10종 + 거래6종이며, 타깃 표시 ego 비트는 별도 구조 입력이다. 계좌 연결과 거래 시각도 그래프 구성에 계속 필요하다.
트리16은 송신/수신 노드 열을 따로 쓰므로 스칼라26열, 트리25는 스칼라40열이다. 종류 수와 실제 열 수를 구분한다.
GNN만 필요하던 20종을 제거하면 합집합이45→25종(44.44% 감소)이 된다. 트리 전용9종까지 제외하면16종(64.44% 감소)이 된다.

학습과 선택 규칙
기본 학습은 2022-09-25까지. GNN 가중치 선택은09-26~10-04의 모니터 구간에서만 했다.
결합층은10-05~10-08에 학습하고,10-09~10-13에서 종류별 결합 방식과 임계값을 선택했다.
과거 테스트10-14~10-31 및 SAML-D는 고정한 모델/임계값으로 평가했다.
기존 프로젝트에서 검증/테스트/SAML을 이미 사용한 이력이 있으므로 새 미공개 홀드아웃 검증으로 볼 수 없다.
GNN 학습은 기존36종 실험과 같은 타깃201,515건, 손실 가중치, 그래프, seed42, 학습률/배치 변경 일정, 최대6 epoch를 사용했다.
학습된36종 가중치를 재활용하지 않았다. 같은 무작위 초기값에서 남는 열만 취한 후 새로 학습했다.
GNN 선택 epoch: 6; 총 학습 epoch: 6.
트리16은 기존 트리25와 같은2,139,509개 학습 타깃, 클러스터/균등 정상 표본 혼합 가중치, HGB300회 설정을 사용했다.
결합층은 예측점수2개로 로지스틱 회귀와 작은 HGB를 비교했다. 실제 정답 라벨은 결합 입력이 아니다.
검증 P 추정치>=70%인 후보의 R을 비교하고 최대R 대비0.1%p 이내이면 적은 원천 피처 수를 우선했다.
종류별 최상위 결합도 검증에서 고정해25종과16종을 모두 보고했다. 테스트 결과로 선택을 바꾸지 않았다.

지표/누수/입력 검증
정상 거래 표본에 날짜별 가중치를 적용했다. 검증 양성12,173건, 과거 테스트 양성44,103건, SAML 양성9,873건은 모두 포함했다.
과거 테스트 정상 표본99,999건과 SAML 정상 표본100,005건을 사용했다. 양성 R은 전수 값이고 P는 표본 추정치다.
P의 근사 Wilson 구간은 정상 오탐 비율의 유효 표본 수로 계산하며, 임계값 선택/반복 실험의 불확실성은 포함하지 않는다.
tree25 대조군은 이번과 같은 검증 표본에서 재선택한 임계값을 쓴다. 과거 전수 검증에서 고정했던 기존 트리 임계값과 혼동하지 않아야 한다.
학습/모니터/결합층 학습/검증/테스트 타깃ID 중복0건. 결합층 전체 점수 재실행, 기본 모델의 표본 재실행, 고정 임계값 혼동행렬 재계산이 모두 일치했다.
입력 축소의 초기 네트워크 수학적 동등성: 출력 최대 차이 2.08e-17, gradient 최대 차이 2.22e-16.
실제 일별 입력/그래프 검사 27회: 제외한 열을 임의값으로 바꿔도 모델에 들어가는 배열은 동일하며 다음 날 그래프 거래는0건.
모델 입력과 파라미터 차원을 실제로 줄였다. 학습된 모델의 피처를0으로 바꾼 결과만으로 성능을 판단하지 않았다.
하루 마감 판정 조건과 기존 동일 분 거래 보존 규칙을 유지했다. 그래프의 다른 분 이웃은 노드/방향별100개 cap이 남아 있다.
공통16종에도 same_entity 및 소유주 단위 집계가 남는다. 따라서 이 모델을 KYC가 전혀 없는 모델로 부르면 안 된다.
KYC 정보의 당시 가용 시점이 없어 원천 자료의 미래누수 부재는 여전히 완전히 인증할 수 없다.
피처 종류 수는 실제 모델에 입력된 합집합이다. 이번 실험은 기존 전체 피처 캐시에서 필요한 열을 선택했으며, 운영 전처리를 필요한 열만 계산하도록 다시 구현한 것은 아니다.
GNN 파라미터 263,041→246,785. 숨은 차원과 그래프 연산을 유지했으므로 피처 감소율이 곧 실행시간 감소율은 아니다.
단일 seed와 사전 고정한 두 가지 축소안의 검증이다. 이것이 가능한 최소 피처 수이거나 제거한 모든 피처가 보편적으로 무의미하다는 증거는 아니다.
