V10 결제 방식 ACH 의존성 진단 — 2026-10-25

결론: 사용자의 우려를 뒷받침하는 강한 결제 방식 의존성이 확인됐다. 특히 패턴 양성의 예측이 ACH 입력에 민감하다.
ACH 거래를 전부 양성으로 분류하는 단순 규칙은 아니다. ACH 정상 거래 대부분은 정상으로 판정하며 다른 피처도 사용한다.
결제 방식의 단독 제거 재학습은 이번 진단에서 실행하지 않았다. 제거하면 성능이 좋아진다는 결론도 아직 내릴 수 없다.

복원된 전체 거래 분포 및 현재 HGB25의 고정 임계값 결과
검증 구간:2022-10-09~10-13. 테스트 구간:2022-10-14~10-31. 모두 정상 포함 전수 집계다.
검증: 정상 8,538,842건, 패턴 양성 7,236건, 무패턴 양성 4,937건.
ACH 비중: 정상 12.2720%, 패턴 양성 100.0000%, 무패턴 양성 72.1896%.
ACH 전체 1,058,690건 중 양성 10,800건. P(양성|ACH)=1.0201%.
ACH만으로 경보하면 P=1.0201%, R=88.7209%.
실제 HGB25는 ACH 정상 1,047,890건 중 3,177건에 경보: ACH 정상 FPR=0.3032%.
무패턴 검출률: ACH 478/3564=13.4119%, 비ACH 13/1373=0.9468%.
과거 테스트에서도 비ACH 무패턴 검출률은 56/4877=1.1482%.
방식별 검출률 차이만으로 결제 방식의 인과적 효과를 판정할 수는 없다. 집단별 행동 특징과 분포도 다를 수 있다.

HGB25 입력 민감도 검사
검증 스크리닝 코호트136,253건(양성 전수12,173건 포함)에 기존 모델과 기존 임계값을 사용했다.
payment_format 하나만 ACH/Cheque/Wire로 바꾸고 나머지39개 스칼라 열을 고정했다. 원본 점수 재실행 최대 차이0.
검증 패턴 양성7,236건은 전부 ACH다. 원본 검출7,179건(99.2123%).
ACH→Cheque 변경 시 검출6건(0.0829%), ACH→Wire 변경 시0건.
결제 방식만으로 모든 양성을 고르는 상태라기보다, 패턴 양성 판정에서 ACH를 강한 조건으로 사용하는 경향을 뒷받침한다.
다른 입력과 맞지 않는 가상의 조합이 생길 수 있으므로 변경 후 수치를 실제 성능 또는 재학습 성능으로 해석하지 않는다.

기존45종 결합 모델의 입력 민감도
GNN36은 payment_format을 직접 입력받지 않는다. GNN 점수를 고정하고 HGB 점수 변화만 결합층에 전달했다.
original: 패턴 양성 검출 7,187/7,236 (99.3228%), 무패턴 검출 447/4,937 (9.0541%).
ACH: 패턴 양성 검출 7,187/7,236 (99.3228%), 무패턴 검출 448/4,937 (9.0743%).
Cheque: 패턴 양성 검출 57/7,236 (0.7877%), 무패턴 검출 193/4,937 (3.9093%).
Wire: 패턴 양성 검출 0/7,236 (0.0000%), 무패턴 검출 0/4,937 (0.0000%).

기존 검증의 범위와 해석
10c_reduce_features.py는 payment_format을 강제로 포함한 뒤 나머지 피처를 선택했다. 따라서 포함 필요성을 단독 제거 비교로 입증한 것은 아니다.
직전25→16종 실험에서는 결제 방식을 포함한9종을 동시에 제거했다. 그 성능 하락을 결제 방식 하나의 효과라고 볼 수 없다.
원본 거래 시점에 관측되는 결제 방식 자체가 자동으로 정답누수/미래누수에 해당하는 것은 아니다.
합성 데이터의 생성 규칙을 반영한 라벨 대리 신호에 의존하면 다른 환경에서 실패할 수 있다. 이번 진단은 그 위험을 뒷받침하지만 일반화 실패 전체의 원인을 하나로 입증하지 않는다.
SAML-D의 입력 차이와 다른 분포 차이도 남아 있다. payment_format 없는 GNN36 역시 앞선 SAML-D 평가에서 목표 미달이었다.

다음에 필요한 분리 검증 — 아직 실행하지 않음
1. 같은 데이터/가중치/학습 조건에서 HGB25 대 payment_format만 뺀 HGB24를 재학습하고 각 임계값은 검증에서만 선택한다.
2. 고정 GNN36과 결합할 때도 결합층을 별도 기간에서 다시 학습한다. 전체 합집합은45→44종이다.
3. ACH 내부 정상 대 무패턴 분리력, 비ACH 무패턴 recall, 결제 방식별 정상 오탐률을 전체 P/R과 함께 비교한다.
4. 임계값을 고정한 다른 기간과 SAML-D를 확인한다. 전수 또는 원래 정상 비율을 반영한 가중치로 평가하며, 단순 균형 표본 precision을 운영 성능으로 쓰지 않는다.
5. 피처를 삭제해도 다른 피처가 같은 정보를 대리할 수 있으므로, 단독 제거 하나만으로 편향이 완전히 사라졌다고 결론내리지 않는다.

판정
현재는 유효한 신호인지 데이터 특이적 단서인지 분리해서 확인해야 하는 최우선 피처다. 무조건 유지 또는 즉시 삭제를 확정할 근거는 부족하다.
성능 목표 P>=70%, R>=65%를 변경하지 않았다. 모델/임계값/원본 데이터도 변경하지 않았다.
