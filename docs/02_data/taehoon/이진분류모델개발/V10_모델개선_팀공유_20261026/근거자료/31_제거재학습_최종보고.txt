V10 후보 제거 후 실제 재학습 — 2026-10-26 UTC

검증된45종에서 후보를 하나씩 제거하고 실제 입력 차원과 모델을 다시 학습했다.
원래 모델 파일은 유지했다. 아래는 이번 새로운 기준 모델과의 비교다.
precision은 정상 표본 가중치 기반 추정치, recall은 해당 평가 기간 양성 전수 기준이다.
전체 모집단 인증 결과가 별도로 없으면 P70/R65 목표 달성으로 주장하지 않는다.

공통 조건
- HGB 학습 1,835,113건, GNN 학습 179,733건. 양성 94,309건은 공통 전수.
- 8/1~8/7은 보정과 관측 이력에만 사용. 학습은8/8~9/25, GNN 회차 선택9/26~10/4, 결합 학습10/5~10/8, 검증10/9~10/13.
- HGB300회/31잎, GNN 최대6회·monitor AP로 체크포인트 선택·미개선2회 조기 종료. 모든 후보는 같은 초기 가중치에서 해당 입력만 잘라 새 학습.
- 결합은 고정 설정의 로지스틱 회귀. 검증에서 P>=70% 조건의 최대 recall 임계값을 선택하고 테스트에는 고정 적용.
- 기존 45종 동결 모델과는 학습 시작일과 GNN 학습 일정이 다르므로 삭제 효과는 이번 baseline45와 비교.
- 동일 분 거래·주변 그래프·가중치·표본 목록은 유지. 피처 제거로 거래나 그래프 간선을 삭제하지 않음.
- 같은 입력을 가진 구성요소는 재사용. 예: ACH를 제거해도 GNN36은 원래 ACH 입력이 없으므로 이번 새 기준 GNN을 재사용.
- 정적 KYC 가용 시점은 여전히 미확인. 이 조건을 해결했다거나 모든 피처가 무조건 시점 인증됐다고 주장하지 않음.

검증·무결성
- 삭제된 피처가 HGB feature_names와 실제 GNN 입력/엣지/readout 차원에서 사라진 것을 검사.
- 새 신경망의 입력 차원 축소가 기존 초기 신경망의 해당 입력0 처리와 출력·기울기 수준에서 일치하는지 사전검사.
- 저장 모델 재로딩 후 점수 재현 및 원래 모델3개·그래프 샘플러 해시 보존 검사.
- 08_조건별_검증.csv에서 ACH/비ACH, 반복금액/새금액, ACH새금액 정상 대 무패턴을 구분. 그룹별 임계값 재조정 없음.
- 과거 테스트와 SAML-D는 이전에도 사용한 자료다. 새 독립 holdout으로 부르지 않음.
- SAML-D는 자체 유형을 사용하므로 HI의 무패턴 recall을 만들어 보고하지 않음.
- SAML-D에는 수취금액·HI KYC가 없어 기존 어댑터의 결측0 처리 제한이 남음.
