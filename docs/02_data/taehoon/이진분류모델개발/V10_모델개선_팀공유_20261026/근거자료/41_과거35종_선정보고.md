# 팀원 IG와 TGNN IG 비교 — 35개 입력 추천 후보

**선택 결과: 노드 19개 + 엣지 16개 = 35개.** 기존 40개 중 5개를 고정 상수로 처리하는 재학습 없는 입력 축소 후보입니다. 8개 저기여 그룹의 256개 조합 중, 전체 평균과 5일 각각에서 두 기준값 모두 성능 조건을 만족하는 가장 작은 구성을 선택했습니다.

**이 결과의 최적성 범위는 이번 탐색 공간과 검증 표본뿐입니다.** 통합 65개 전체의 전역 최적 조합이나 재학습 후 최적 구성을 입증한 것은 아닙니다. 운영 모델·원본 데이터·전처리 코드는 변경하지 않았습니다.

## 선택 기준과 실제 검사

- 같은 TGNN 가중치와 임계값을 고정했습니다. 검증 5일·5만 거래(양성 12,245건), 정상 점수 구간 층화·역확률 가중치를 재사용했습니다.
- 조건: AP 감소 ≤ 0.5%p; 고정 임계값 정밀도·재현율, 상위 1% 재현율, 미연결 양성 상위 1% 재현율 감소 각각 ≤ 1%p. 전체 합산 및 날짜별 모두 적용했습니다. 이는 이번 분석의 임시 기술 기준이며 업무상 합의된 허용 손실은 아닙니다.
- 기준값 두 가지: 0 / 학습 기간 2022-08-20 표본 중앙값. 계좌 유형 원핫 6개는 두 경우 모두 해당 학습 표본의 최빈 실제 유형 패턴으로 함께 고정했습니다.
- 우선 8개 축소안을 검사하고, 6개 저기여 피처 64개 조합, 마지막으로 8개 그룹 256개 조합을 검사했습니다. 앞선 검사가 최종 탐색에 포함될 수 있으므로 독립 실험 수로 더하지 않습니다.
- 최종 256개 조합 중 9개가 모든 날짜·두 기준값·전체 합산 조건을 통과했습니다. 최소 입력 수 동률은 최악 날짜의 AP 손실, 미연결 양성 상위 1% 재현율 손실 순으로 골랐습니다.
- 같은 검증 데이터로 반복 선택했습니다. 새 날짜의 독립 확인, 여러 모델 시드, 실제 운영 결과를 확인한 것은 아닙니다. 원래 점수 기준 층화 표본이므로 교란 후 새로 고득점이 되는 정상의 추정 불확실성은 남습니다.

## 팀원 피처와 무엇을 합쳤는가

- 팀원 31개와 우리 40개에는 명세상 공통 의미 6개가 있어 통합 후보 명세는 65개입니다. 이 6개는 우리 이름을 한 번만 사용합니다. 시간 간격은 단위·로그 변환이 달라 원시 시각에서 동일 계약으로 계산해야 합니다.
- 공통: `tb_pair_repeat → pair_prior_count`, `dt_pair_log → pair_gap_minutes`, `pair_cnt_1h → pair_count_1h`, `dt_src_log → sender_gap_minutes`, `dt_dst_log → receiver_gap_minutes`, `tb_self_loop → is_self_transfer`.
- `amt_z_pay_ccy`와 `paid_currency_z`는 목적이 비슷하지만 평균/표준편차 대 중앙값/IQR로 계산이 다릅니다. 같은 피처로 병합하지 않았으며 현재 학습된 `paid_currency_z`를 사용합니다.
- 통화 15열의 IG는 묶음 단위입니다. 대응표에 반복 표시된 그룹 기여도를 개별 열 기여도로 읽거나 15번 합산하면 안 됩니다.
- 팀원 고유 25개는 추가 보류입니다. 현재 TGNN이 학습하지 않은 입력이므로 IG만 보고 가중치를 붙여 넣을 수 없습니다. 원통화 금액, 통화 ID 15열, 누적 상대 수, 24시간 카운트는 별도 후보이며 현재 피처와 정확히 중복된다고 단정하지 않습니다.
- 계좌별 금액 z·휴면 급증 조합은 통화 혼합과 계산 정의 수정 이슈가 있습니다. 수정된 계좌·통화별 정의에 기존 팀원 MLP의 IG 값을 그대로 성능 근거로 옮기지 않습니다.
- 결제수단 피처 제외라는 기존 프로젝트 결정을 유지합니다. 원본 명세나 데이터를 삭제하지 않았습니다.

## IG 비교에서 지킨 한계

- 팀원 IG: 실제 팀원 모델이 아니라 31개 명세로 만든 별도 MLP, 5개 시드. 기존 테스트 기간 내부를 다시 학습·조기 종료·설명 구간으로 나눴습니다. 현재 TGNN과 같은 모델·기간이 아니며 독립 테스트 근거가 아닙니다.
- 우리 IG: 같은 TGNN의 검증 5일, 1,000건, 정상 참조 16개. 모델·기간·기준 입력·설명 단위가 달라 양쪽 raw logit 기여도를 합쳐 순위를 매기지 않았습니다. [65개 근거 대응표](comparison_65.csv)는 각 모델 안의 순위와 지표를 나란히 보관합니다.
- 우리 IG 16,000개 (거래, 참조) 중 515개가 수렴 기준 미달이었습니다. 참조 16개를 모두 통과한 거래만 재집계하면 그룹별 순위 상관 0.970~0.999, 상위 5개 겹침 4~5개였습니다. 이 검사는 남은 설명의 정확성이나 탈락 표본의 무작위성을 보장하지 않습니다.
- 자기이체·수취 집중도처럼 양성 IG가 낮아도 정상 거래의 오탐을 억제하는 피처를 보존했습니다. 미연결 양성에서 중요한 송신 집중도·소유자 다양성도 전체 양성 IG만으로 제외하지 않았습니다.
- `pair_history_count`와 `pair_prior_count`는 높은 상관이 있어도 정의가 다릅니다. 현재 가중치에서 하나를 상수화하면 큰 손실이 있어 둘 다 유지합니다. 둘을 합칠 수 있는지는 재학습 과제입니다.

## 더 작은 후보를 최종 추천에서 제외한 이유

- 26개 후보는 전체 합산 기준을 통과했지만 날짜별 검사에서 미연결 양성 상위 1% 재현율이 최대 약 6.7%p 하락했습니다. 따라서 [26개 후보](candidate26_schema.json)는 공격적 후속 후보로만 보관합니다.
- 25개는 합산 정밀도 기준을 통과하지 못했고, 20개 핵심 목록만 남기면 AP·재현율 손실이 커졌습니다. 저 IG 피처를 한 번에 삭제하는 방식이 안전하지 않다는 실제 검사 결과입니다.
