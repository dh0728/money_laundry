# V10 이진분류 모델 개선 흐름 보고서


**목표는 같은 고정 임계값에서 Precision ≥70%, Recall ≥65%를 달성임.**

실험흐름은 **그래프 구조 개선 → 무패턴 미탐 분석 → 정상·무패턴 전용 분류 → 전처리·지표 재검증 → 행동 피처 추가 → GNN·트리 결합 → 피처 축소 → FraudGT 비교 및 공식 방식 학습 → SALT-GNN 계획**으로 이어짐


## 지표를 읽는 기준

| 표기 | 의미 |
|---|---|
| P / R / F1 | 정밀도 / 양성 재현율 / 두 지표의 조화평균. 표의 값은 % |
| 무패턴 R | 무패턴 양성 중 탐지한 비율. 전체 R과 분모가 다름 |
| AP | 여러 임계값의 정밀도·재현율을 요약한 average precision. 이 문서는 0~1로 표기 |
| 전수 평가 | 정상·양성 전체를 채점한 결과 |
| P 추정 | 정상 표본을 역추출확률로 가중한 정밀도. 정상 전수 평가값이 아님 |
| 양성 전수 R | 해당 기간의 양성을 모두 평가한 재현율 |
| 조건부 P/R | 현재 FraudGT에서 실제 점수가 나온 거래만 대상으로 계산한 값 |
| coverage | 요청한 거래 중 실제 점수가 나온 비율 |

여기서 무패턴은 **이진 정답은 양성이지만 기존 8패턴 주석에 대응하지 않는 거래**를 뜻합니다. 따라서 정상 거래로 취급할 수 없으며, 관측 가능한 이상 행동이 전혀 없다는 의미도 아닙니다. 또 과거 실험에서 같은 테스트 기간을 여러 번 살펴봤기 때문에 이 문서에서는 ‘역사 테스트’라고 부릅니다. 처음 보는 독립 데이터에서 얻은 성능과는 구분해서 읽을 필요가 있습니다.

## 1. 초기 구조 개선: 이웃 확대 → Reverse MP → Ego → Port numbering

**실험 방법 및 계획**

처음에는 주변 거래의 구조를 더 잘 활용하는 데 초점을 맞췄습니다. V8·V9에서 구조를 비교한 뒤, V10에서는 패턴 분류 손실을 빼고 세탁 여부를 판단하는 이진 학습에 집중했습니다. 기본 입력은 계좌 19종과 거래 17종을 합한 36종입니다. 정상 거래는 군집별로 일부를 뽑고, 패턴·무패턴 양성은 모두 학습 대상으로 유지했습니다.

| 구조 변경 | 실제 동작 | 기대한 역할 |
|---|---|---|
| baseline10 | 최근 입금 이웃 최대 10개 | 좁은 문맥의 기준 모델 |
| 이웃 확대 | 입금·출금 방향별 최대 100개, 2홉 확장 | 좁은 표본에서 빠지는 주변 관계 관찰 |
| Reverse MP | 입금·출금 방향의 메시지를 구분해 계산 | 자금이 모이는 방향과 퍼지는 방향 구분 |
| Ego ID | 판정 거래 양끝 계좌에 표시 추가 | 주변 계좌 중 판정 대상의 위치 식별 |
| Port numbering | 수취 계좌별 송신 상대의 최초 관측 순번 부여 | 여러 상대와 병렬 거래의 구조 구분 보조 |

설정에서 말하는 **100은 계좌별로 선택하는 이웃 수의 상한**이고, 실제로 관계를 따라가는 깊이는 2홉입니다. baseline10에서 sampling으로 넘어갈 때는 이웃 수와 함께 방향, 선택 방식도 바뀌었습니다. Port는 그래프 안에서 거래 상대에 부여하는 순번으로, 통신 포트번호와는 다른 개념입니다. Ego·Port 같은 구조 표시는 기본 업무 피처 36종과 별도로 셉니다.

**기대효과**

금액만으로 구별하기 어려운 거래도 주변의 자금 관계를 함께 보면 탐지할 수 있을 것으로 기대했습니다. 이진 손실만 사용한 이유도 무패턴 양성을 세탁 거래로 직접 학습하는 데 집중하기 위해서였습니다.

**실험결과 지표**

seed42에서 저장된 V10의 **전체 검증 AP**를 기준으로 선택한 결과는 다음과 같습니다.

| 단계 | 선택 epoch | 전체 val AP |
|---|---:|---:|
| baseline10 | 19 | 0.619316 |
| sampling: 방향별 100개 | 19 | 0.611356 |
| + Reverse MP | 13 | 0.590831 |
| + Ego ID | 10 | **0.630229** |
| + Port numbering | — | V10 해당 단계 완료 결과 없음 |

실제 결과는 구조를 추가할 때마다 좋아지는 형태는 아니었습니다. 이웃 확대와 Reverse MP 단계에서는 AP가 낮아졌고, 당시 실험 예산 안에서는 **Ego·seed42·epoch10**을 선택했습니다. 다만 계획했던 모든 단계와 3시드 비교를 끝내지는 못했으므로, 이 결과만으로 각 구조의 효과를 확정하기는 어렵습니다.

Port는 앞서 진행한 V8 복합목적 모델에서 참고할 결과가 있습니다. 3시드 전체 검증 집계에서 Ego→Ports의 보조 이진 AP 평균은 **0.544032→0.565761**, 패턴 Macro-F1 평균은 **44.02→44.40%**로 올랐습니다. 반면 무패턴 이진 R 평균은 **2.96→1.78%**로 낮아졌습니다. 이 실험은 체크포인트도 패턴 Macro-F1으로 골랐기 때문에, V10 이진모델에서도 Port가 도움이 되는지는 별도 확인이 필요합니다.

**검증 근거**

단계별 학습 기록과 모델 선택 결과를 대조해, 테스트 성능을 보지 않고 전체 검증 AP로 모델을 골랐음을 확인했습니다. V10은 seed42에서 완료된 범위의 비교이며, Port의 참고 수치는 별도 V8 모델의 3시드 결과입니다. 따라서 두 모델의 결과를 같은 조건의 실험으로 해석하지 않았습니다.

## 2. 무패턴이 전체 모델 성능을 제한하는 정도 확인 — 10/16 기준선

**실험 방법 및 계획**

구조를 개선한 뒤에는 모델이 어떤 양성을 놓치는지 살펴봤습니다. 전체 양성을 패턴과 무패턴으로 나누어 미탐을 다시 집계하고, 무패턴을 제외했을 때의 높은 성능이 전체 거래에서도 유지되는지 확인했습니다.

**기대효과**

패턴 탐지율을 더 높이는 것만으로 R65에 도달할 수 있는지 확인하려 했습니다. 이 분석을 통해 이후 실험에서 무패턴 탐지에 얼마나 집중해야 할지 판단하고자 했습니다.

**실험결과 지표**

기존 V10으로 전체 테스트 33,429,507건을 평가한 결과는 **P81.74 / R55.63 / F1 66.20 / AP0.6221**이었고, 정상 거래의 오탐은 5,480건이었습니다.

| 양성 구분 | 테스트 건수 | 양성 내 비중 | 해당 집단 R |
|---|---:|---:|---:|
| 알려진 패턴 | 25,896 | 58.72% | **94.35%** |
| 무패턴 | 18,207 | 41.28% | **0.56%** |

전체 재현율은 `패턴 비중 × 패턴 R + 무패턴 비중 × 무패턴 R`로 계산됩니다. 이 테스트에서는 패턴을 전부 찾아도 무패턴을 하나도 못 잡으면 전체 R이 **58.72%**에 머뭅니다. R65에 도달하려면 패턴 R100%일 때도 무패턴 R이 **최소 15.22%**, 패턴 R99.5%라면 **최소 15.93%**는 필요합니다. 여기에 정밀도 조건까지 함께 맞춰야 하므로, 무패턴 탐지를 개선하는 일이 핵심 과제로 남았습니다.

초기에 이야기했던 패턴 약61%·무패턴 약39%는 기간에 따라 달라질 수 있어, 여기서는 위 테스트의 실제 거래 수를 기준으로 계산했습니다. 다만 이 표는 같은 모델의 집단별 성능을 비교한 것입니다. 무패턴을 학습에 넣거나 빼는 것 자체의 효과를 보려면, 두 모델을 같은 평가 대상에서 비교해야 합니다.

**검증 근거**

전체 테스트 33,429,507건의 정탐·오탐·미탐 건수로 P/R을 다시 계산했고, 보고된 값과 일치했습니다. 패턴 25,896건과 무패턴 18,207건을 모두 양성에 포함했으므로, 무패턴을 빼서 성능이 높아진 평가가 아닙니다. 다만 당시 입력은 구간 종료까지의 거래를 사용했기 때문에 일마감 운영 성능과는 구분했습니다.

## 3. 정상과 비슷한 무패턴 및 실제 이웃 손실 분석 — 10/19~23

**실험 방법 및 계획**

무패턴을 더 잘 찾으려면 정상과 어떤 점이 다른지부터 알아야 했습니다. 계좌 연결, 시간순 자금 흐름, 소유주 관계를 살펴보고, 결제방식·통화·주차가 같으면서 금액과 활동량도 비슷한 정상 거래를 찾아 비교했습니다. 화면에 표시한 양성 중심 그래프가 실제 GNN 입력과 얼마나 다른지도 함께 확인했습니다.

**기대효과**

주변에 단서가 있어도 샘플러가 놓치는지, 아니면 모델이 보는 특징 자체가 정상과 비슷한지를 구분하려 했습니다. 이 과정에서 찾은 금액의 새로움, 활동 변화, 소유주의 외부 자금 흐름을 피처 후보로 연결하고자 했습니다.

**실험결과 지표**

- 전체 관찰 무패턴 82,260건 중 다른 무패턴과 계좌를 공유한 거래는 **60.24%**였습니다. 다만 24시간 안에 시간과 방향이 이어지는 3계좌 이상 연결에 참여한 비율은 **1.27%**였습니다. 계좌를 공유한다는 사실만으로 같은 돈이 연속해서 이동했다고 보기는 어려웠습니다.
- 주요 송신 계좌 15개에서 선택된 테스트 출금 이웃 1,500건을 보면, 무패턴은 **1건**, 정상은 **1,499건**이었습니다. 전체 무패턴 출금이 8,331건인 계좌에서도 고정 이웃 100개에는 무패턴이 0건이었습니다.
- 같은 15개 허브의 무패턴 22,979건과 정상 출금 16,199,387건을 비교한 진단 분류기의 AUC는 **약0.53**이었습니다. 이 허브 집단에서는 관측한 특징만으로 두 집단을 구별하기가 쉽지 않았습니다.
- 학습 무패턴마다 비슷한 정상을 최대5개씩 찾았을 때, 무패턴의 **99.81%**에서 비교할 정상을 찾을 수 있었습니다. 미탐 무패턴의 소유주 거래 공백이 대응 정상보다 긴 비율은 학습 앞/뒤 구간에서 **63.5% / 62.5%**였습니다.

이 결과를 보면 무패턴에도 주변 연결은 있지만, 그 연결이 실제 입력에 충분히 들어오지 않거나 정상 거래와 모습이 겹치는 경우가 있습니다. 따라서 이웃 수를 늘리는 실험과 함께, 허브에서 드문 양성 신호를 어떻게 보존하고 정상과 구별할지도 살펴볼 필요가 있었습니다.

**검증 근거**

무패턴 전체의 연결 집계와 주요 송신 계좌 15개의 실제 이웃 캐시를 대조하고, 결제방식·통화·주차를 맞춘 유사 정상 거래와 행동 차이를 비교했습니다. 정답 라벨은 분석과 결과 확인에만 사용했으며, 양성 이웃을 골라 모델에 넣지는 않았습니다. 15개 계좌에서 확인한 이웃 손실을 전체 거래의 손실률로 일반화할 수는 없습니다.

## 4. 정상 대 무패턴 전용 이진분류와 어려운 정상 재학습 — 10/20~23

**실험 방법 및 계획**

이어서 **정상과 무패턴 양성만으로 학습하는 HGB**를 시험했습니다. 패턴 양성은 정상으로 바꾸지 않고 감독학습 대상에서만 제외했습니다. 과거 시간창, 금액 반복·밀도, 소유주 행동, 동일 분 집중도를 추가하고, XAI와 제거 실험으로 입력을 줄였습니다. 후속 캐스케이드에서는 1단계 모델이 헷갈린 정상을 2단계에 다시 학습시켰습니다. 입금 거래의 예측 의심 점수를 모은 연쇄 피처와 정상 표본 가중치 조정도 별도로 비교했습니다.

**기대효과**

상대적으로 잘 잡히는 패턴 양성보다 정상과 무패턴의 경계에 학습을 집중하면 도움이 될 것으로 봤습니다. 특히 비슷한 정상 거래와 비교했을 때 남는 차이를 찾아, 무패턴 탐지를 늘리면서 오탐도 줄이는 것이 목적이었습니다.

**실험결과 지표**

아래 P는 **패턴 양성을 제외하고, 정상 모집단 비율에 맞춰 보정한 추정치**입니다. 전체 이진모델의 P70 목표와는 평가 대상이 다르므로 수치를 직접 비교할 때 주의가 필요합니다.

| 실험 | 평가·운영점 | 무패턴 R | P 추정 | 실제 정상 FPR |
|---|---|---:|---:|---:|
| 시간 피처74개 추가 전 기준 트리 | 검증 FPR≤0.1%에서 고정, test | 15.32% | 7.57% | 0.1020% |
| 계좌 시간 피처 추가 | 위와 같은 선택 규칙, test | 14.08% | 6.88% | 0.1040% |
| 차이 중심 피처·점수 결합 | 검증 FPR≤0.15%에서 고정, test | 21.08% | 7.49% | 0.1420% |
| 기존 V10 비교용 임계값 | 동일 거래·검증 FPR≤0.15%, test | 18.34% | 5.63% | 0.1676% |
| 무패턴 전용 HGB218 | 바로 위 V10과 동일 평가 대상, test | **25.35%** | 8.92% | 0.1412% |

**검증 근거**

수정 GNN 입력은 HI 2,944건과 SAML-D 64건에서 기존 전처리 결과와 일치했고, 결합 모델의 18개 평가 결과도 저장 점수로 지표와 혼동행렬을 다시 계산했을 때 일치했습니다. 축소 모델은 실제 입력·파라미터를 줄여 재학습했으며, 학습·선택·평가 간 타깃 ID 중복이 없고 제거한 열이 모델 입력에 남지 않음을 확인했습니다. 다만 최대 6epoch의 제한된 학습이므로 GNN 구조 전체의 성능 한계로 보기는 어렵습니다.

## 11. 결제방식을 다시 넣고 V10·FraudGT 구조 비교 — 10/26

**실험 방법 및 계획**

다음 비교에서는 결제방식을 다시 넣고 V10과 FraudGT를 살펴봤습니다. **GNN 입력은 계좌19+거래수치14+결제방식1=34종**이며, 기존 HGB22와 결합하면 합집합42종입니다. 결제방식은 학습 범주7개와 Unknown을 더한8열 원핫으로 표현해 판정 대상과 주변 거래에 모두 적용했습니다. V10, FraudGT, PE-FraudGT, Multi-FraudGT는 같은 V10 실험 예산 안에서 비교했습니다.

**기대효과**

거래 엣지 정보를 활용하는 FraudGT가 기존 V10을 보완할 수 있는지, Port와 방향 구분이 추가로 도움이 되는지 확인하려 했습니다. 결제방식 복원의 이득뿐 아니라 ACH에 대한 의존도도 함께 살펴보는 비교였습니다.

**실험결과 지표**

아래는 **초기 통제 비교**에서 얻은 역사 테스트 결과입니다. 당시에는 양성 가중치300, 최대6epoch, 논리 배치512, 일마감 개별 그래프와 방향별 cap100을 사용했습니다. **V10 조건 안에서 구조를 비교한 결과**이므로, 논문 공식 학습 조건의 성능과는 구분해서 봐야 합니다.

| 구조 | GNN 단독 P 추정 / R / 무패턴 R | HGB와 결합 P 추정 / R / 무패턴 R |
|---|---|---|
| V10+결제방식 | 75.06 / 54.68 / 1.91% | 71.15 / 61.60 / 8.11% |
| FraudGT+결제방식 | 72.78 / 56.68 / 2.12% | 63.61 / 63.51 / 12.40% |
| PE-FraudGT+결제방식 | 68.39 / 57.32 / 2.35% | 63.92 / 63.03 / 11.12% |
| Multi-FraudGT+결제방식 | 78.68 / 41.89 / 1.17% | 52.74 / 63.35 / 12.37% |

FraudGT 결합의 무패턴 R은 기준41종의10.40%보다 높았지만 P는 낮아졌고, 모든 후보가 목표에 미치지 못했습니다. 이후 공식 설정을 다시 검토하면서 양성 가중치300, 배치, 이웃 선택, 그래프 공유 범위, 검증 방식의 차이를 확인했습니다. 이 차이를 반영한 실험이 다음 단계입니다.

**검증 근거**

네 구조를 같은 학습 예산과 평가 거래로 비교했고, 각 모델과 임계값은 검증에서 정한 뒤 테스트에서 유지했습니다. 양성은 모두 평가하고 정상 표본은 모집단 비율로 보정했지만, 목표를 통과한 후보가 없어 정밀도 전수 인증은 진행하지 않았습니다. 양성 가중치300·최대6epoch를 사용한 초기 비교이므로 다음 단계의 공식 조건 실험과는 구분했습니다.

## 12. 현재 실험: V10 입력 + FraudGT 공식 방식의 공유그래프 — 10/27~진행 중

**실험 방법 및 계획**

공식 소스 버전을 고정한 뒤 이웃 선택, 배치 구성, head, 검증 주기를 맞췄습니다. 개별 그래프 실습형은 비교용으로 남겨 두었지만, 메모리가 부족해 체크포인트를 보존하고 중단했습니다. 현재는 공유그래프 실험을 먼저 진행하고 있습니다.

| 항목 | 현재 고정 조건 |
|---|---|
| 비교 순서 | `fraudgt_format` → `pe_fraudgt_format` → `multi_fraudgt_format` |
| 입력 | V10 계좌19종+거래수치14종+결제방식1종=34종. 결제방식8열 원핫; 기본 엣지22열 |
| 이웃 선택 | 실제 PyG `LinkNeighborLoader`, **2홉 fanout [50,50]**, 비복원 균등 무작위 |
| 공유 범위 | 타깃2,048건의 한 loader 배치 안에서 그래프 공유 |
| 관계·구조 표시 | 기본/PE는 정방향, Multi는 정·역방향. PE의 Port, Multi의 Port·Ego는 별도 구조 입력 |
| 학습량 | epoch당 요청2,048×256=524,288건, 8개 배치 평균 손실 누적 후 업데이트 |
| 손실·최적화 | 양성 가중치 **6**; 기존300 제거. AdamW lr0.001, weight decay1e−5, warmup5, cosine, clip1 |
| 기간 | train8/1~9/25, val9/26~10/13, test10/14~10/31 |
| epoch·선택 | 후보별 최대500epoch, epoch1 및4의 배수에서 검증, 0.5 임계값 val F1으로 선택 |
| 검증 표본 | 전체 val에서 균등 순열의 최대524,288건. 양성 전수·IPW 표본 방식 아님 |
| 그래프 시간 범위 | 각 분할 종료까지의 누적 문맥. 거래별 일마감 제한 없음 |

이 단계에서는 일마감은 시연에 적용하고, 학습 비교는 논문 방식을 따르기로 조건을 정리했습니다. 이에 따라 **현재 그래프 정책은 10/24~26의 일마감 실험과 다릅니다.** 같은 분의 이웃이나 판정 대상 엣지를 강제로 추가하지도 않습니다. 일마감 운영에 사용할 때의 시간 기준과 누수 여부는 별도로 확인해야 합니다.

**기대효과**

배치 안에서 주변 그래프를 공유하면 같은 거래를 반복 계산하는 비용을 줄일 수 있을 것으로 기대했습니다. 또 이웃을 매번 무작위로 선택하면 고정 표본에서 놓쳤던 관계를 학습 중에 더 관찰할 수 있습니다. 공식 조건에 가깝게 학습한 결과를 확보하되, 실제 속도와 탐지 성능이 각각 얼마나 달라지는지 확인하려는 실험입니다.

**실험결과 지표 — 중간 결과**

23:28 UTC 확인 시점에는 기본 `fraudgt_format`이 **311epoch를 마치고 312epoch를 검증 중**이었습니다. 현재 공식 조건에서 PE·Multi의 완료 결과는 아직 없습니다. 아래는 **실제로 점수가 나온 검증 거래만 대상으로 계산한 중간 성능**입니다.

| 저장된 검증 | val loss | P | R | F1 | AP | 무패턴 R | coverage | 요청 양성 기준 R 하한 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 최고 val F1: epoch280 | 0.01592 | 91.85% | 62.00% | 74.03% | 0.70836 | 0.00% | 33.65% | 39.18% |
| 최근 완료: epoch308 | 0.01921 | 82.37% | 55.85% | 66.57% | 0.64329 | 0.00% | 33.60% | 34.38% |

이 수치를 읽을 때는 채점된 범위를 함께 봐야 합니다. epoch280에서는 요청524,288건 중176,419건에 점수가 나왔고, 요청 양성 중233건은 채점되지 않았습니다. 표의 R62%는 채점된 양성400건 중248건을 찾았다는 뜻입니다. 요청 양성633건 전체를 기준으로 미채점 양성을 미탐으로 처리하면248/633=39.18%가 됩니다. 따라서 **조건부 P91.85%만으로 전체 거래에서 목표를 달성했다고 보기는 어렵습니다.** 무패턴 R0%도 해당 epoch에 채점된 무패턴 표본의 결과이며, 전체 무패턴을 평가한 값은 아닙니다.

개별 그래프 비교는5epoch를 마친 뒤 중단했기 때문에 두 방식의 최종 우열은 아직 판단하기 어렵습니다. 현재 학습 중인 모델도 최종 테스트 결과를 기다려야 합니다.

**검증 근거**

고정한 공식 소스와 실제 이웃 선택·판정 출력·기울기를 대조했으며, 공식 클래스와의 최대 출력 차이는 약3.58e−7이었습니다. 미채점 타깃을 별도로 집계해 지표의 평가 범위를 확인했고, 중단 시 모델·옵티마이저·진행 위치를 보존해 학습 재개를 검증했습니다. 다만 V10 피처와 KYC, 단일시드·자원 제한 등의 차이가 남으며, 이 검증은 구현의 일치 여부를 확인한 것으로 최종 테스트 성능이나 일마감 운영 적합성을 보장하지는 않습니다.

## 13. 후속 계획: SALT-GNN으로 통계 정보와 Attention을 층마다 결합

**실험 방법 및 계획**

SALT-GNN은 각 메시지 전달 층에서 **평균·표준편차·최솟값·최댓값과 degree 보정의 통계 경로**를 **Attention 경로**와 결합합니다. 트리와 GNN의 마지막 점수를 합치는 현재 결합과 달리, 결합된 표현이 다음 층의 입력이 됩니다. SALT-Trans와 SALT-GAT 변형이 있습니다. [SALT-GNN 원논문 §3](https://arxiv.org/html/2607.10131v1#S3)

다음 단계에서는 아래 순서로 SALT-GNN을 비교할 계획입니다. 현재는 계획 단계로, 프로젝트에서 구현·학습·성능 검증을 마친 결과는 아직 없습니다.

1. 먼저 현재 FraudGT에서 요청한 거래와 실제 채점된 거래의 차이를 정리합니다. 공식 head의 조건부 결과와 모든 요청 타깃을 평가하는 조건을 나누어 비교할 수 있도록 합니다.
2. 같은 V10 입력·분할·표본·손실·학습 예산에서 **Attention 단독 → 통계 단독 → 마지막 층 결합 → 층별 결합**을 비교합니다. 첫 비교에서는 새 업무 피처를 추가하지 않고 구조의 차이를 살펴봅니다.
3. 먼저 fanout[50,50]을 유지해 집계 구조의 효과를 확인합니다. 이후 이웃 상한 확대와 동일 분/최근 이웃 보존을 별도 비교해, 어떤 변경이 도움이 됐는지 구분합니다.
4. 전체 P/R과 함께 무패턴, ACH/비ACH, 새 금액/반복 금액, 수취 계좌 degree 구간별 성능을 기록합니다. coverage, 메모리 사용량, epoch 시간도 함께 확인합니다.
5. 유망 후보는 여러 seed와 별도 기간에서 다시 확인합니다. 검증에서 정한 임계값을 유지한 전수 평가로 P70/R65 달성 여부를 판단하고, 일마감 시연용 문맥도 별도로 검증합니다.

**기대효과**

우리 데이터처럼 정상 이웃이 많은 허브에서는 Attention 평균만으로 금액 분포나 거래량의 작은 차이가 약해질 수 있습니다. 통계 경로가 이 부분을 보완하고, 층마다 결합한 정보가 다음 홉으로 이어진다면 1홉에서 약하게 보였던 행동 차이를 더 잘 활용할 수 있을 것으로 기대합니다.

다만 **샘플에서 빠진 거래까지 집계 방식만으로 복원할 수는 없습니다.** degree를 선택된 이웃 수로 계산할지, 허용된 문맥의 실제 연결 수로 계산할지도 정해야 합니다. 정상과 무패턴의 관측 차이가 작은 문제나 KYC·반복 금액 규칙에 대한 의존성 역시 별도로 살펴볼 과제입니다.

**실험결과 지표**

프로젝트에서는 **아직 실험하지 않았습니다.** 아래 논문 결과는 이 방향을 검토하는 참고 근거이며, V10에서도 같은 성능이 나올 것이라는 예상치는 아닙니다.

| 논문 벤치마크 | 비교 | 양성 F1 평균±표준편차 |
|---|---|---|
| HI-Small, 5 seeds | FraudGT / SALT-Trans | 67.9±1.8% / 71.6±1.8% |
| HI-Medium, 3 seeds | TransConv84k / SALT-Trans | 68.2±0.4% / 70.5±0.4% |

논문은 HI-Small에서 FraudGT 대비 F1 차이가 통계적으로 유의하지 않다고 설명합니다. 또한 우리 프로젝트의 ‘무패턴’ 집단에 대한 R 개선이나 P70/R65 달성을 증명한 연구는 아닙니다. [원논문 표2·3 및 검정 설명](https://arxiv.org/html/2607.10131v1#S5)

**검증 근거·완료 판정 계획**

현재 근거는 논문의 구조 비교와 수취 계좌 연결 수별 평가 결과이며, 프로젝트 자체 실험 결과는 아직 없습니다. 같은 입력에서 구조만 바꾼 비교, 라벨·미래 거래 변경 검사, 전체 타깃 채점 여부와 여러 시드의 결과를 확인할 계획입니다. 검증에서 고정한 임계값으로 P70/R65와 무패턴 탐지를 함께 확인한 뒤 채택 여부를 결정하겠습니다.

## 결과 기록의 유지 방식

이 문서는 실험마다 어떤 판단을 했고 다음 단계로 어떻게 이어졌는지를 중심으로 정리했습니다. 각 단계의 검증 근거는 당시 실험 기록과 원본 결과를 읽고, 확인한 방법·결과·남은 한계를 짧게 요약한 내용입니다. 이후 결과도 **방법/조건 → 기대효과 → 실제 지표 → 검증 근거** 순서로 이어서 기록하고, 기존 기준선과 실패 결과, 평가 대상 수는 함께 남길 예정입니다.

앞으로는 **정상과 무패턴을 구별할 신호를 더 찾는 일**, **요청한 전체 거래를 빠짐없이 평가하는 일**, **다른 데이터와 새로운 기간에서도 성능이 유지되는지 확인하는 일**이 남아 있습니다. SALT-GNN은 이 가운데 이웃 정보를 모으는 방식을 개선할 수 있을지 살펴볼 후보입니다. 실제 목표 달성에 도움이 되는지는 후속 실험으로 확인하겠습니다.
