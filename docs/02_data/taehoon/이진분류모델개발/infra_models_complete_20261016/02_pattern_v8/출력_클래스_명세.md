# 출력 클래스와 번호 명세

## 이진모델 v10

| 클래스 | 의미 |
|---:|---|
| 0 | 정상 거래 |
| 1 (양성) | 자금세탁 거래 — 알려진 패턴과 무패턴 모두 포함 |

`risk_score >= 0.4338742792606354`이면 `alert=true`입니다. risk_score는 모델 위험 점수이며 완전히 보정된 실제 발생 확률을 보장하지 않습니다.

## 패턴모델 v8 — 배포 API 번호

| 번호 | 이름 | 의미 |
|---:|---|---|
| 0 | NORMAL | 정상 거래 또는 알려진 8패턴에 속하지 않는 무패턴 자금세탁 |
| 1 | FAN-OUT | 한 계좌에서 여러 계좌로 분산 |
| 2 | FAN-IN | 여러 계좌에서 한 계좌로 집결 |
| 3 | G-SCATTER | 여러 계좌에서 중심 계좌로 모은 뒤 여러 계좌로 분산 |
| 4 | S-GATHER | 출발 계좌에서 여러 중간 계좌로 분산한 뒤 도착 계좌로 집결 |
| 5 | CYCLE | 여러 거래를 거쳐 출발 계좌로 돌아오는 순환 |
| 6 | RANDOM | 데이터 생성기의 무작위 이동 패턴 라벨 |
| 7 | BIPARTITE | 송신 계좌 집단에서 별도 수신 계좌 집단으로 이동 |
| 8 | STACK | 여러 계좌 층을 순차적으로 이동 |

패턴은 위 순서의 확률 중 argmax로 결정합니다. 출력 JSON에는 pattern_class 이름과 pattern_scores가 있습니다. 번호가 필요하면 위 고정 순서로 변환합니다.

**패턴 0은 이진 정상과 다릅니다.** 무패턴 자금세탁이 포함되므로 이진 알림 여부는 v10 출력으로 판단합니다. v8에도 보조 risk_score와 alert가 있지만 v10의 출력과 별개이며, v8 보조 임계값은 0.4057740867137909입니다.

내부 학습용 원시 라벨 번호는 배포 번호와 다릅니다. 원시 번호 0~9의 배포 번호 매핑은 `[0,7,5,2,1,3,6,4,8,0]`입니다. machine-readable 명세는 각 모델 폴더의 `assets/output_contract.json`을 참고하세요.

이 문서와 가중치는 기존 무패턴 포함 학습 v8/v10 기준입니다. 진행 중인 구조 정제 재학습 모델의 임계값·보정값으로 혼용하지 마세요.
