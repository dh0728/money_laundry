# 인프라 전달 모델 성능표 — v10 이진분류 · v8 패턴분류

작성일: 2026-10-16. 아래 수치는 전달한 **무패턴 포함 학습 모델**의 저장된 전체 테스트 결과입니다. 무패턴 제외 재학습 모델의 결과가 아닙니다. 새로 학습하거나 임계값을 변경하지 않았습니다.

## 1. 모델 파일과 역할

| 항목 | 이진분류 v10 | 패턴분류 v8 |
|---|---|---|
| 가중치 | [binary.pt](01_binary_v10/models/binary.pt) | [nine_class.pt](02_pattern_v8/models/nine_class.pt) |
| 선택 모델 | ego_seed42 · epoch 10 | ego_100/seed_1 · epoch 20 |
| 주 역할 | 정상 / 자금세탁 판정 | NORMAL + 8가지 패턴 분류 |
| 부가 출력 | — | 독립된 보조 이진 위험 점수 |
| 이진 판정 임계값 | 0.4338742792606354 | 0.4057740867137909 |
| 선택 기준 | 전체 검증 binary AP | 전체 검증 9클래스 Macro F1 |

가중치는 state_dict와 추론 설정을 담은 체크포인트입니다. `.pt` 파일만으로 실행하는 TorchScript 모델이 아닙니다. 함께 전달한 [v10 노트북](01_binary_v10/01_binary_v10.ipynb), [v8 노트북](02_pattern_v8/02_pattern_v8.ipynb)의 모델 정의와 고정 피처·보정 파일이 필요합니다.

## 2. 평가 조건

- 학습: 2022-08-01~09-25 / 검증: 09-26~10-13 / 테스트: 10-14~10-31.
- 테스트 채점 대상: **33,429,507건** = 정상 33,385,404건 + 알려진 패턴 자금세탁 25,896건 + 무패턴 자금세탁 18,207건.
- 그래프 문맥: train + val + test 누적, 테스트 종료일까지. 채점 대상은 테스트 구간 거래만.
- 날짜별 거래 직전 정보만 사용하는 실시간 평가가 아니라 구간 종료 시점 누적 스냅샷 평가.
- 노드 19개 + 거래 17개 피처, ego 표시 추가, 2층 TransformerConv, 양방향 메시지 전달, 2홉 샘플링.
- 계좌별 입금·출금 각각 최대 100개, 샘플링 seed 42. 모델 학습 seed와 구분.
- 임계값은 검증에서 정하고 테스트에는 고정 적용. v10은 전체 실험 계획을 모두 완료하기 전 예산 제한으로 종료한 후보군에서 선택된 모델.

## 3. 동일 테스트에서의 이진 탐지 성능

v8 열은 **패턴 분류 성능이 아니라 v8 보조 위험 출력의 성능**입니다. 최종 이진 알림은 v10 출력과 구분해야 합니다.

| 지표 | v10 이진모델 | v8 보조 이진 출력 |
|---|---:|---:|
| AP | 62.21% | 58.98% |
| Precision | 81.74% | 74.80% |
| Recall | 55.63% | 52.24% |
| F1 | 66.20% | 61.51% |
| FPR | 0.01641% | 0.02325% |

| 구분 | v10 | v8 보조 이진 출력 |
|---|---:|---:|
| TN | 33,379,924 | 33,377,642 |
| FP | 5,480 | 7,762 |
| FN | 19,569 | 21,065 |
| TP | 24,534 | 23,038 |

v8의 Precision·F1·FPR은 저장된 risk_confusion([[TN, FP], [FN, TP]])으로 계산했습니다. AP는 Average Precision이며 임계값 한 점의 지표가 아닙니다. FPR은 정상 거래 중 오탐 비율입니다.

## 4. 패턴 분류 성능 — v8

이진 위험 점수로 차단하기 전 패턴 head의 argmax 결과입니다.

| 지표 | 값 |
|---|---:|
| 9클래스 Macro F1 | 43.81% |
| 알려진 8패턴 Macro F1 | 36.79% |

| 패턴 | Precision | Recall | F1 | 테스트 건수 |
|---|---:|---:|---:|---:|
| NORMAL | 99.97% | 99.99% | 99.98% | 33,403,611 |
| FAN-OUT | 60.49% | 39.53% | 47.82% | 2,699 |
| FAN-IN | 54.64% | 31.88% | 40.27% | 2,456 |
| G-SCATTER | 55.76% | 53.39% | 54.55% | 4,907 |
| S-GATHER | 58.63% | 57.39% | 58.00% | 5,013 |
| CYCLE | 35.69% | 28.93% | 31.95% | 2,375 |
| RANDOM | 22.22% | 9.35% | 13.16% | 1,733 |
| BIPARTITE | 39.36% | 10.64% | 16.75% | 2,312 |
| STACK | 43.89% | 24.97% | 31.83% | 4,401 |

**v8의 NORMAL은 정상 거래뿐 아니라 무패턴 자금세탁도 포함하는 클래스입니다.** 따라서 패턴 NORMAL 예측을 이진 정상 판정으로 대체하면 안 됩니다. NORMAL support는 33,403,611건입니다. G-SCATTER는 GATHER-SCATTER, S-GATHER는 SCATTER-GATHER입니다.

## 5. v10의 패턴별 이상거래 탐지 재현율

아래는 패턴 이름을 맞힌 비율이 아니라, 해당 패턴 거래를 **자금세탁으로 탐지한 비율**입니다.

| 실제 패턴 | 탐지 재현율 | 테스트 건수 |

| BIPARTITE | 89.32% | 2,312 |
| CYCLE | 92.76% | 2,375 |
| FAN-IN | 94.30% | 2,456 |
| FAN-OUT | 98.04% | 2,699 |
| G-SCATTER | 96.72% | 4,907 |
| RANDOM | 92.90% | 1,733 |
| S-GATHER | 96.99% | 5,013 |

알려진 패턴 합계 탐지 재현율: **94.35%**. 무패턴 탐지 재현율은 v10 **0.56%**, v8 보조 위험 출력 **1.77%**입니다. 전체 성능에는 이 어려운 무패턴 거래도 포함돼 있습니다.

## 6. 전달 검증과 근거

- 전달 가중치의 모든 state_dict 텐서가 원본과 동일함을 확인했습니다(v10 43개, v8 49개).
- 두 노트북을 각각 독립된 임시 폴더에서 전체 실행했습니다.
- 모델별 원본 기준 그래프 2건의 예측을 절대 오차 2e-5 이내로 재현했습니다.
- 모델별 합성 입력의 전처리부터 18건 JSON 응답 생성까지 검증했습니다. 합성 예제는 성능 측정 데이터가 아닙니다.
- CPU 실행 검증이며 새 환경에서의 전체 pip 재설치·서버 부하 시험은 수행하지 않았습니다.
