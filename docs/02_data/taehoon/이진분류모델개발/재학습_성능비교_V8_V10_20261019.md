## 실험 및 비교 조건

- 패턴 구조 불일치·퇴화 블록을 제외하고 V8과 V10을 재학습했다. 시간 조건만 미충족한 블록, 정상 거래, 무패턴(UNMATCHED) 거래는 유지했다.
- 기존 모델과 재학습 모델을 동일한 테스트 거래 33,428,088건으로 비교했다.
- 기존 모델은 기존 전체 문맥을, 재학습 모델은 구조 불일치 블록을 제거한 문맥을 사용했다. 따라서 학습 데이터와 입력 문맥 변경이 함께 반영된 비교다.
- 임계값은 각 모델의 검증 데이터에서 각각 결정하고 테스트에서는 고정했다.
- 선택된 epoch: V8 20, V10 15.

## 해석 및 전달본 상태

- V10의 AP·F1이 개선됐으며 정상 거래 오탐은 5,480건에서 4,459건으로 감소했다.
- V8의 전체 Macro F1은 개선됐지만 모든 패턴이 개선된 것은 아니다.
- CYCLE 패턴 재현율은 28.94%에서 29.40%로 소폭 상승했으나 F1은 0.323370에서 0.321363으로 소폭 하락했다. 구조 불일치 블록 제거만으로 CYCLE 분류 문제가 해결됐다고 볼 수 없다.
- 기존 `infra_models_complete_20261016` 폴더와 ZIP은 재학습 전 모델 전달본이다. 이 결과 기록은 모델 전달본 교체를 의미하지 않는다.
