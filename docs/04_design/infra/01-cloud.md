## 클라우드란?

클라우드는 서버, 저장 공간, 데이터베이스와 네트워크 같은 컴퓨팅 자원을 인터넷을 통해 빌려 쓰는 방식이다. 물리 장비를 직접 구매하고 설치하는 대신 필요한 자원을 생성하고 사용량에 따라 비용을 지불한다.

클라우드를 사용한다고 애플리케이션 운영이 모두 자동화되는 것은 아니다. 사용하는 서비스 유형에 따라 운영체제 패치, 보안, 백업, 장애 복구와 비용 관리는 여전히 사용자가 담당한다.

## 기본 용어

- **리전(Region)**: 클라우드 사업자가 서비스를 제공하는 지리적 지역
- **가용 영역(Availability Zone)**: 한 리전 안에서 물리적으로 분리된 데이터센터 묶음
- **IaaS**: 서버와 네트워크 같은 기반 자원을 빌리고 운영체제 이상을 사용자가 관리하는 방식
- **PaaS**: 애플리케이션 실행 플랫폼 일부를 사업자가 관리하는 방식
- **SaaS**: 완성된 소프트웨어를 서비스 형태로 사용하는 방식
- **관리형 서비스**: 설치, 패치, 백업이나 확장 중 일부를 클라우드 사업자가 대신 관리하는 서비스
- **온프레미스**: 조직이 직접 소유하거나 통제하는 장소에서 서버를 운영하는 방식

## 클라우드 종속성이 생기는 이유

가상 머신, 컨테이너와 표준 SQL처럼 여러 환경에서 제공되는 기능은 비교적 옮기기 쉽다. 반대로 특정 클라우드만의 API, 권한 모델, 이벤트 형식과 관리형 서비스에 애플리케이션이 직접 연결되면 이전할 때 코드와 운영 절차를 변경해야 한다.

클라우드 이동성은 사업자 이름보다 실제로 어떤 기능을 어느 정도 사용했는지에 더 크게 영향을 받는다.

## 주요 클라우드 서비스

### AWS(Amazon Web Services)

Amazon이 제공하는 퍼블릭 클라우드다. 가상 서버인 EC2, 객체 스토리지인 S3, 관리형 데이터베이스인 RDS 등 여러 인프라 서비스를 리전 단위로 제공한다. 각 자원의 접근 권한은 주로 IAM이라는 권한 시스템으로 관리한다.

### NCP(NAVER Cloud Platform)

NAVER Cloud가 제공하는 퍼블릭 클라우드다. 가상 서버, 스토리지, 데이터베이스와 네트워크 서비스를 제공하며 한국 리전과 국내 기업 환경을 위한 상품 및 지원 체계를 갖추고 있다.

### GCP(Google Cloud Platform)

Google이 제공하는 퍼블릭 클라우드다. Compute Engine 가상 서버, Cloud Storage 객체 스토리지, 관리형 데이터베이스와 데이터·AI 관련 서비스를 제공한다.

### Microsoft Azure

Microsoft가 제공하는 퍼블릭 클라우드다. Azure Virtual Machines, Blob Storage와 관리형 데이터베이스 등을 제공하며 Microsoft의 개발·기업용 제품 생태계와 연결된다.
