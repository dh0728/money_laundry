## 데이터베이스란?

데이터베이스(DB)는 애플리케이션 데이터를 구조적으로 저장하고 안전하게 조회·변경하는 시스템이다. 사용자, 거래, 권한과 작업 상태처럼 서버가 재시작되어도 유지해야 하는 정보를 보관한다.

## 관계형 데이터베이스

관계형 DB는 데이터를 행과 열로 구성된 테이블에 저장한다. 테이블 사이의 관계, 제약조건과 SQL을 이용해 데이터를 다룬다.

- **Primary key**: 한 행을 고유하게 구분하는 값
- **Foreign key**: 다른 테이블 행과의 관계를 표현하는 값
- **Constraint**: 잘못된 데이터 저장을 막는 규칙
- **Join**: 여러 테이블의 관련 데이터를 하나의 결과로 조회하는 연산
- **Schema**: 테이블, 열, 타입과 관계의 구조

## 문서형 데이터베이스

문서형 DB는 JSON과 비슷한 문서 단위로 데이터를 저장한다. 하나의 문서 안에 중첩 구조를 자연스럽게 표현하고 문서별 구조를 유연하게 바꿀 수 있다. 관계와 일관성을 어느 계층에서 책임질지는 별도로 설계해야 한다.

## 트랜잭션과 ACID

트랜잭션은 여러 데이터 작업을 하나의 논리적 단위로 처리한다.

- **Atomicity**: 모두 성공하거나 모두 취소된다.
- **Consistency**: 정해진 데이터 규칙을 유지한다.
- **Isolation**: 동시에 실행되는 작업이 서로 잘못 간섭하지 않는다.
- **Durability**: 완료된 변경은 장애 후에도 유지된다.

## 인덱스

인덱스는 특정 조건의 데이터를 빠르게 찾기 위한 별도 자료 구조다. 조회는 빨라질 수 있지만 저장 공간을 사용하고 데이터 변경 비용이 늘어난다. 실제 조회 패턴에 맞게 설계해야 한다.

## 주요 데이터베이스

### PostgreSQL

PostgreSQL은 오픈소스 객체 관계형 데이터베이스 관리 시스템이다. SQL, 트랜잭션, 관계와 제약조건을 제공하고 JSON을 포함한 다양한 데이터 타입과 확장 기능을 지원한다.

### MySQL

MySQL은 오픈소스 관계형 데이터베이스 관리 시스템이다. SQL과 트랜잭션을 지원하며 웹 애플리케이션과 여러 관리형 데이터베이스 서비스에서 널리 사용된다. 실제 동작은 사용하는 Storage Engine과 버전 설정의 영향을 받는다.

### MongoDB

MongoDB는 BSON 형식의 문서를 Collection에 저장하는 문서형 데이터베이스다. 문서는 중첩 객체와 배열을 포함할 수 있으며 고정된 테이블 행과 다른 방식으로 데이터 구조를 표현한다.
