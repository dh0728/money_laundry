서버 기본 개념

서버란?

서버는 다른 프로그램이나 사용자의 요청을 받아 기능이나 데이터를 제공하는 컴퓨터다. 웹 서비스에서는 API 처리, 정적 파일 제공과 백그라운드 작업 등이 서버에서 실행된다.

물리 서버와 가상 서버

물리 서버는 실제 하드웨어 한 대를 직접 사용하는 방식이다. 가상 서버는 가상화 기술을 이용해 물리 장비의 CPU, 메모리와 디스크를 나누어 독립된 서버처럼 사용하는 방식이다.

클라우드의 가상 서버는 필요한 크기로 빠르게 만들고 삭제할 수 있다. 다만 가상 서버 안의 운영체제, 애플리케이션과 보안 설정은 일반적으로 사용자가 관리한다.

기본 용어

  • 인스턴스: 클라우드에서 생성한 가상 서버 한 대
  • vCPU: 가상 서버에 할당된 CPU 처리 단위
  • 메모리: 실행 중인 프로그램이 사용하는 빠른 임시 저장 공간
  • 디스크·볼륨: 운영체제, 프로그램과 데이터를 저장하는 영구 저장 공간
  • Public IP: 인터넷에서 서버에 접근할 때 사용하는 주소
  • Private IP: 내부 네트워크에서 서버끼리 통신할 때 사용하는 주소
  • 수직 확장: 한 서버의 CPU와 메모리를 늘리는 방식
  • 수평 확장: 서버 수를 늘려 요청을 분산하는 방식

단일 서버와 다중 서버

단일 서버는 구조가 단순하지만 서버 장애가 전체 서비스 장애로 이어지는 단일 장애 지점이 된다. 다중 서버는 장애 대응과 확장에 유리하지만 로드밸런서, 공유 데이터, 배포와 상태 관리가 추가로 필요하다.

주요 서버 실행 서비스

Amazon EC2

EC2(Elastic Compute Cloud)는 AWS에서 Linux나 Windows 가상 서버를 생성하는 서비스다. 사용자가 인스턴스 크기, 운영체제 이미지, 디스크와 네트워크를 정하고 운영체제부터 애플리케이션까지 관리한다.

Amazon Lightsail

Lightsail은 가상 서버, 고정 IP, DNS와 스토리지 같은 자원을 단순한 화면과 묶음형 요금으로 제공하는 AWS 서비스다. 클라우드에 익숙하지 않은 사용자나 비교적 단순한 워크로드를 빠르게 시작할 수 있도록 EC2보다 선택 항목을 간소화한다.

Amazon ECS

ECS(Elastic Container Service)는 AWS에서 컨테이너 실행 상태와 배치를 관리하는 컨테이너 오케스트레이션 서비스다. 어떤 이미지와 자원을 사용할지 Task Definition으로 정의하고 Service를 이용해 필요한 컨테이너 수를 유지한다.

AWS Fargate

Fargate는 ECS나 EKS의 컨테이너를 사용자가 직접 관리하는 EC2 서버 없이 실행하게 하는 서버리스 컴퓨팅 방식이다. 사용자는 컨테이너에 필요한 CPU와 메모리를 지정하고 AWS가 실행 기반 서버를 관리한다.
