Git과 소스 저장소 기본 개념

Git이란?

Git은 소스 코드와 문서의 변경 이력을 기록하는 분산 버전 관리 시스템이다. 누가 무엇을 변경했는지 확인하고, 여러 개발자의 작업을 합치거나 이전 상태를 찾을 수 있다.

소스 저장소란?

소스 저장소는 Git으로 관리하는 파일과 변경 이력을 보관하는 공간이다. GitHub와 GitLab 같은 호스팅 서비스는 원격 저장소와 함께 코드 리뷰, 이슈, 접근 권한과 자동화 기능을 제공한다.

기본 용어

  • Repository: 프로젝트 파일과 변경 이력을 보관하는 저장소
  • Commit: 특정 시점의 변경 내용을 기록한 단위
  • Branch: 다른 작업과 분리된 변경 흐름
  • Remote: 네트워크에 있는 원격 저장소
  • Clone: 원격 저장소를 로컬로 복사하는 작업
  • Push: 로컬 변경 이력을 원격 저장소에 올리는 작업
  • Pull: 원격 변경 이력을 로컬로 가져오는 작업
  • Pull/Merge Request: 변경을 기본 브랜치에 합치기 전에 검토를 요청하는 절차
  • Merge conflict: 같은 부분의 서로 다른 변경을 Git이 자동으로 합치지 못한 상태

Git 자체는 특정 호스팅 서비스에 종속되지 않는다. 다만 이슈, 전용 CI 문법, 권한과 앱 연동 같은 호스팅 서비스 고유 기능은 저장소를 이전할 때 별도로 옮겨야 할 수 있다.

주요 Git 저장소 서비스

GitHub

GitHub는 Git 원격 저장소 호스팅, Pull Request, Issues, 권한 관리와 자동화 기능을 제공하는 서비스다. GitHub.com을 관리형 SaaS로 사용하거나 별도의 기업용 구성을 사용할 수 있다.

GitLab

GitLab은 Git 저장소, Merge Request, Issues, 패키지 저장소와 CI/CD 기능을 하나의 플랫폼에서 제공한다. 관리형 SaaS와 조직이 직접 설치해 운영하는 Self-Managed 형태가 있다.
