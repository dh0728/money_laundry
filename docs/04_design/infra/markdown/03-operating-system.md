# 운영체제 기본 개념

[인프라 결정 기록으로 돌아가기](README.md)

## 운영체제란?

운영체제(OS)는 CPU, 메모리, 디스크와 네트워크 같은 하드웨어 자원을 관리하고 프로그램이 실행될 환경을 제공하는 소프트웨어다. 서버에서는 사용자 계정, 파일 권한, 프로세스, 네트워크와 패키지도 운영체제가 관리한다.

## Linux 배포판

Linux는 운영체제의 핵심인 커널을 중심으로 다양한 배포판이 만들어진다. Ubuntu, Amazon Linux, Debian과 Red Hat 계열은 Linux 커널을 사용하지만 패키지 관리자, 기본 설정과 지원 정책이 다르다.

## LTS란?

LTS(Long Term Support)는 장기간 보안 업데이트와 유지보수를 제공하는 릴리스다. 운영 서버에서는 변화가 잦은 단기 릴리스보다 지원 기간이 길고 안정적인 LTS 버전을 주로 사용한다.

## 서버 운영체제에서 관리할 것

- 보안 업데이트와 재부팅 일정
- 사용자 계정과 SSH 접근 권한
- 방화벽과 네트워크 설정
- 디스크 용량과 파일 권한
- Docker 같은 시스템 소프트웨어 버전
- 시스템 로그와 시간대

컨테이너를 사용해도 호스트 운영체제는 사라지지 않는다. Docker 엔진과 컨테이너는 호스트 운영체제 커널 위에서 실행되므로 호스트 보안과 업데이트가 계속 중요하다.

## 주요 운영체제

### Ubuntu

Ubuntu는 Canonical이 개발·지원하는 Debian 계열 Linux 배포판이다. `apt` 패키지 관리자를 사용하며 데스크톱, 서버, 여러 클라우드와 온프레미스에서 널리 사용된다. LTS 버전은 장기간 보안 업데이트를 제공한다.

### Amazon Linux

Amazon Linux는 AWS가 개발하고 유지하는 Linux 배포판이다. EC2 등 AWS 환경에서 사용할 수 있는 이미지와 AWS 도구 구성을 제공한다. 패키지, 기본 설정과 지원 주기는 선택한 Amazon Linux 릴리스에 따라 달라진다.
