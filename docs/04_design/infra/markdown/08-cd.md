# CD 기본 개념

[인프라 결정 기록으로 돌아가기](README.md)

## CD란?

CD는 CI에서 검증한 결과물을 실행 환경에 전달하고 적용하는 과정이다.

- **Continuous Delivery**: 언제든 배포 가능한 상태를 유지하지만 운영 반영 전에 사람의 승인을 둘 수 있다.
- **Continuous Deployment**: 정해진 검증을 통과한 변경을 운영 환경까지 자동으로 반영한다.

```mermaid
flowchart LR
    Artifact[검증된 결과물] --> Approval[승인 또는 자동 조건]
    Approval --> Deploy[배포]
    Deploy --> Health[상태 확인]
    Health -->|실패| Rollback[이전 버전 복구]
```

## 배포 과정의 기본 단계

1. 배포할 이미지나 파일의 정확한 버전을 정한다.
2. 운영 서버에 결과물을 전달하거나 내려받게 한다.
3. 환경 설정과 비밀정보를 주입한다.
4. 새 버전을 실행한다.
5. Health check로 정상 동작을 확인한다.
6. 실패하면 이전 버전으로 롤백한다.

## 기본 용어

- **Deployment**: 새 버전을 실행 환경에 적용하는 작업
- **Rollback**: 문제가 생긴 배포를 이전 정상 버전으로 되돌리는 작업
- **Health check**: 배포된 서비스가 정상적으로 응답하는지 확인하는 검사
- **Deployment approval**: 운영 반영 전에 담당자가 승인하는 절차
- **Deployment history**: 언제 누가 어떤 버전을 배포했는지 남긴 기록
- **Downtime**: 배포나 장애로 서비스를 이용할 수 없는 시간
- **Zero-downtime deployment**: 사용자가 중단을 느끼지 않게 버전을 교체하는 방식

배포 명령 자체와 그 명령을 서버에 전달하는 방법은 분리할 수 있다. 이렇게 하면 SSH, 관리형 명령 실행 서비스 등 전달 수단이 바뀌어도 같은 배포 스크립트를 재사용하기 쉽다.

## 주요 배포 명령 전달 방식

### SSH

SSH(Secure Shell)는 암호화된 네트워크 연결을 통해 원격 서버에 로그인하고 명령을 실행하는 표준 프로토콜이다. 공개 키와 개인 키를 이용한 인증을 사용할 수 있으며 파일 전송과 원격 스크립트 실행에도 이용된다.

### AWS Systems Manager Run Command

Run Command는 Systems Manager가 관리하는 서버에서 원격 명령을 실행하는 AWS 기능이다. 서버의 SSM Agent가 AWS 서비스에서 작업을 받아 수행하고 결과를 돌려준다. 실행 주체의 권한은 IAM으로 통제한다.

### AWS CodeDeploy

CodeDeploy는 애플리케이션 배포 단위, 배포 대상과 단계별 Hook을 정의하고 실행 상태를 추적하는 AWS 배포 서비스다. AppSpec 파일을 이용해 파일 배치와 배포 전후 스크립트 실행 순서를 정의할 수 있다.
