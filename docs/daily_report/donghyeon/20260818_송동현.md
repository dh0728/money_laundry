## 실적
- 룰 엔진을 IF-THEN이나 자연어를 이용해 룰 시나리오 커스텀 기능을 주는것으로 기능 제안
- 현재 확보한 데이터로 실행 가능한 프로토타입을 먼저 구현하고 검증 후 시연용 더미데이터를 활용하는 것으로 합의
- AWS IAM, EC2, VPC, Subnet 등 Network ACL, 보안그룹등 인프라 구현에 필요한 서비스 들을 실습해봄
  
## 문제 상황
- 실 서비스에서는 고객 개인 정보가 필요하지만 현재 데이터 셋에서는 없음
- 데이터 보강을 하려고 해도 데이터가 왜곡 되기 때문에 불가능한 상황
- 룰엔진, 구현 범위 등 많은 내용이 수정되면서 최신화된 산출물이 없음
