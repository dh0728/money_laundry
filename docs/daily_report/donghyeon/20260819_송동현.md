## 실적
- 기획 수정에 따른 기획서 및 시스템 아키텍처 수정
- 멘토 미팅에 필요한 질문 정리
  
## 문제 상황
- 기획이 수정되면서 기존 문서들이 최신 기획사항과 일치 하지 않는 문제 확인
- 룰 엔진, 고객 위험도, 데이터 처리 주기 등 일부 기능의 구현 범위가 명확하지 않아 멘토 의견이 필요

## 내일 계획
- 멘토링 결과를 바탕으로 최종 기획 정리 및 구체화
- 거래 판정 -> 알림 -> 사건 조사로 이어지는 핵심 업무 흐름 구체화
- 포로토 타입에 포함할 필수 기능과 추후 확장 기능 정리

새로운 시스템 배치 상태 

상태	의미
UPLOADING	batchId 발급 후 고객사가 S3에 파일을 업로드하는 중
READY	파일 업로드가 완료되어 실행 가능한 상태
QUEUED	Spring이 SQS에 작업 메시지를 등록한 상태
RUNNING	Python Worker가 메시지를 받아 처리 중
RETRY_WAIT	처리 실패 후 SQS 재시도를 기다리는 상태
COMPLETED	탐지·Alert 생성과 결과 저장까지 완료
FAILED	재시도 횟수를 초과했거나 복구 불가능한 오류 발생
