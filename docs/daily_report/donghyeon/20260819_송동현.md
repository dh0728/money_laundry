## 실적

## 문제 상황
- 기획이 수정되면서 기존 문서들이 최신 기획사항과 일치 하지 않는 문제 확인
- 룰 엔진, 고객 위험도, 데이터 처리 주기 등 일부 기능의 구현 범위가 명확하지 않아 멘토 의견이 필요

## 내일 계획

- 포로토 타입에 포함할 필수 기능과 추후 확장 기능 정리
