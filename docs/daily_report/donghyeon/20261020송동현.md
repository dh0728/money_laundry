주요 담당 업무: 데이터 피처 재분석 및 서비스 파이프라인 분석

## 실적
- AML 데이터 파이프라인 공부
- 현재 피처에서 누락된 정보가 있는지 확인 및 추가 분석 실시
  - 같은 시간에 발생한 거래 내역에 대한 피처가 누락
- 카운팅 피처 기준바뀜에 따른 재분석

## 문제 상황
- 쿠버스피어에서 8090으로 서버를 띄웠는데 메모리 초과가 나면 꺼짐
- 프록시서버도 같이 꺼지는 문제 발생
- 현재 같은 시간에 발생한 거래 내역에 대한 정보가 피처에서 누락된거 같아서 확인이 필요함
- 피처의 카운팅이 한달 ~ 누적으로 바뀜에 따라 카운트형 노드 피처(log_out_count, log_in_count, log_active_days, log_entity_observed_accounts)에 대해 월별로 세탁 계좌 vs 정상 계좌의 분포와 단변량 AUC를 다시 계산할 필요가 있음
