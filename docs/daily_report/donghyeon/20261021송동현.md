주요 담당 업무: 데이터 샘플링 실험

## 실적
- 데이터 샘플링 실험 설계 및 진행중
  - 목적: HI-Large 정상 99.9% 불균형에서 GNN(v10) 학습용 정상 거래 다운샘플링 방법·비율 결정
  - 기존 실험 정리: 태훈님 GNN 54건(original/random/cluster, IPW+pos_weight)·은총님 LightGBM 25조건(k-means/CLARA/CSSMC × r × w) 경로·지표·결론 문서화
  - 설계 결정
    - 지도 샘플링(그래프 유지, loss target만 축소) vs 구조 샘플링(그래프에서 제거)을 분리해 둘 다 비교
    - 샘플링 비율 r 과 양성 손실 비중 pi_eff 를 분리 (pos_weight 를 pi_eff 에서 역산)
    - 선택 방식: random_under / 일별 층화 무작위 / hard-negative 혼합 / CSSMC
    - hard-negative의 기준
      - 세탁 계좌가 낀 정상 거래 — 세탁 거래의 송신·수신 계좌가 한 번이라도 포함된 정상 거래. 세탁 계좌도 평소엔 정상 거래를 하니까, "같은 계좌인데 이건 정상, 저건 세탁"을 구분하려면 이게 필요
      - 같은 분 sibling — 세탁 거래와 같은 송신 계좌에서 같은 분에 찍힌 정상 거래 (03 리뷰에서 찾은 생성기 특성)
    - 검증은 양성 전부 + 정상 2% 가중 표본으로 고정, 모든 조건 공유

- 유형 분류시 이진분류에서 오분류된 데이터만 추가하는 방안 설계
