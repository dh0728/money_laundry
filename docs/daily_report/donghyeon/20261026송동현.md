주요 담당 업무: 데이터 샘플링 실험

## 실적
- 데이터 샘플링 실험 설계 및 진행중
  - RUS 샘플링 데이터 학습중
- 논문에 모델 학습을 위한 데이터 적용 방식 정리
  - 논문에서는 다운 샘플링을 거의 하지않음
    - 가중 손실을 통해 양성에 좀더 가중치를 주고 이웃 샘플링으로 데이터의 양에 따른 시간 소모를 줄임
- 기본 피처로 GNN (Multi-GNN 구조, FraudGT 식 학습), 트리 모델 기준선 (LightGBM, XGBoost) 학습

## 문제 상황
- 샘플링 데이터 학습을 하는데 시간이 너무 오래 걸림 코드를 개선할 필요가 있어보임
- 논문의 흐름대로 기본 부터 차례로 실험 해보면서 성능 개선을 해볼 필요가 있음
