## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : 5, 6세대 GNN AI 모델(V5) 개발 완료 및 V4 주요 결함 수리 산출물 경로: JupyterLab
- 주요 성과 :  학계 및 산업계 기준선을 상회하는 압도적 종합 성능 (SOTA 달성)
지표: Val PR-AUC 0.6532 / Test PR-AUC 0.5945 / 시나리오 재현율 92.90%

IBM 공식 벤치마크 논문의 최고 기록(F1 59.71% / PR-AUC 0.59 수준)을 뛰어넘는 역대 최고 탐지 정밀도를 달성함.

상위 0.1%라는 극도로 좁은 경보 예산 내에서도 61.22%의 높은 정밀도(Precision@예산)를 유지하여 오탐으로 인한 현업 모니터링 부담을 최소화함.

2-Track 상호 보완 구조의 성공적 안착
Track A (GNN): 3-Hop 방향성 컨볼루션(MegaConv)을 통해 점조직 분산 송금(Fan-out), 순환(Cycle) 등 복잡한 자금세탁 체인(패턴 내)을 90.5% 수준으로 완벽히 장악함.

Track B (LightGBM): 그래프를 보지 않는 18종의 순수 행동 이상치 피처(PastIndex)를 새로 투입하여 트리 단독으로도 PR-AUC 0.6259라는 강력한 체급을 확보함. (신규 피처가 전체 중요도의 57.7% 차지)

완벽한 데이터 누수 차단 및 수치 안정성 (Zero-Leakage & Stability)
라벨/시계열 누수 원천 봉쇄: 시계열 순차 분할(Time-split)을 철저히 지키고, 과거 행동 통계 계산 시 Train 구간만 참조하도록 설계됨.

부동소수점 오차 및 NaN 버그 해결: 분 단위 동시각 거래의 정렬 순서 누수를 PastIndex로 제거하고, bfloat16 AMP를 통해 수만 건 허브 계좌 집계 시 발생하던 NaN 오버플로우를 완전히 해결함.

랭크 정규화 기반의 안정적 앙상블 시너지
서로 다른 점수 분포(GNN Logit vs LGBM Probability)를 백분위 순위(rank01)로 정규화한 후 최적 선형 결합(0.65 : 0.35)함으로써, GNN 단독(0.6354) 대비 +0.0178p의 확실한 성능 향상을 이끌어냄.
