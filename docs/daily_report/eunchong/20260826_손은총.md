## 실적

- **완료한 일 + 산출물 경로/이슈 번호**
  - **다중 클래스(9-Class) 세탁 유형 분류 데이터셋 전처리 설계 및 검토**
    - 회의를 통해 기존 단일 모델 접근 대신 '8대 패턴 분류 + 패턴 외 세탁 이진 분류'로 이어지는 2단계 계층적(2-Stage) 탐지 파이프라인 구조를 정립함.
    - 시계열 데이터 누수(Data Leakage)를 방지하기 위해 엄격한 시간 분할(Strict Temporal Split: Train 60%, Val 20%, Test 20%) 및 Train 기준 통계치/스케일러 적합 원칙을 전처리 파이프라인에 반영함.
    - 산출물 경로: JupyterLab (`preprocess_multiclass.py` 및 전처리 프로토타입 노트북)

- **진행 중인 일 + 현재 단계**
  - **HI-Small 기반 9-Class 세탁 유형 분류 모델 아키텍처 수립**
    - 8대 세탁 토폴로지(Fan-in, Fan-out, Cycle 등)와 패턴 외 세탁(Out-of-Pattern)을 타깃(Class 0~8)으로 정의하고, 독립 학습용 양성 거래 풀 및 패턴 특화 피처(상대시간차 Δt, 진입/진출 차수 등) 엔지니어링 진행 중.

## 문제 상황

- **막힌 내용**
  - **전처리 및 라벨링 기준 재정립에 따른 구조 변경**
    - 회의에서 혼동이 잦은 유형(Bipartite vs Stack)의 원시 데이터 심층 분석(EDA) 필요성이 제기되고, 데이터셋 구간(1~10일 vs 전체 18일)에 따른 패턴 분포 차이가 확인되어 전처리 및 라벨링 기준을 재조정함.
    - 단일 랭킹 결합 시 발생하는 점수 희석을 막기 위해, 탐지 유형에 따른 알림 생성 단위(패턴 블록 알림 vs 단건 블록 알림)와 후처리 로직의 정합성을 맞추는 작업이 요구됨.
- **필요한 협업 또는 결정권자**
  - **AI 모델팀 (김명기, 박지원, 김태훈)**: 1단계 이진 분류 모델과 2단계 다중 클래스 분류 모델 간 입출력 인터페이스(Mock Alert Pool 규격) 및 Confusion Matrix 분석 공유.
  - **백엔드/인프라 (송동현 등)**: 모델 추론 결과 서브그래프 패키징을 위한 후처리 프로그램 요구사항 협의.
