## 진행 중인 일 + 현재 단계

**현재 단계**: 2026-08-26 회의 결정(1차 9-Class 다중분류 → 2차 패턴외 이진분류)에 맞춰 전처리와 1차 모델을 끝내고, test 평가까지 마친 상태.

- **전처리**: `HI-Small_10day`(주 실험) / `HI-Small_18day`(대조군) 두 벌. 1차 9-Class 학습셋(y=0~7 8종 패턴, y=8 패턴 외), 2차 이진 학습셋, 클러스터·무작위 언더샘플 각 4벌, 후처리 블록(오라클 상한) 전부 생성 완료. 자체 검증 33~37건 전부 통과(팀 EDA 수치 재현 포함).
- **1차 모델**: 평탄 9-Class 대신 **계층 분해**(패턴 여부 → 유형, 출력은 그대로 9-Class 확률)로 구조를 잡음. 표본 변형 9벌·모델 3종 스윕 → 재현율 0.70 고정 후 정밀도로 비교(팀 관례) → seed 5회로 잡음 여부 확인 → 최종 설정 선택 → test 최초 개봉까지 완료.
- **test 결과**: 재현율 0.70 지점에서 정밀도(패턴 일치) 0.565 · 정밀도(세탁 일치) 0.577. 패턴외 세탁의 2차 라우팅 0.978(1차가 2차 입구를 막지 않음). 알림 843건이 블록 542~797개로 묶이고, 채점 자격 있는 시도 24건 중 0.71 적발.
- 결과와 근거는 `전처리_보고서_9class_손은총_20260826.docx`, `모델_보고서_9class_손은총_20260827.docx`, 검토용 노트북 `preprocess_9class.ipynb` / `train_9class_review.ipynb`에 정리.

## 문제 상황

**막힌 내용 1 — 채점 규칙 실수를 두 번 냈다가 적대 검증으로 잡음**

- 처음 만든 임계값 스윕이 분위수 격자라 고정밀 구간(알림 상위 수백 건)을 통째로 건너뛰어 "목표 정밀도 근처에서 재현율 0.001"이라는 잘못된 결론이 날 뻔함 → 알림 예산 K 기반 스윕으로 교체.
- 그다음 사전확률 보정 없이 언더샘플링 변형을 비교해 "언더샘플링은 해롭다"는 결론을 냈는데, 이것도 채점 규칙의 산물이었음. 보정을 적용하니 격차(0.264~0.568)가 0.494~0.576으로 붕괴 — **결론을 뒤집음**(언더샘플링 자체는 성능을 깎지 않고, 클러스터가 무작위보다 낫다는 근거도 없음).
- 재발 방지를 위해 두 번 다 사람 검토 전에 코드 적대 검증 워크플로로 잡아냈지만, 애초에 채점 규칙 설계 단계에서 더 신중했어야 함.

**막힌 내용 2 — 유형 정밀도가 낮음(0.14)**

- 알림이 진짜 8종 패턴인 비율(0.56)에 비해 유형까지 맞는 비율은 0.14뿐. 혼동행렬을 보면 원인이 BIPARTITE↔STACK 혼동보다 **train 표본이 많은 클래스(SCATTER-GATHER 등)로의 쏠림**. RANDOM은 45건 중 0건 적중 — train 60건으로는 원리적으로 학습이 안 됨.

**막힌 내용 3 — 정밀도 90%(팀 정량 목표)와 쓸만한 재현율을 동시에 만족하는 지점이 없음**

- val에서 정밀도 90%를 달성하는 지점은 있으나 그때 재현율이 0.033. 운영점을 어디로 잡을지는 모델이 아니라 팀이 정할 문제.

**막힌 내용 4 — 알림 블록 시간창이 test 구간에서 무력화됨**

- 전처리가 오라클 복원율 기준으로 고른 창(10,080분)이 test 구간 길이(3,350분)보다 길어 split 안에서는 계좌 공유만으로 블록이 만들어짐. 창을 60분으로 좁히면 블록 정밀도가 0.36 → 0.55로 오름 — 알림 블록용 창은 오라클 복원용 창과 따로 정해야 함.

**막힌 내용 5 — HI-Small 표본 크기가 근본 제약**

- train의 최소 패턴 클래스가 60건. 계층 분해로 완화했을 뿐 없앤 것은 아님. HI-Medium 이상으로 규모를 올리는 것이 다음 단계인데, 화두 12(저장 형식·파티션·공유 위치)가 선행 조건.

## 내일 계획

### 가장 먼저 할 일

1. **팀 회의 안건 7건 상정** — 특히 우선순위 셋:
   - 채점 규칙을 파이프라인 계약에 명시(사전확률 보정 없이 쓰면 정밀도가 떨어짐 — BE 추론 서버가 지킬 순서)
   - 회의 결정 6 다듬기(클러스터 기반 → "가중 + 사전확률 보정, 다운샘플은 속도 필요할 때만 무작위로")
   - 운영점(알림 예산 K) 확정 — 관제팀이 하루에 볼 수 있는 알림 수 기준으로
2. **2차 이진분류 모델 착수** — 1차가 패턴외 세탁을 0.978로 거의 다 2차로 넘기므로, 이제 2차가 실제 병목인지 확인할 차례.
3. **HI-Medium 착수 여부 판단** — 화두 12 선행 조건 확인 후 규모 확대 검토.
