## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : Large데이터로 실험 완주 및 9클래스 하이브리드 도전, 산출물 경로 주피터랩
- 진행 중인 일 + 현재 단계  : Hi-large데이터로 언더샘플링을 시도했으며, 하이브리드 모델 평가를 완료하였음. 실행 결과, Extratrees 단독으로 사용했을 시 시드 1 기준 0.5834, 시드 7기준 0.5400인 반면, 하이브리드는 시드 1 기준 0.5941, 시드 7은 0.5800으로 성능이 더 높게 나왔다!

## 문제 상황

- 막힌 내용 : Large 데이터의 크기가 너무 큰 바람에 실행 시간이 굉장히 오래걸렸음. 또한 다중 분류에서 ExtraTrees 모델을 쓰는 것은 LightGBM, XGBoost와 같은 다른 분류 모델들과 비교를 하였을 때, 제일 점수가 높게 나왔기 때문이었음. 그러나 V13에서 하이브리드 모델을 사용했을 때, 점수가 제일 높게 나온 것이 갑작스레 떠올랐고, 다중 분류에서도 하이브리드 모델을 시도하고자 했음.
- 필요한 협업 또는 결정권자 : 김태훈
