## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : 태훈님과의 피처 통합 및 선정 완료
- 산출물 경로 : 주피터랩, 깃허브
- 진행 중인 일 + 현재 단계  : 현재 태훈님의 GNN 모델 용 40개 피처로 고정을 확정하였으며(이는 트리 계열 모델이 GNN의 피처에 적응하는 것이, 트리 모델의 피처에 GNN이 적응하는 것보다 훨씬 용이하기 때문이고, 실험을 돌리기에 시간이 너무 많이 걸리고, 또한 시간을 할애하기에 시간은 부족하기 때문이다. 또한 피처 정제에 몰두하기 보다는, 다음 전처리를 수행하면서 살짝식 손 보는 게 낫다고 판단하였다.)
## 문제 상황

- 막힌 내용 : 피처가 통일되지 않았음
- 필요한 협업 또는 결정권자 : 김태훈
