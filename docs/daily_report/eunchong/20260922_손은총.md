## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : 이진분류 모델 및 다중분류 모델의 피처 통합 완료 
- 산출물 경로 : 주피터랩, 깃허브
- 진행 중인 일 + 현재 단계  : 언더샘플링 방식(Clara를 적용한 k-medodids, k-means, cssmc)과 언더샘플링을 하지 않고 클래스 가중치만 준 것을 비교하여, 시각화로 표를 나타내 어떤 선택이 제일 최선의 선택일지 고르는 보고서 작업을 하고 있음.
## 문제 상황

- 막힌 내용 : 전처리 순서 중 언더 샘플링을 완료하지 않아, 이를 끝낼 예정이다.
- 필요한 협업 또는 결정권자 : 김태훈
