## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : FraudGT 도입에 관해 숙고함. 
- 산출물 경로 : jupyterlab
- 진행 중인 일 + 현재 단계  : 기존에는 TransformerConv와 LightGBM 각각 따로따로 실험을 했었는데, 8개의 세탁 패턴만 맞히도록 Extratrees를 도입하여 앙상블 조합으로 사용하면 어떨까 싶었다. 그렇게 실험을 돌리는 와중 Out of memory로 인해 두 번 이상 세션이 날아가 버렸고, Extratrees의 도입은 철회하였다. 그러나 앙상블로 성능을 보았을 때, 이전 각자 따로 하였을 때보다 조금이나마 상승이 되었었기에, 다른 기법이 없나 찾아보던 중, 자금세탁탐지용 모델인 (GNN계열) FraudGT 모델을 발견하게 된다. 처음 보는 모델이기에 어떤 구조로 작동하는지 파악을 하였고, 바이브 코딩으로 FraudGT 도입의 정당성을 따져보게 된다. 최종적으로 판단하였을 때, 논문에서 사용된 데이터와 우리가 사용하고 있는 데이터의 형태가 다르다는 점, 그리고 학습 시간이 많이 걸린다는 점 때문에 회의적인 입장으로 기울었으나, 직접 해보기 전까지는 모른다는 생각에 FraudGT를 도입하기 위해 Train, test, validation 데이터를 정제하고 있다. 
## 문제 상황

- 막힌 내용 : Extratrees 때문에 out of memory가 두 번 나버려, 세션이 두 번이나 날아가 버렸다. (저장이 안된 상태였음)
- 필요한 협업 또는 결정권자 : 김태훈
