## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : FraudGT를 활용한 모델 개발  
- 산출물 경로 : jupyterlab
- 진행 중인 일 + 현재 단계  : FraudGT를 활용하여 모델을 개발하였다. 또한, 확률값을 보정하고, 정규화 norm_m을 TransformerConv 모델에 추가하였다. 아직 결과를 확정짓기에는 학습과 테스트가 전부 끝나지 않아 이르지만, 세탁 정밀도는 0.472 -> 0.896 (FraudGT에서 확률 보정 함. Val 앞 8일로 보정값을 맞춤)으로 올라갔다 (비록 재현율은 0.999에서 0.656으로 떨어졌긴 하나) 그리고 TGNN 또한, 0.371에서 0.893으로 올라갔다 (마찬가지로 재현율은 0.999에서 0.621로 떨어짐) 다만 여기서 세탁 정밀도는 이진분류로만 잰 것이기 때문에, 금방 올라갈 수 있다고 생각한다. 그러나 유형분류또한 0.1~0.2 정도를 웃돌던 모델들이 0.4 이상으로 뛰기도 하는 등, 진척을 보이고 있기 때문에 내일 결과를 보고 판정해봐야할 것 같다.
