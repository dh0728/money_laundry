## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : LightGBM 하이퍼파라미터(잎값 조정) 조절 후 학습 시작, TimeGAN 기법 재도입
- 산출물 경로 : 주피터랩
- 진행 중인 일 + 현재 단계  :  이전 멘토 분께서 If Then 기법으로 결정 트리를 설명용 모델로 사용할 수 있다는 말에서 착안해 현재 사용 중인 LightGBM을 설명용 모델로 학습하려 하였다. 그러나 LightGBM의 구조를 살펴보던 중, 하이퍼 파라미터에서 잎값 폭주를 막고 조절하는 값들이 우리의 데이터 및 작업 현황과는 상당히 맞지 않는 수로 맞춰져 있었고, 우리 데이터 셋에 맞는 하이퍼 파라미터로 재조정하여 학습을 돌리기 시작했다. 또한 이전에 클로드 코드가 pdf 읽기 프로그램을 갖고 있지 않던 탓에, 첨부해놨던 TimeGAN 기법 논문 파일을 그냥 지나쳐버렸었던 적이 있다. 때문에 pdf 읽기 프로그램 설치 후, TimeGAN 기법 논문을 다시 파악하고 LightGBM 실험이 끝난 뒤 TimeGAN 기법으로 bipartite를 재증강할 예정이다.
