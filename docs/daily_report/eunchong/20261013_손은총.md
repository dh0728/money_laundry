## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : PatchTST 및 mamba 구조 도입, ExtraTrees 학습 완료, LightGBM 잎 값 조정한 후 학습 완료, SALT-GNN 디버깅 완료
- 산출물 경로 : 주피터랩
- 진행 중인 일 + 현재 단계  : 어제의 회의 내용 이후("세탁 유형만 분류한다") 기존 정상 거래를 과감히 제거하고, 세탁 유형만 분류하는 모델을 개발하게 되었다. 때문에 학습 및 작업 속도가 매우 빨라졌으며, 기존에 메모리 문제로 못 돌렸던 extratrees를 돌릴 수 있게 되었고(정상거래 1600만 건이 빠지며), LightGBM의 잎 값을 조정한 후 돌렸던 작업이 마무리 되었다. (다만 효과는 0.02+ 정도에 불구했다) 마찬가지로 이전에 왠지 모르게 SALT-GNN의 성능이 눈에 띄게 (다른 모델과 비교했을 때) 나빴는데, SALT-GNN의 하이퍼 파라미터 값 하나가 꺼져있는 상태였다. 그걸 켜니 약 1~2%의 차이로 내 모델들 중 SOTA를 달성하였다. (정밀도 45%)   
## 문제 상황

- 막힌 내용 : 다만 bipartite와 random의 문제가 있고, bipartite의 데이터를 분석하여 문제는 파악하였으나 해결 방법을 고안하고 시도하기 까지는 가지 않았다. 때문에 이 bipartite를 해결해 보기 위 해 여러 방법을 시도해 볼 것이다.
