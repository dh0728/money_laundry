## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : TimeGAN기법 사용 및 탐구
- 산출물 경로 : 주피터랩
- 진행 중인 일 + 현재 단계  : 직접 데이터를 까보기로 했다. 세탁 데이터 중 논문에서 설명한 각 데이터 형식의 최소 조건에 부합하는 데이터만 남겼더니 데이터의 개수가 너무 적어지는 바람에, TimeGAN기법을 활용하여 늘린 뒤 학습이 빠른 LightGBM에 넣어보기로 했다. 확정이 아니라 실험으로 진행하고 있다. 사실상 데이터 제작자가 설명하는 형태의 데이터를 보존하고, 그와는 다른 이상한 데이터를 제거한다는 게 맞다 싶다가도, 왠지 모르게 멋대로 결정하면 안되는 안건 같았다.
일단 TimeGAN 기법을 사용했으나, 역시나 제대로 된 증강 데이터가 하나도 없었다. 다만 하늘이 무너져도 솟아날 구멍은 있다고, timeGAN 기법에서의 문제들을 파악하고, 다시 timeGAN 증강 시도를 하고 있다. GPU와 컴퓨터 자원깨나 쓰는 작업이다 보니, 내일이 되서야 결과를 확인할 수 있을 것 같다. 
## 문제 상황

- 막힌 내용 : TimeGAN 기법으로 증강한 데이터의 퀄리티가 현저히 떨어짐.
- 필요한 협업 또는 결정권자 : 김태훈(이진분류), 송동현(팀장)
