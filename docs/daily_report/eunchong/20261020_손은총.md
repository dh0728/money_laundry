## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : 금액열을 추가한 모델을 돌려 cycle과 random 쪽의 재현율과 정밀도를 올렸다. + 무패턴 세탁 포함
- 산출물 경로 : 주피터랩
- 진행 중인 일 + 현재 단계 : 모델이 트레인에서 본 세탁은 벨리데이션에서 잘 맞추는데, 벨리데이션에서 처음 보는 세탁은 잘 못 맞춰서 이 간극을 줄이기 위해 여러 실험을 진행하고 있다.
## 문제 상황

- 막힌 내용 : 일단 계속 진행해봐야 한다. 
- 필요한 협업 또는 결정권자 : 김태훈, 송동현
