## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : 각 유형 별 혼동 행렬 파일 및 val 기간 세탁 데이터 시각화 및 분석
- 산출물 경로 : 주피터랩
- 진행 중인 일 + 현재 단계 : val 데이터에서 거래가 잘려버려, cycle이 random처럼 보이는 경우가 발생했다. 약 val의 50%가 이렇게 되어버렸는데, 이렇게 되면 random과 cycle을 잘 가르지 못하는 문제가 발생하기 때문에 시각화 파일을 보면서 어떻게 하면 이 두 열을 좀 더 잘 가를 수 있을지 고뇌하고 있다.
## 문제 상황

- 막힌 내용 : 일단 계속 진행해봐야 한다. 
- 필요한 협업 또는 결정권자 : 김태훈, 송동현
