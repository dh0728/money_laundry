## 실적

- 산출물 경로 : 주피터랩
- 진행 중인 일 + 현재 단계 : ga sc 데이터를 TimeGAN으로 증강하고 있다.
## 문제 상황

- 막힌 내용 : 각 유형별 성능을 시각화 하는 파일을 만들어 확인을 하였을 때, 몇몇 유형의 데이터의 정밀도 및 재현율이 0.9를 넘는 등 급증하는 현상을 파악했다. 다만 이 수치가 어떻게 나왔는지 궁금하여 클로드 코드에게 물어보니, 트레인에서의 데이터 정답을 외워 벨리데이션 까지 이어지는 거래를 맞춰버리는 바람에 성능이 높게 나오는 것이었다. 물론 완전히 망한 학습 방법은 아니다. train에서 시작하여 train에서 끝나는 데이터도 있고, val에서 시작하여 val에서 끝나는 데이터도 있기 때문이다. 그러나 train에서 시작하여 val에서 끝나는 데이터도 많기 때문에 유형 과적합이 많이 일어났다고 볼 수 있다. 그래서 일단.... train에서 시작해서 train까지 끝나는 데이터가 몇 개인지, train에서 시작하여 val에서 끝나는 데이터가 몇 개인지, val에서 시작하여 val에서 끝나는 데이터가 몇 개인지를 확인하려고 한다.
- 필요한 협업 또는 결정권자 : 김태훈, 송동현
