## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : 정화 기법을 사용한 모델의 학습을 마쳤다. (트레인과 벨리데이션 사이에 걸쳐있는 데이터가 있다면, 트레인에서는 데이터를 빼고, 벨리데이션에서는 쓰는 방법) 또한 B-CNN기법 (대분류 -> 소분류)을 사용한 모델의 학습 또한 마쳤다. 퇴근 시간에 막 끝나서, 제대로 파악하는 것은 내일 본격적으로 봐야할 것 같다.
- 산출물 경로 : 주피터랩
- 진행 중인 일 + 현재 단계 : 모델의 학습이 끝났지만, 성능 지표는 정말 믿을만 한지 제대로 분석해봐야 한다.
## 문제 상황

- 막힌 내용 : 일단 계속 진행해봐야 한다. 
- 필요한 협업 또는 결정권자 : 김태훈, 송동현
