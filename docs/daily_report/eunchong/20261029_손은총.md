## 실적

- 완료한 일 + 산출물 경로/이슈 번호 : 
1. 원본 데이터 파일 복사본을 만들어서, 대분류 라벨 (4개)을 추가함.
2. 복사본에 있는 노이즈 데이터 제거
3. train val / val test 사이 각각 걸치는 데이터들을 정화 기법을 사용함 (train에서는 빼고 val에서는 넣고 / val에서는 빼고 test에는 넣고)
4. Hi-Medium 세탁 데이터를 가져와서 빠르게 lightGBM 모델에 넣어봄. -> gather scatter만 정밀도, 재현율이 오르고 나머지는 다 떨어짐
5. Hi medium gather scatter만 추가해서 SALT-GNN을 학습함
6. SALT-GNN 학습 완료

- 산출물 경로 : 주피터랩
- 진행 중인 일 + 현재 단계 : 모델의 학습이 끝났지만, 성능 지표는 정말 믿을만 한지 제대로 분석해봐야 한다.
## 문제 상황

- 막힌 내용 : BCNN 구조로서 대분류 후 소분류를 시도하였으나, LightGBM으로는 큰 성과를 보지 못하였고, 오히려 성능이 떨어지기도 하였다. 이상함을 느끼고 직접 데이터를 시각화한 html 파일로 하나하나씩 보니, 이전에 노이즈 데이터로 빼놨었던 거래들이 들어 가 있었고, 무작위 추출을 하는 바람에 미래 정보가 과거로 가는 등의 문제가 있었다.
때문에 이를 해결하기 위해 노이즈 데이터를 다시 빼고, 정화 기법을 사용했으며, 무작위 추출을 금지한 상태로 SALT-GNN 모델 학습을 마쳤다.
- 필요한 협업 또는 결정권자 : 김태훈, 송동현
