## 실적

- 완료한 일 + 산출물 경로/이슈 번호 :
1. EmDT(디퓨전)로 GATHER-SCATTER 데이터를 늘려 val 에 넣어 봄 → 차이 없음. 검토해 보니 합성 데이터가 진짜보다 38 ~ 53배 넓게 퍼져 있어서 생성 자체가 실패였음(학습이 600걸음뿐이라 모자람).
2. 그래서 EmDT 를 처음부터 다시 설계함(0단계 진단 · 1단계 생성기 다시 만들기). MLP 와 EmDT 6가지 구조를 8만 걸음까지 학습해 '진짜와 얼마나 비슷한지' 관문으로 봤는데, 둘 다 관문 통과 없음. 6개 지표 중 5개는 진짜 범위 안에 들어왔지만, 진짜와 합성을 가려내는 판별 AUC 가 0.98(관문 0.576 이하)로 아직 쉽게 구별됨.
3. 완성된 사건 하나로 채점해 봄(시도의 마지막 거래 기준) → 정밀도 / 재현율 0.6245 / 0.5643(거래 단위 0.6507 / 0.6085). CYCLE 재현율은 0.217 → 0.344 로 오르지만 전체는 떨어져서, 채점은 지금처럼 거래 단위로 유지하기로 함.
4. Bipartite · STACK 을 데이터에서 아예 빼고 7클래스로 다시 학습해 봄 → 두 칸만 지운 것(0.7018 / 0.6603)과 다시 학습한 것(0.6975 / 0.6576)이 씨앗에 따라 달라져서, 다시 학습한 이득은 없었음.
5. val 에 정화를 안 했을 때 성능 확인(train 은 정화 그대로): 노이즈 · 정화 둘 다 안 함 0.5096 / 0.4883 · 노이즈만 뺌 0.5662 / 0.5291 · 지금(둘 다 함) 0.6507 / 0.6085.
6. top-k 성능 확인: 9칸 평균 재현율 top-1 0.608 · top-2 0.744 · top-3 0.822. CYCLE 은 top-2 로 넓히면 0.217 → 0.532 (2등일 때 1등은 대부분 RANDOM).
7. 팀장님 요청으로 학습 · 고르기 · 평가 기간 유형별 데이터 수를 정리함.
- 산출물 경로 : 주피터랩 (results/R_EmDT_GASC_20261103/ · R_EmDT_GASC_재설계_20261103/ · R_완성한건채점_20261103/ · R7_BIP_STACK뺌_20261103/ · R_정화전val_20261103/ · R_topk_20261103/)
- 진행 중인 일 + 현재 단계 : 지금은 거래 낱개 하나하나로 학습하고 있는데, 완성된 사건 하나를 통째로 보고 학습 · 채점하는 방식으로 실험 중이다. 그래프를 만들다 메모리 한도에 두 번 걸려서, 나눠 만드는 방식으로 고쳐 다시 돌리고 있다.
## 문제 상황

- 막힌 내용 : EmDT 로 만든 데이터가 아직 진짜와 쉽게 구별돼서 증강에 쓸 수 없다. CYCLE 과 RANDOM 을 서로 헷갈리는 문제도 여전하다.
- 필요한 협업 또는 결정권자 : 김태훈, 송동현
