## 실적

- 완료한 일 + 산출물 경로/이슈 번호 :
1. **BIP · STACK 을 원장에서 아예 지운 판(R7-원장뺌-마감)**: BIP · STACK 이 아예 없는 데이터라고 보고, 그날 자정까지의 거래를 다 보게 다시 학습함. val 7칸 정밀도 / 재현율 0.705 / 0.648 → 7칸으로 학습한 판(0.690 / 0.646)과는 씨앗에 따라 달라지고, 9칸으로 학습해 7칸으로 채점한 판(0.714 / 0.671)보다는 씨앗에 흔들리지 않고 낮음. FAN-IN 정밀도만 세 씨앗 모두 오름. 실제 운영에서는 원장에서 지울 수 없어 진단용으로만 둠.
2. **GA-SC 데이터 늘리기(시계열 디퓨전 v3)**: TimeGrad · TimeDiT 설계안 작성 → 0단계 배선 점검 26/26 통과 → 1단계 실행. 20개 설정 중 가장 나은 설정도 확인 8판에서 관문을 통과하지 못함(진짜끼리 비교한 기준과의 거리 5.87 · 기준 10개 중 7개만 통과 · 커버리지 · 머리축 분산 · GA-SC 이웃 몫이 진짜 범위 밖). 시간 정보를 넣으면 '시간이 지날수록 허브 모양이 달라지는 정도'는 진짜와 비슷해짐(0.62 vs 진짜 0.60). 하지만 '같은 날 허브 거래끼리 가깝게 모이는 모양'은 못 따라감(0.64 vs 진짜 0.27 · 작을수록 잘 모임). 마지막으로 EmDT v2 를 마저 돌려 비교하는 중(15:49 시작).
3. **나눔 경계에서 거래가 잘리는지 보는 HTML**: 유형별로 시도의 거래를 왼쪽 → 오른쪽 시간 흐름으로 그림. HTML 과 집계로 확인한 결과, val 패턴 행의 65%(15,675 / 24,280)는 val 전에 시작한 시도의 뒷부분이었음. 그 시도의 앞 기간 행은 정화 때 train 에서 빠져 있었음(옮긴 것이 아니라 지운 것).
4. **시도 단위 나눔으로 다시 채점**: 시도를 끝나는 구간으로 통째로 옮기는 나눔으로 바꿈. train 에서 시작해 train 에서 끝난 시도만 학습하고, val · test 로 이어진 시도는 앞 기간 행까지 val · test 에 넣음. 이 나눔으로 지금 모델(R-마감 · 7칸)을 다시 채점하면 새 val 0.631 / 0.610(지금 val 0.714 / 0.671) · 새 test 0.541 / 0.533(지금 test 0.584 / 0.563). 옮겨 온 앞 기간 행이 특히 어려움(test 쪽 학습 · 고르기 날짜 행 0.278 / 0.344).
5. **val 조각 채점(새 학습 없음 · 저장 확률 다시 셈)**: 지금 val 숫자(0.702 / 0.660)의 패턴 행 84% 가 val 전에 시작한 시도의 뒷부분(0.618 / 0.628)임을 확인함. val 에서 시작한 시도만 보면 0.353 / 0.374 이고, 경계에 걸친 시도를 양쪽에서 지운 판은 0.362 / 0.306 임(SC-GA 16행뿐이라 흔들림이 큼).
