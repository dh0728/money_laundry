## 실적

- 바뀐 거래만 다시 계산하는 구조 효과 확인
  - 거래일 9/7~9/13 분석 입력 고정 합 1,868.7초 → 968.6초(-48.2%), 마지막 두 날(9/14·9/15)을 버스트 소진 없이 처음 측정(15.8분, 21.8분)
- 분석 입력 고정·모델 입력 준비가 바뀐 거래만 색인으로 읽도록 변경
  - 분석 입력 고정 968.6초 → 669.5초(-30.9%), 모델 입력 준비 거래일 9/11~9/14 118~133초 → 35~54초
  - 중단과 버스트 소진 없이 9일을 이어 잰 첫 실행으로 9일 합 96.6분, 디스크 읽기 306GiB → 194GiB
- 거래 통합의 보고 본문 읽기를 기본키 조회로 변경
  - 하루 약 37만 건을 읽기 위해 보고 본문 표 전체(4.5~4.8GiB)를 읽던 문제 수정
  - 거래 통합 9일 합 1,297.0초 → 1,023.2초(-21.1%), 같은 크기 날 거래 통합 115.9~163.3초 → 115.5~123.2초로 날이 가도 늘지 않게 됨
- 초기화 직후 분석 입력 고정이 멈추던 문제 수정
  - 초기화 직후 통계가 없는 표 때문에 실행 계획이 잘못 잡혀 백필 첫날 분석 입력 고정이 약 51분 멈춘 문제 수정
- 한 실행의 분석 입력 조회 3개(대상 건수, 최초 거래 시각, 현재 점수 갱신)를 표 전체 대신 기본키로 읽도록 변경
- 매 수정마다 결과 동일성 확인: 거래 3,079,111건 전부 대응, 점수 상관 0.9995 이상, 의심 기준 근처 10~15건 차이로 모델 흔들림 수준
