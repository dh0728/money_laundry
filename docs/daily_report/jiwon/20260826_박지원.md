## 실적

- 모델 성능 평가 지표 비교
- 정규화 조합 실험(run_011): λ=100 + hessian 하한 1.0 조합이 새 기준선(max-F1 68.98%)
- 리프 수 확장 실험(run_012): 손해 확인, 파라미터 사다리 종결
- 평가 체계 확장: 혼동행렬·클래스별 OVR PR-AUC·패턴 닻 보조지표(P@패턴R0.9) 상설화
- 지표 총정리 문서 + 히트맵 보드 HTML 산출물 작성
- BIPARTITE↔STACK 혼동 원인 분석(경계층 간선 국소 동일성) + 블록 뷰어 산출물 작성
- 분할 경계 걸침 블록의 지표 부풀림 발견
- 차기 아키텍처(9클래스+이진 캐스케이드) 검증 실험 설계

## 문제 상황
- 논패턴과 노말을 구분을 잘 못함
- bipartite와 stack을 잘 구분 못함
- 꼬리를 제거하고 유효기간만 쓸거냐 전체 기간을 쓸거냐를 떠나서
- train/val/test로 절단하면 그 순간 그 절단 경계선에선 블록이 끊어지는건 똑같은 상황이라 패턴이 깨짐
- 그 절단된 패턴 블록의 앞부분이 train으로 들어가서 편향 존재
