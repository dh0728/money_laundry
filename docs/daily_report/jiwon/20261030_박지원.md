## 실적

- 그래프 거래 흐름 표시 사라짐 원인 확인
- dev Alert 유형 판정 편향 원인 확인
- Alert 유형 결정트리에서 결제 방식 피처 제외
- 데이터셋별 세탁 거래 구성 집계
- Alert에 정상 거래가 거의 섞이지 않는 원인 확인
- dev 시연 데이터 HI-Medium 전환 준비


## 문제 상황
- HI-Medium 계좌의 99.99%가 HI-Large에도 있어, HI-Large로 학습한 이진분류 모델의 시연 점수가 실제보다 높게 나올 수 있음
- HI-Medium 20곳 시연에는 16일 세탁 거래의 24.93%만 들어가고, 통째로 남는 거래 3건 이상 패턴은 87개이며 STACK은 0개임
- 결제 방식을 빼도 거래 1~2건 Alert과 금액 차이가 수십~수백 배인 별 모양은 비패턴으로 판정됨(별 모양 시험에서 비패턴 174개 중 각각 40개, 134개)
- 비패턴 유형은 그래프 모양이 아니라 정답 패턴 목록 수록 여부에서 나온 분류여서 조사자에게 모양 정보를 주지 못함
- HI-Medium 20곳은 하루 중앙값 36만 건으로, LI-Large 처리 속도 기준 16일 적재에 16시간 이상 걸릴 것으로 추정(HI-Medium 실측 아님)
