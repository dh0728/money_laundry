## 실적

- dev 분석 입력 고정 시간 급증 원인 조사 착수
  - dev HI-Medium 분석에서 대상 거래가 약 36만 건으로 같은데도 분석 입력 고정이 9/13 624초 → 9/14 2,690초, 9/15 3,430초로 증가한 원인 조사

  - 실행 계획 변경과 DB 서버(RDS) 성능 한도를 후보로 두고, 해당 시간대 RDS 지표와 느린 SQL을 읽기 전용으로 뽑는 조회 스크립트 준비
