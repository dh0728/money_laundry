## 실적

- 이진분류 모델을 Multi-FraudGT + HGB로 교체
  - 추론 서버에 새 모델 폴더(팀원 코드 + 우리 입출력 형식으로 잇는 연결 파일)를 추가하고, 기존 모델(v10)은 폴더·등록·테스트·문서까지 모두 제거하여 백엔드에 흔적이 남지 않도록 정리(파일 59개)
  - 내용이 완전히 같은 거래는 모델 입력에서 하나만 남기고, 추론 후 빠진 거래에 같은 점수를 붙이도록 구현
  - 팀원 예시 거래 18건 대조 최대 점수 차이 0.00000008, 추론 서버 테스트 66개, worker 테스트 259개 통과
  - KubeSphere 추론 서버와 dev 동시 배포
- 기존 모델 dev 결과 저장과 기준선 분석
  - dev 초기화 전 기존 모델 9일 결과(거래 점수 3,079,111건, 유형 판정, Alert 368개, 작업 시간)를 은행·파일·행 위치와 함께 저장하여 초기화 후 다시 올린 거래와 1:1로 대조할 수 있도록 구성
  - 기존 모델 기준 패턴 세탁 재현율 51.36%, AP 0.6917, Alert 핵심 포함 57.52%, 패턴이 한 Alert에 통째로 묶인 비율 47.73%(88개 기준), 의심 거래 정밀도 77.29%
- 조작패널 초기화 응답 시간 초과 수정
  - 초기화 확인 요청이 테이블 58개의 행 수를 세면서 데이터가 16일치로 늘자 패널 대기 시간(15초·30초)을 넘김, 실제 응답 19초 확인
  - 초기화 확인·실행 두 요청만 대기 시간을 120초로 늘리고, 실제 로그인 경로를 거치는 테스트 추가, 패널 테스트 71개 통과
- 추론 서버 네이버클라우드 이전 준비
  - dev 브랜치만 받으면 새 모델과 유형 분류 모델 가중치까지 모두 들어 있어 별도 파일 전달이 필요 없음을 확인(체크섬 6개 일치)
  - 새로 만들어야 하는 설정(토큰, HTTPS 프록시 인증서)과 dev 연결 설정 위치를 단계별 설치 문서로 정리
- dev 새 모델로 HI-Medium 20개 은행 백필 7일 후 분석 진행

## 문제 상황
- SEED 보강 기준값(0.1, 0.01)은 기존 모델 점수에 맞춘 값을 임시로 쓰고 있어 새 모델 결과로 재조정 필요
- 네이버 서버에서 새 모델 설치와 GPU 실행은 아직 확인하지 않음
