## 실적

- 색 의미 변수(Semantic)를 전부 지우고 처음부터 다시 짰다. 면·테두리·글자와 아이콘 세 묶음이 같은 구조를 갖게 하고, 묶음마다 중립·브랜드·상태(위험·주의·긍정·안내·대기)로 나눴다. 단계는 옅음·기본·진함 3단계, 상태는 기본·호버·눌림으로 맞추고 비활성은 묶음 최상위에 하나씩 두었다.
- 기본 색 팔레트(Primitive)를 다시 다듬었다. 탁해진 색을 선명하게 되돌리고 빠져 있던 파랑을 새로 만들었으며, 단계 사이 밝기가 자연스럽게 이어지도록 곡선을 고쳤다. 흰색·검정·회색은 mono 하나로 합치고 투명도는 5단위로 정리했다.
- 브랜드 색 변수는 라이트·다크 구분을 없애 11개로 줄였다. 대칭 구조라 다크 모드는 반대 단계를 쓰면 된다.
- 간격, 사이드바 너비, 헤더 높이 같은 크기 변수(Unit)를 추가하고 순서대로 정렬했다.
- 피그마 페이지를 foundation·icon·components·screen 네 개로 통합했다. 패널은 사이드바·헤더처럼 곡률과 여백 없이 붙이고, 크기 조절 손잡이는 단순화했다.

## 문제 상황

- 변수를 새로 짜면서 컴포넌트와 변수 연결이 끊긴 곳이 많다. 라이트 모드의 카드·패널·표 헤더와 다크 모드의 진한 카드가 회색으로 보인다.
- 다른 컴포넌트를 품은 컴포넌트도 깨져 있어 컴포넌트 단계에서 한꺼번에 고쳐야 한다.
- AI가 규칙을 잘못 적용해 글자색을 흐리게 바꾼 일이 있어 되돌렸다. 이후 변수 편집은 직접 하고 AI는 연결 작업만 맡긴다.

## 내일 계획

- 컴포넌트 단계에 들어가 끊긴 변수 연결부터 고치고, 호버가 있는 컴포넌트에 눌림 상태를 추가한다.
- 초안 기준으로 구현한 코드를 팀 회의에 가져가 같이 본다.
