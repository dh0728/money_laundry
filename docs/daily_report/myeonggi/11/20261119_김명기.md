## 실적

- 노션 표를 직접 살펴보고 조사 화면과 비교했다. 행 선택 위치와 필터·정렬 적용 표시를 검토하고, Alert 조사 카드에 남아 있던 선택 체크박스와 중복 상태 표시를 찾아 정리했다.
- Alert·Episode 카드의 판정 결과와 경과일을 먼저 읽을 수 있도록 카드 본문과 태그 순서를 정리했다. 조사 표와 상세 화면에서 상태와 모델 점수가 같은 순서로 읽히도록 표시 기준을 맞췄다.
- 사이드바를 펼치고 닫으며 하단 계정·설정 버튼과 조사 탭 추가 흐름을 검수했다. 이미 열린 탭의 중복 추가를 막고, 카드에서 탭을 추가한 결과를 화면 하단 중앙에서 바로 확인하도록 다듬었다.

## 문제 상황

- 조사 카드와 표, 설정 창에 공통 스타일과 개별 스타일이 겹친 부분이 있었다. 웹 시험 화면의 공통 스타일을 정리했고 최신 화면과 Figma의 차이 확인이 남아 있다.
- 조사 탭 추가와 판정 흐름은 샘플 데이터로 확인하는 단계다. 기관 발급 계정과 실제 업무 권한을 연결한 검증이 남아 있다.

## 내일 계획

- 최신 웹 시험 화면을 Figma와 대조해 카드·사이드바·팝업의 차이를 정리한다.
- 조사 탭 추가, 결과 알림 확인, 판정 사유 입력과 확정까지 이어지는 흐름을 다시 검수한다.
