## 실적

- Figma에서 실제 서비스 화면을 만들어봤고, 대부분의 요소들을 컴포넌트화하여 정리했다.
- 폰트와 색상, 버튼·업무 상태를 다시 정리했고 아이콘 버튼과 패널 이동 손잡이도 만들었다.
- 여러 해상도를 시험할 작업 화면을 만들어 뒀다.

## 문제 상황

- 반응형 배치는 아직 초안이다. 1920 화면과 세로 화면을 직접 만져봐야 제대로 된 기준이 나올 것 같다.
- 관계도 선, 패널 크기 조절, 설정이나 부가 옵션 UI 작업은 아직 못했다.
- Pretendard 폰트를 Figma MCP가 인지하지 못하는 문제 때문에 그 부분은 내가 직접 수정해야한다.

## 내일 계획

- 1920×1080과 1080×1920 화면부터 직접 배치를 잡아본다.
- 괜찮은 패턴이 나오면 다른 화면에도 같은 방식으로 적용한다.
- 남아 있는 관계도와 UI를 이어서 정리한다.
