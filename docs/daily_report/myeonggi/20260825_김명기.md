## 실적

- YouTubed에서 Figma Design System 강의를 찾아 들으면서 디자인 시스템 구축
- Cover, Foundations 등 디자인 시스템을 명확히 보여주고 포트폴리오로 활용할 수 있는 기반도 마련
- AI가 만들어서 난잡하고 사용처가 불확실한 컴포넌트 재설계

## 문제 상황

- 기존 Button은 label-only 상태라서 강의에서 다룬 leading·trailing icon, Loading, Spinner와 별도 Icon Button이 아직 없다.
- 기존에 만든 16px·20px 아이콘 variant는 최종 크기 기준과 맞지 않아 24px·16px 기준으로 교체해야 한다.
- 최신 IBM UI Icon Library를 AML RADAR에 연결하고 필요한 아이콘을 가져오는 작업은 아직 완료하지 못했다.
- Button은 Black 화면에서만 일부 확인했으며 White 화면과 실제 Toolbar 사용 상황 검증이 남아 있다.

## 내일 계획

- 최신 IBM UI Icon Library를 AML RADAR에 연결한다.
- 실제로 자주 사용할 Search·Filter·Sort·Move·Panel·상태 아이콘부터 24px·16px variant로 정리한다.
- Spinner를 먼저 만든 뒤 Button에 leading·trailing icon과 Loading property를 추가한다.
- 40×40 Standard와 32×32 Compact Icon Button을 만들고 실제 Figma 화면에서 검수한다.
