## 실적

- Figma Design System 강의를 이어서 학습하며 AML RADAR의 Color·Number·Typography 변수와 Dark·Light mode 구성을 직접 점검
- Figma에서 Divider 단계 순서를 `Primary → Secondary → Tertiary`로 바로잡고 Foundation variable system을 v0.1 기준으로 동결
- 팀 회의에 참여해 pattern 분류와 pattern 외 이상거래 판별을 분리하는 2단계 구조를 검토하고, Frontend Alert 생성을 위한 거래 block 복원 문제가 남아 있음을 확인

## 문제 상황

- 대상 사용자가 감독기관인지 개별 은행인지, L1·L2·관리자 권한과 은행 통보 범위가 확정되지 않아 화면과 Userflow를 확정하기 어렵다.
- tree 모델의 거래 분류 결과만으로는 같은 Alert를 구성하는 연결 거래 block을 알 수 없어, 분류 뒤 block을 복원하는 후처리 방식과 API contract가 필요하다.
- Foundation은 동결했지만 실제 consumer에서 Button·Loading·상태 표현을 검증하는 컴포넌트 제작은 아직 시작하지 못했다.

## 내일 계획

- 최신 전제를 기준으로 AML RADAR 사용자 중심 FigJam Flow를 다시 정리한다.
- 미확정 역할과 기능은 확정된 흐름과 섞지 않고 `TBD/FUTURE`로 분리한다.
- Userflow와 화면 구조를 정리한 뒤 첫 컴포넌트 bundle 제작을 준비한다.
