## 실적

- 표의 열 너비가 행마다 어긋나던 문제를 해결했다. 각 열의 너비를 한 곳에서 정해 두고 모든 행이 그 값을 따르도록 바꿨고, 위험도·유형·처리상태를 표시하는 부품을 새로 만들었다.
- 키보드로 화면을 이동할 때 "지금 여기 있다"를 보여주는 표시를 고쳤다. 기존에는 버튼 바깥에 테두리를 그려서 화면 맨 끝 버튼에서는 표시가 잘려 보이지 않았고, 이는 접근성 기준 위반이었다. 버튼 안쪽 네 모서리에 표시하는 방식으로 바꾸고 버튼·입력창·체크박스 등 5종에 똑같이 적용했다.
- 왼쪽 메뉴를 5개에서 4개로 정리했다. 조사 메뉴를 에피소드에 합치고 알림 메뉴를 추가했으며 모델 성능 메뉴는 뺐다. 아이콘은 중복 21개를 정리해 세 가지 크기로 정돈했고, 입력창 아래 안내문구가 잘리던 문제도 원인을 찾아 고쳤다.

## 문제 상황

- 글자와 배경의 색 대비를 검사하는 방법 자체가 틀렸던 것을 중간에 발견해 바로잡았다. 우리 화면은 어두운/밝은 테마가 여러 개인데 한 가지 테마 기준으로만 계산하고 있었다.
- 다시 계산해 보니 밝은 테마와 버튼을 누른 상태에서 글자가 배경에 묻혀 잘 안 보이는 곳들이 나왔다. 기준치에 못 미치는 수준이라 색을 조정할지 판단이 필요하다.
- 버튼 중 "누르면 상태가 바뀐 채로 유지되는 버튼"이 어떤 것인지 분류가 아직 안 끝났다. 14개가 미정이며, 확정 전까지 동작은 건드리지 않았다.

## 내일 계획

- 미정 상태인 버튼 14개의 동작 분류를 확정한다.
- 왼쪽 메뉴 아이콘 선정을 마무리하고, 메뉴를 하나 없앤 여파로 화면에서 잘못 표시되는 곳이 없는지 점검한다.
- 팀에서 알림 목록 표의 항목이 확정되면 실제 표 너비를 재고, 화면 크기별 배치 기준을 정한다.
