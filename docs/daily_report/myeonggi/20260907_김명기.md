## 실적

- 회의 이후 사이드바에 잘못 들어가 있던 메뉴 이름을 고치고, 아이콘을 뜻이 바로 읽히는 것으로 교체했다.
- 백엔드에서 인계받은 API 문서를 바탕으로 거래 패턴 유형을 정립했다.
- 사용자 흐름 문서의 메뉴 구조를 실제 화면에 맞춰 정리했다. 담당 등급으로 묶여 있어 은행 조직도처럼 읽히던 것을 대시보드·수집·알림·에피소드·계정 순서로 바꾸고, 시연 범위 밖인 관리자 통보 항목 3개는 뺐다.

## 문제 상황

- 알림 목록 표에 들어갈 열이 확정되지 않아 표 너비와 화면 크기별 배치 기준을 못 정하고 있다. 위험도 기준값과 에피소드 항목이 필요하다.
- 에피소드로 들어가는 경로와 관계 그래프의 기준 단위가 미결이다. 그래프를 에피소드 기준으로 그릴지 알림 기준으로 그릴지에 따라 화면 배치가 달라진다.
- 9월 30일 범위에 로그인과 권한 관리를 넣을지 정해지지 않았다. 이 결정이 나야 만들 화면 목록이 확정된다.

## 내일 계획

- 정립한 거래 패턴 유형을 기준으로 카테고리별 표 프리셋을 만든다. 완료 기준은 카테고리마다 쓸 표 형태가 정해지는 것이다.
- 앱 기본 골격과 화면 이동 구조를 만든다. 완료 기준은 왼쪽 메뉴에서 각 화면으로 이동되는 것이다.
