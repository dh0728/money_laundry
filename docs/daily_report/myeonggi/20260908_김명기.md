## 실적

- 글자 스타일 체계를 정리했다. 크기·굵기·줄간격 기준이 빠져 있어 화면마다 글자가 제각각이던 문제를, 7개 그룹 92개 기준으로 다시 묶어 해결했다. 옛 이름으로 남아 있던 749곳도 새 기준에 다시 연결했다.
- 아이콘 라이브러리를 정리했다. 아이콘을 16·24·32 세 가지 크기로 쓰는데 크기별 개수가 5개 어긋나 있었다. 빠진 크기를 IBM 원본에서 받아 각 200개로 맞추고, 세 목록을 같은 순서로 정렬했다.
- 화면 골격과 반응형 구조를 만들었다. 일반 모니터·와이드 모니터·세로 모니터 세 기준으로 여백과 왼쪽 메뉴 동작을 정하고, 대시보드에 쓸 카드와 패널의 구분 기준을 세웠다.
- 브랜드 색을 파랑으로 바꾸는 작업은 잠정 중단했다. 순수한 파랑을 넣어보니 밝은 화면에서는 촌스럽다는 반응이 나왔고 어두운 화면에서는 글씨 대비가 기준의 절반도 안 됐다. 색상 재료에 밝은 단계 208개를 새로 만들어뒀고, 오늘은 기존 연두+검정으로 화면 작업을 이어갔다.

## 문제 상황

- 각종 표 프리셋을 아직 만들지 않았다. 예를 만들어봐야 표 너비와 화면 크기별 배치를 정할 수 있다.

## 내일 계획

- 대시보드 상단 지표 카드와 그 안에 들어갈 작은 뱃지를 만든다. 완료 기준은 지표 카드 4개가 대시보드 화면에 실제로 배치되는 것이다.
- 표 컴포넌트를 만든다. 완료 기준은 거래 패턴 유형별로 쓸 표 형태가 정해지는 것이다.
- 왼쪽 메뉴에서 각 화면으로 이동되는 골격을 완성한다. 완료 기준은 메뉴를 눌러 화면이 바뀌는 것이다.
