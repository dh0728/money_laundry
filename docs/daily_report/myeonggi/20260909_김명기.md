## 실적

- 버튼·체크박스·라디오에서 눌림 상태를 없애고 마우스 올림 방식을 바꿨다. 눌림은 1초도 안 되는 순간을 위해 따로 만들어 두는 것이라 관리 비용만 컸고, 마우스를 올렸을 때의 표시가 흐릿해 잘 안 보이던 문제도 있었다. 이제 마우스를 올리면 배경색과 글자색이 서로 바뀌어 확실히 구분된다. 버튼 조합이 90개에서 72개로 줄었다.
- 입력창에 마우스 올림 상태를, 토글 버튼에 키보드 초점 표시를 새로 만들었다. 입력창은 화면에 크고 오래 떠 있어서 버튼처럼 색을 뒤집으면 과하다고 판단해 배경만 한 단계 밝아지게 했다. 토글 버튼은 키보드로 이동했을 때 지금 어디에 있는지 표시가 아예 없어서 다른 요소와 같은 방식으로 채웠다.
- 오늘 회의에서 요구받은 기존 서비스 디자인 조사를 시작했다. 국내외 자금세탁방지 제품 스무 곳을 훑어 실제 화면을 볼 수 있는 곳을 찾았고, 비교 기준 아홉 가지를 먼저 정한 뒤 네 곳을 관찰했다. 기준은 모서리 형태, 배경 밝기, 메뉴 위치, 표 밀도, 위험도 표시 방식, 관계 그래프 유무, 강조색, 글꼴, 경보 색이다.

## 문제 상황

- 자금세탁방지 제품들은 화면을 왜 그렇게 설계했는지를 공개하지 않는다. 스무 곳을 확인했는데 로고와 색 규정 같은 브랜드 문서만 있고, 화면 설계 근거를 적어 둔 곳은 한 곳도 없었다. 그래서 남의 설명을 인용하는 대신 여러 제품 화면에서 반복되는 것을 직접 세는 방식으로 바꿨다. 회의에서 이야기한 대로 각자 좋게 본 화면을 보내 주시면 함께 비교하겠다.
- 지금까지 관찰한 세 제품이 서로 반대 방향이라 아직 결론을 못 낸다. 한 곳은 각진 모서리에 정보가 빽빽하고, 두 곳은 둥근 모서리에 여백이 넓다. 배경도 밝은 쪽 둘, 어두운 쪽 하나로 갈린다. 네 곳 이상에서 같은 것이 반복돼야 근거로 쓰기로 기준을 정해 둬서, 표본을 더 모아야 한다.

## 내일 계획

- 조사 표본을 네 곳 이상으로 늘린다. 완료 기준은 아홉 개 기준 중 반복해서 확인되는 항목을 추려 팀에 공유할 수 있는 상태가 되는 것이다.
- 표의 기준을 정한다. 열 순서와 정렬 방향, 행 높이, 마우스 올림과 선택 상태의 모양까지 정하고, 실제 표는 개발 단계에서 라이브러리를 붙이기로 한다. 완료 기준은 대표 행 두세 개로 이 기준이 화면에 나오는 것이다.
- 대시보드 상단 지표 카드를 배치한다. 완료 기준은 지표 카드 네 개가 대시보드 화면에 실제로 놓이는 것이다.
