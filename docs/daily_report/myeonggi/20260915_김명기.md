## 실적

- 화면 설계 초안 27장을 한 장씩 검토해 역할별 행동, 필요한 데이터, 빈 화면·로딩·오류 상태와 표·필터·관계 그래프의 동작을 구체화했다. 확정한 내용을 반영해 역할과 상태별 화면 38장을 만들고, 전체 화면이 1920×1080에서 겹치거나 잘리지 않는지 검사했다.
- 완성된 화면을 디자인 파일에 옮겨 이전안과 새 안의 이름을 정리하고, 같은 화면의 역할·상태 차이를 옆으로 비교할 수 있게 재배치했다. 새 안을 다시 직접 보면서 로그인·대시보드·알림 목록·알림 상세를 고쳤고, 에피소드 상세 개요부터는 내일 이어서 검토한다.

## 문제 상황

- 서비스 대상이 은행에서 금융감독기관으로 바뀌었지만 로그인은 과거에 합의한 이메일 방식이 남아 있다. 기관 통합 계정을 사용할지 현재 방식을 유지할지에 따라 화면과 서버 작업이 함께 달라지므로 팀 합의가 필요하다.
- 관계 그래프와 판단 근거 화면에 필요한 데이터 중 실제로 서버와 모델에서 제공되는 범위가 아직 모두 정해지지 않았다. 화면에 표시할 값과 생성 주체를 백엔드·모델 담당자분들과 확인해야 한다.

## 내일 계획

- 에피소드 상세 개요부터 남은 화면을 순서대로 검토한다. 완료 기준은 에피소드 상세·알림·설정·계정 화면의 수정 사항과 보류 사항이 모두 기록되는 것이다.
- 전체 검토가 끝나면 확정된 수정 사항으로 다음 화면 설계안을 만들고 다시 검사한다. 완료 기준은 화면 번호를 사용자 흐름에 맞게 다시 매기고, 역할별 화면을 나란히 배치한 뒤 모든 화면의 겹침·넘침·잘림을 확인하는 것이다.
