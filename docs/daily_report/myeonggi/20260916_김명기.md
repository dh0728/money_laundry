## 실적

- 전날 만든 화면을 이어서 v8부터 v11까지 반복 개선해 v11을 완성했다. 이후 팀 회의에서 완성된 v11 화면을 직접 보여주며 화면별로 검토했고, 개인 대시보드와 기관 전체 현황판의 역할을 분리하며 개인화 화면 외에는 담당 역할과 관계없이 같은 알림·에피소드 화면을 사용하기로 정리했다.
- 회의에서 확정된 변경 사항을 v12에 반영했다. 목록 조건은 태그처럼 누적되는 검색 조건으로 바꾸고, 알림 이력을 개요 하단에 합쳤으며, 발생해서는 안 되는 변경 충돌 화면을 제거하고 중간발표의 역할 전환은 로그아웃 후 다른 계정으로 다시 로그인하는 흐름으로 정리했다.
- 관계 그래프의 정보 표현을 다시 설계했다. 거래 방향은 항상 화살표로 표시하고 선 굵기는 금액, 색은 위험도, 글자는 거래 건수를 나타내도록 분리했으며, 여러 거래를 묶은 구간과 선택한 두 계좌의 거래 내역을 함께 확인할 수 있는 3열 화면을 v12에 반영했다. 작업 말미에는 이전 버전과 최신 문서를 바탕으로 브라우저에서 실행되는 v13 초안을 만들었고, 추가 사용성 검토가 필요한 상태이다.

## 문제 상황

- 기관 전체 현황판과 개인 대시보드를 분리하기로 했지만 기관 전체 화면에 어떤 지표와 범위를 보여줄지는 아직 확정되지 않았다. 중복 없는 지표 구성을 위해 기획 관점의 팀 합의가 필요하다.
- 관계 그래프가 조사에 꼭 필요한 표현인지, 선택 범위 밖으로 빠져나가는 자금 흐름을 어떻게 보여줄지는 결론이 나지 않았다. 모델도 탐지 유형의 확률만 제공하고 해당 유형을 구성한 계좌와 거래 근거는 제공하지 않아 백엔드·모델 담당자분들과 실제 제공 범위를 확인해야 한다.
- 금융감독기관용 로그인에 기관 통합 계정을 사용할지 자체 계정을 유지할지 정해지지 않았다. 인증 방식에 따라 로그인 화면과 서버 작업이 함께 달라지므로 팀 결정이 필요하다.

## 내일 계획

- v12와 실행 가능한 v13 화면을 직접 보면서 마우스로 위치를 짚어 남은 사용성 문제를 화면별로 검토한다. 완료 기준은 사이드바·상단 영역·대시보드·목록·상세·설정·조사 도우미의 수정 사항과 보류 사항을 모두 기록하는 것이다.
- 검토 결과를 다음 화면 설계안에 반영하고 주요 업무 흐름을 다시 검사한다. 완료 기준은 대시보드에서 업무를 찾고 알림을 검토해 에피소드 조사로 이어지는 흐름에서 겹침·잘림·잘못된 이동이 없는 상태이다.
