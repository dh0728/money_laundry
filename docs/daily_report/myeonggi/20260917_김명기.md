## 실적

- v12·v13 화면을 직접 보면서 사이드바·상단 영역·대시보드·목록·상세·설정·조사 도우미의 사용성 문제를 화면별로 짚어 디자인 파일에 정리했고, 이를 반영해 v14·v15를 만들었다. 로그인 화면은 배경 전체를 계좌 네트워크 애니메이션으로 채웠고, 조사 도우미는 화면 위에 떠 있던 버튼 대신 상단 검색창 옆 버튼으로 필요할 때만 열도록 바꿨다.
- 관계 그래프를 모델링 담당 팀원이 전달한 실제 데이터(IBM 공개 자금세탁 데이터셋)로 다시 만들었다. 탐지 유형별 대표 사례를 하나씩 뽑아 세탁 거래는 빨간색, 정상 거래는 회색, 선 굵기는 금액으로 표시했고, 시간축으로 거래를 발생 순서대로 따라갈 수 있게 했다. 그래프 모양은 로그인 화면의 네트워크 표현과 맞춰 화면 전체의 디자인을 통일했다.
- v15를 직접 검토해 수정 사항을 정리하고 v16에 반영했다. 두 계좌 사이의 거래 상세는 팀원 제안대로 흐름 띠 차트(산키 차트)로 바꿔 양방향 거래와 금액 차이를 한눈에 보게 했고, 계좌 하나를 선택하면 그 계좌를 중심으로 들어오고 나간 거래가 모두 보이게 했다. 상단 검색창에서는 알림·에피소드·계좌·설정 항목을 모두 찾을 수 있게 했다.

## 문제 상황

- 기관 전체 현황판에 보여줄 지표는 오늘 회의가 없어 아직 정해지지 않았다. 지금은 분석 대상 데이터 규모와 탐지 유형 분포로 임시 구성했으며, 기획 관점의 팀 합의가 필요하다.
- 팀원 데이터에는 의심 계좌와 바로 연결된 계좌까지만 있어서, 그 바깥 2~5단계 주변 계좌와 개별 거래 시각은 화면 확인용으로 임시로 만든 값이다. 실제 서비스에서 어느 범위의 계좌와 거래 근거를 받을 수 있는지 백엔드·모델 담당자분들과 확인해야 한다.
- 금융감독기관용 로그인에 기관 통합 계정을 쓸지 자체 계정을 유지할지는 여전히 결정되지 않았다. 로그인 화면과 서버 작업이 함께 달라지므로 팀 결정이 필요하다.

## 내일 계획

- v16 화면을 직접 보면서 문제가 있는 부분만 캡처해 수정 사항을 정리한다. 완료 기준은 대시보드·목록·상세·관계 그래프·알림·설정·조사 도우미에서 발견한 수정 사항과 보류 사항을 화면별로 모두 기록하는 것이다.
- 정리한 수정 사항을 다음 버전에 반영하고 주요 업무 흐름을 다시 검사한다. 완료 기준은 대시보드에서 업무를 찾고 알림을 검토해 에피소드 조사로 이어지는 흐름에서 겹침·잘림·잘못된 이동이 없는 상태이다.
