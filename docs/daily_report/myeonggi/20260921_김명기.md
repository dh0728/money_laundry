## 실적

- v21 프로토타입을 실제 업무 화면처럼 사용할 수 있도록 대시보드·거래 목록·Alert 상세를 중심으로 다시 다듬었다. 대시보드의 기본 색을 흰색과 회색으로 정리하고 사용자가 가리킨 요소에만 빨간색 강조가 나타나도록 했으며, 하나의 기간 설정이 세 그래프에 함께 적용된다는 점이 명확히 보이게 구성했다. 기간 해제, 범례, 필터 버튼, 검색창 최소 너비 등 세부 동작도 함께 수정했다.
- Transactions는 소유주·계좌·거래를 별도 열과 계층으로 구분하고 전체 펼치기, 행 선택 해제, Alert·Episode 상호 이동, 화면을 따라오는 가로 스크롤을 적용했다. 상세 거래에는 소유주와 계좌 바로가기를 연결했고, 자금 흐름에는 거래별 날짜와 금액을 선 중앙에 표시했다. 사이드바 전환, 탭 이동 애니메이션, 조사 도우미 위치, 시맨틱 색상과 마우스 조명 범위도 정리해 좁은 화면과 긴 화면에서도 주요 기능을 사용할 수 있게 했다.
- 다크 모드와 라이트 모드, 넓은 화면과 가로폭이 좁은 화면, 세로로 긴 화면에서 전체 화면을 점검했다. 자동 테스트 306개와 lint·build를 통과한 결과를 `fe/prototype` 브랜치에 커밋·푸시하고 PR #98을 만들었다. 프로토타입 폴더는 `01`~`21` 순서로 정렬되도록 한 자리 버전명도 정리했다.

## 문제 상황

- 팀장 검토에서 Transactions 진입 시 `거래 내역`이라는 한국어 제목이 바로 보여야 한다는 의견을 받았다. 현재 테이블은 소유주·계좌·거래의 계층 구조가 한눈에 들어오지 않으므로, 이전의 3열 섹션 구조를 바탕으로 세 단계가 명확히 구분되도록 다시 설계해야 한다.
- 기관 현황 지표, 계좌·거래 데이터 제공 범위, 로그인 방식 등 백엔드·정책과 연결된 항목은 아직 팀 합의가 필요하다. 미확정 안내 문구는 실서비스 형태의 프로토타입에서 제외했으며, 결정이 필요한 내용은 별도 문서로 관리해야 한다.

## 내일 계획

- v22 제작 시 Transactions의 화면 제목을 `거래 내역`으로 표시하고, 소유주·계좌·거래를 3열 섹션 구조로 재구성한다. 완료 기준은 화면 진입 즉시 거래 내역 화면임을 알 수 있고 세 단계의 소속 관계를 별도 설명 없이 파악할 수 있는 상태이다.
- 백엔드·모델 담당자와 확인해야 하는 정책 및 데이터 항목을 별도 문서로 분리한다.
