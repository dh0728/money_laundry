## 실적

- 팀 피드백에서 이해하기 어렵다고 나온 기관 대시보드의 의심 거래 구성·패턴 분포 차트를 관계 막대로 바꿈. 넓은 화면에서는 거래 건 비율 기둥과 연결선, 알림 막대로 보여 주고 720px 미만에서는 세로 깔때기로 보여줌. 이해하기 어렵다던 이중 도넛은 없앰.
- '내 담당' 대시보드를 새로 정리함. 상단 지표를 기관 전체 화면과 같은 형태로 맞추고, 업무를 검토 전·검토 중·종결 3열로 나눴으며, 위험 점수·경과일·최근 탐지·의심 확률로 정렬할 수 있게 함. 요약 문구는 규칙에 따라 만든 임시 데이터.
- 처리 상태 '신규'는 들어온지 며칠 지났는데 오해하기 만드니까 Alert에서는 '검토 전', Episode에서는 '조사 전'으로 바꾸고 패턴 태그 색을 통일했으며, 좁은 화면에서는 AI 패널이 닫힌 채 시작하게 함. v24 변경을 커밋 6개로 나눠 `fe/prototype` 브랜치에 올렸음.

## 문제 상황

- 관계 표현이 넓은 화면(연결선)과 좁은 화면(그라데이션)에서 서로 다르다. 어느 쪽으로 맞출지 팀의 의견이 필요함.
