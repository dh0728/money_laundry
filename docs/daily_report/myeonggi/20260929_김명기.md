## 실적

- 화면 설계서의 세부 화면과 선택 상태를 보강함. 대시보드, 거래·계좌 상세, Alert·Episode 탭과 그래프를 다크 모드 고해상도로 다시 캡처하고 화면 ID·흐름 ID·설명을 맞춰 26쪽에서 41쪽으로 늘림. 제출일 파일명으로 PDF를 교체하고 Jira MONEY17-157에 기록함.
- 자금 흐름 그래프의 화면 맞춤 배율을 100%로 고정하고 휠 확대 폭을 줄임. 떨어진 계좌 묶음의 간격도 좁혀 그래프를 읽기 쉽게 조정함.
- 백엔드 V12를 반영해 조사 화면과 대시보드의 실제 API 연결을 보강함. Alert 판정·Episode 편입 명령, 그래프 live 어댑터, 테마 체계와 화면별 배치를 정리하고 RDR 9000 요약을 다듬음. Frontend 통합 후 dev에 반영함.
- Alert 거래 선택·제외와 Episode 연결 Alert 선택·해제 UI를 구현함. 해제 후 Alert가 1건 이하이면 Episode를 해체해 각 Alert를 단독으로 돌리고, 거래 제외·Episode 해체에 2차 확인을 추가함. 해당 화면의 mock 동작과 테스트를 검증함.

## 문제 상황

- 거래 제외·Episode 해체는 Frontend mock 동작과 실제 서버 저장을 따로 구현해야 했음. Backend 담당자에게 연동 요구사항을 전달함.
- 전날 막혔던 테스트 서버 정보·계정 문제는 해소됨. 두 역할의 서버 동작은 Backend 담당자가 정상이라고 전달했으나, 내 시연 동선은 직접 재확인하지 못함.

## 내일 계획

- 조사자·관리자 계정으로 로그인부터 Alert 판정, Episode 생성·편입·해체, 거래 제외, 목록 재조회까지 시연 동선을 직접 확인함.
- 화면 설계서와 실제 웹앱의 차이를 확인하고 중간발표 시연·리허설에 필요한 화면과 설명을 정리함.
