## 실적

- UI 전면 재설계 업무를 Jira 에픽으로 등록함(기한 10/18).
- 재설계의 기본 방향 세 가지를 정함. 새 화면은 기존 시연 화면을 유지한 채 별도 경로로 만들고 완성 후 전환하며, 그래프 배치 방식을 정하고, 임시 저장은 서버 기록으로 남기되 입력 중인 내용만 브라우저에 보존함.

## 문제 상황

- 룰엔진 세부 설계와 API 제공 시점이 미정임. 룰엔진 화면 작업이 10/19에 시작하므로 그 전에 Backend·Infra 담당자의 설계가 필요하며, 멘토가 제안한 트리 기반 룰 추출을 더할지는 모델 담당자와 함께 정해야 함.
- 관리자 역할을 정했지만 현재 API는 사건 처리를 담당 직원에게만 허용함. Backend 담당자가 관리자 권한을 넓혀야 하며, 다른 담당자 Alert를 묶을 때의 알림과 Episode 별도 테이블에 따른 API 변경도 확인이 필요함.
- 재설계 기한(10/18) 안에 만들 화면 범위가 미정임. 조사 흐름(목록 → Alert 상세 → Episode)을 먼저 만드는 안을 두고 팀장과 범위를 정해야 함.

## 내일 계획

- 팀장 목업에 의견을 더해 Alert·Episode 상세에 들어갈 정보를 정리함. 완료 기준은 항목별로 각 값이 기존 응답·서버 추가 계산·새 테이블 중 어디서 오는지 구분하고, 목업과 다르게 갈 부분을 정하는 것임.
- 사건 개요 첫 카드 이름을 팀에 묻고, Backend 담당자에게 관리자 권한 확대·묶기 알림 등 필요한 API 변경을 전달함. 유성희 멘토님께 Frontend 조언 약속을 따로 잡음. 완료 기준은 항목별 담당자 확인과 일정임.
