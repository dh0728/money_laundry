- Alert·Episode 상세 개요 탭을 다시 설계함. 완료 기준은 조사자가 먼저 보는 정보와 판단 순서를 정하고, 각 값이 기존 응답·서버 추가 계산·새 계산 중 어디서 오는지 구분한 정리를 박지원·송동현 님께 전달할 수 있는 상태로 만드는 것임.
