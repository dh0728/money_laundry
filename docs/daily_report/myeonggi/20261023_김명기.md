## 실적

- 손그림으로 세탁기 형태의 홈과 선택·검색 → 정보 확인 → 근거·관계 분석 → 판단·저장의 4단계 조사 흐름을 설계했다.
- 거래내역·탐지 알림(Alert)·에피소드(Episode) 목록을 분리하고, 다중 선택 후 개별 확인과 상위 묶음 생성을 구분하도록 설계했다.
- 정보 확인은 타임라인·비교 테이블, 관계 분석은 패턴별·소유주별 그래프와 거래 테이블을 함께 보는 구조로 설계했다.
- 묶기 사유를 저장한 뒤 검토를 완료하도록 정하고, 대시보드는 내 업무·전체 현황 탭과 상태별 업무 보드로 설계했다.

## 문제 상황

- 여러 대상의 의견 저장 방식 등 세부 동작은 추가 설계가 필요하다.
