## 실적

- 탐지 알림(Alert)·거래·에피소드(Episode) 목록 카드를 하나의 공통 카드로 설계했다. 분석가가 목록에서 바로 판단하는 데 필요한 정보(위험도, 패턴과 확률, 거래 기간·건수·금액, 담당자, 처리 상태, 경과일)만 남기고, 상세 화면에서 볼 수 있는 내용은 뺐다.
- 여러 건을 골라 한 번에 판단하는 흐름을 화면에 옮겼다. 카드와 표에 체크박스를 넣고, 화면 오른쪽 아래에 선택한 개수를 보여 주는 판단 버튼을 두었다.
- 목록이 길어져도 상단 탭과 화면 제목은 고정되고 본문만 스크롤되도록 화면 구조를 바꿨다.

## 문제 상황

- 부품 단위 설계에 시간을 많이 쓰느라, 팀이 여러 번 먼저 요청한 전체 화면 와이어프레임이 아직 나오지 않았다. 지금은 구현 완료보다 화면 흐름을 팀과 맞추는 일이 먼저라는 점을 늦게 받아들였다.

## 내일 계획

- 전체 화면 와이어프레임을 먼저 완성해 팀과 흐름을 맞춘다.
