## 실적

- 버튼·태그 색 기준을 화면에 적용하고 다크모드 색 깨짐을 고쳤다.
- 거래 상세를 '보낸 계좌 → 거래 → 받은 계좌' 화면으로 새로 만들었다.
- 전체 대시보드를 정리하고, 위험 점수 4구간과 실제 코드 기준 9개 유형 분포를 넣었다.

## 문제 상황

- 대시보드 유형 목록이 처음엔 코드와 달라(5개) 9개로 다시 맞췄다.

## 내일 계획

- 나머지 화면의 필터 버튼을 각 영역으로 옮긴다.
- 발표용 이전/현재 화면 비교 자료를 준비한다.
