## 실적

- 상태·패턴·점수 태그를 StatusTag, PatternTag, ScoreTag로 나눠 만들고, 기존 화면 태그를 이 컴포넌트로 바꿔 달았다. 경과일은 3일 이하 노랑, 3일 초과 7일 이하 주황, 7일 초과 빨강으로 맞췄다.
- 적용 중인 필터는 FilterTag로 두었다. 태그를 누르면 해제되고, 필터가 두 개 이상이면 '모두 지우기'가 나온다.
- Alert·Episode 목록에 카드 보기와 표 보기를 나누고, 전환 라벨을 '카드 보기' / '표 보기'로 달았다. Episode 표 화면도 새로 만들었다.
- 기존 화면 25개를 점검해 FilterTag 색을 브랜드 색에 맞추고, 표 칸을 고치고, 겹친 레이어를 정리했다. 전역 AppHeader는 빼서 화면을 다시 맞췄다.

## 문제 상황

- 경과일 기준이 화면에서 세 단계로 바뀌어서, 구현할 때 기존 코드의 5일 기준도 맞춰야 한다.

## 내일 계획

- 화면 점검에서 남은 오류를 고치고, 아직 안 그린 화면을 이어서 그린다.
