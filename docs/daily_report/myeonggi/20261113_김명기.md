## 실적

- 역할별 색 변수를 처음부터 다시 정리해 피그마에 반영했다.
- 태그 구성을 현재 색에 맞게 다시 짰다. 노랑과 주황은 amber로 합치고, 경과일은 1주 이내와 1주 초과 두 단계로 줄였다.
- 태그 호버에 씌우던 회색 겹은 빼고 너비는 내용에 맞췄다. 소유주 분석 표에서 태그가 보이게 고치고, 열람 전 태그는 점선 테두리로 두었으며, 추가 탭의 패턴 열을 넓혔다.
- 색을 한 차례 반영한 뒤, 노랗게 변한 중성 카드와 버튼 호버, 겹친 노랑 태그를 고쳤다.
- 피그마에 v3 색 토큰을 반영했다. 라이트는 #0196fc, 다크는 #0d99ff이고 글자는 흰색이다. 라이트·다크·Solarized 네 테마와 브랜드 색 네 가지(Sky, Violet, Pink, Lime)에 맞추고, 섹션 배경과 대시보드 막대 색도 바로잡았다.

## 문제 상황

- 정상 판정 카드가 아직 초록 배경이 아니다.
- 사이드바를 접으면 본문이 전체 너비를 쓰지 못한다.
