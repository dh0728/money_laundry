## 실적

- HI-Large 학습 모델이 다른 두 데이터셋(SAML-D·TransXion)에서 작동하지 않는 원인 분석 — 세 데이터를 같은 형식·같은 규칙으로 정리하고 현재 피처를 재계산(원 구현과 불일치 0)한 뒤 전이 실험 수행
- 결제방식 피처가 주된 원인이 아님을 확인 — 결제방식을 쓰지 않는 구성으로 학습해도 전이 성능은 무작위 수준이고, 오히려 넣으면 순위 성능이 더 떨어짐
- 피처 부족도 아님을 확인 — 같은 피처로 각 데이터에서 다시 학습하면 성능이 나오고, 자동 선택에서도 현재 피처가 상당수 뽑힘
- 진짜 원인 규명 — 데이터셋마다 정상 거래의 모습 자체가 다름. HI-Large는 같은 상대에게 같은 금액을 반복하는 비율이 91.9%인데 다른 두 데이터는 1% 미만이고, "처음 거래하는 상대"는 데이터셋에 따라 신호 방향이 반대. 현재 피처 7개가 방향 역전
- 결제방식과 세탁의 연관도 데이터마다 다름 — HI-Large는 ACH가 세탁의 87%, SAML-D는 현금 입출금, TransXion은 차이 없음. HI-Large에서는 다른 피처로 ACH 여부를 맞힐 수 있어 결제방식을 빼도 간접 정보가 남음
- SAML-D의 AP 1.0은 누수가 아님을 검증 — 라벨 섞기, 거래 시점 이전 이력만 사용, 과거 미등장 계좌끼리의 거래로 각각 확인. 다만 당일 마감 정보에 기대고 있어 거래 시점 정보만 쓰면 0.755로 떨어지므로, SAML-D 내부 성능은 변별력 없는 지표로 결론
- 결제방식 유지·제거 판단 정리 — 패턴 양성만 보면 결제방식의 기여는 주로 비ACH 거래의 오탐 제거지만 그만큼 의존이 생겨, 양성의 결제방식만 바꾸면 재현율이 97%에서 50~60%대로 떨어짐. HI-Large 성능이 목표면 유지, 비ACH 경로의 세탁까지 잡으려면 제거가 안전하다고 정리
- 대안 구성 기각 — 세 데이터 공통으로 선택된 5개 피처만 쓰는 구성은 전이·자체 성능 모두 미달. TransXion의 지급액=수취액 피처는 생성기 흔적으로 판단해 일반화 평가에서 제외


## 문제 상황

- V10 목표(정밀도 70% / 재현율 65%) 여전히 미달 — 현 결합 모델이 정밀도 71.9% / 재현율 62.3%이고 병목인 무패턴 양성(재현율 약 9%)은 이번 분석에서 다루지 않음
- 어떤 피처 구성으로도 교차 데이터 전이는 무작위 수준 — 피처 보강이나 데이터셋 내 백분위 변환으로도 해결되지 않음
- 실제 결합 모델을 다시 돌린 것이 아니라 피처를 재계산해 LightGBM으로 확인한 결과이고, 구성마다 시드 하나
- 다단계 경로 같은 그래프 구조 피처는 포함하지 않음
- 세 데이터 모두 합성이라 전이 평가가 생성기 사이의 차이를 재는 쪽에 가깝다는 해석상 한계
