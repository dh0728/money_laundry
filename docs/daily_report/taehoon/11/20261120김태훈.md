## 실적

- 우리 18종과 팀원 17종 피처 비교 — 합집합 26종(공통 9, 우리만 9, 팀원만 8). 팀원 전용 8종은 대부분 우리 18종의 정의 안에 간접적으로 들어 있고, 날짜에만 의존하는 1종만 기간이 바뀐 Test에서 맞지 않음
- 결합 모델에 팀원 구성을 넣어 비교 — 결합 AP는 우리 18종 0.981, 팀원 17종 0.971, 팀원 구성에 소유주 묶음을 더하면 0.980으로 동급. 우리 11종 GNN은 시드를 바꿔도 동일
- 무패턴 양성 재현율 측정 (학습에서 제외하고 사후 채점) — GNN 단독·트리 단독·결합 전부 0.1~3.5%로, 패턴과 무패턴을 합친 전체 재현율은 53~60%에서 정체
- 트리 모델의 역할 규명 — 정밀도 90% 임계값에서 놓친 패턴을 1,652건 → 434건으로 줄이고 같은 재현율에서 오탐을 25~46% 줄이지만, 재현율을 우선하는 임계값에서는 GNN 단독과 차이 없음
- Test 정밀도가 낮게 나온 원인 규명 — 30일 주기 재투자(자기 계좌 이체) 거래가 10/30에 몰려 그날 오탐이 급증. 피처 구성 탓이 아니고 그날을 빼면 어떤 구성이든 68~77%, 자기이체 표시 피처를 더해도 해결되지 않음




## 문제 상황

- 무패턴 양성은 어떤 모델·구성으로도 잡히지 않아 전체 재현율 상한이 60% 수준
- 재투자 거래 처리 방침 미정 — 경보 대상에서 빼려면 결제방식 값을 쓰게 되고, 대안은 임계값을 정하는 검증 구간에 재투자 날을 포함시키는 것
