## 실적

- 결합(GNN + 트리)의 이득이 작다는 점을 정리 — 18종을 전부 GNN에 넣으면 단독 AP 0.968 대 결합 0.981로 격차가 좁고, 결합기 계수가 GNN 3.3 대 트리 0.2로 트리를 거의 쓰지 않음. 과거 결합 효과가 커 보였던 이유는 11종 GNN이 트리 전용 7종을 못 봤기 때문
- 차수 비교 문서를 팀원 검토대로 수정 — 차수 정의를 논문 기준(거래를 받는 계좌의 in-degree)으로 교체하고, "입력으로 쓰는 차수와 같은 값"이라는 오기를 정정, 학습량이 작아 두 모델의 우열을 판단할 수 없다는 점을 명시
- 논문 기준으로 재집계 — 두 모델 모두 차수 구간에 따라 재현율이 떨어지지 않아(SALT 88~91%, Multi 98~99%) 논문이 말한 고차수 구간 열화가 재현되지 않고, 두 모델의 격차도 구간과 무관
- HI-Large가 논문 데이터보다 훨씬 빽빽하다는 점 확인 — 패턴 양성의 절반, 정상 거래의 87%가 차수 100 이상 (논문 데이터는 1% 미만)
- 두 모델 동일 조건 40에폭 재학습 착수 — 입력·학습 대상·배치·주변 그래프·에폭 선택 기준을 전부 일치시키고 최적화 설정만 각 논문 부록대로 적용


## 문제 상황

- 권장 구성을 'GNN 18종 단독'으로 바꿀지 미결정
- 재학습이 시드 하나라, 두 모델 차이가 작게 나오면 우열을 판단할 수 없음
- 논문에 에폭 수가 본문·부록 모두 없어 학습량 대조가 불가능
