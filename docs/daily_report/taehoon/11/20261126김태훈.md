## 실적

- SALT-GNN 18종·논문 방식 6에폭 학습 완료 — 오류나 건너뛴 배치 없음. 최고는 4에폭이고 Test AP 0.975 / F1 0.906 / 정밀도 83.7% / 재현율 98.8%로, 앞서 끝난 GNN 실험 전부보다 F1이 높음
- Multi-FraudGT 18종·논문 실험 방식 자동 시작 — 당일 80에폭까지 검증, 최고는 60에폭(검증 AP 0.987 / F1 0.935)이고 중간에 내려간 값은 모두 다음 검증에서 회복
- 판넬 그림에 SALT 18종 추가 및 문구 정리 — 그림 속 모델 중 PR-AUC·F1 모두 최고
- 차수 구간별 두 모델 비교 — 확률 0.5 F1은 SALT가 모든 구간에서 높아 논문 주장과 같은 방향이지만, 정밀도를 90%로 맞추면 FraudGT 18종이 모든 구간에서 재현율이 높음(전체 98.5% 대 96.5%, 놓친 패턴 382건 대 903건). 논문 주장은 확률 0.5 F1에서만 재현된다고 결론
- 대시보드에 들어갈 요약 AI RAG기반 프롬프트 작성


## 문제 상황

- 두 모델의 우열은 아직 확정 불가 — 평가 구간과 양성 비율이 달라 중간 검증값으로 비교할 수 없음
- Multi-FraudGT 검증은 뽑은 거래 중 그래프 표본에 들어온 약 34%만 채점하므로 재현율이 과대평가됨
