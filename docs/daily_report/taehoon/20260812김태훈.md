## 실적

- HI-Medium/LI-Medium 스케일 확장, 교차 데이터셋 전이(54개 평가), HI+LI 합성 학습, calibration 분할, 패턴/허브 계층화 평가, 허브 피처·재균형 실험
- HI+LI 합성 학습이 최선의 실무 결과 도출(LI 성능 2.5배 개선, HI 손실 거의 없음), calibration 분할로 LI 정밀도 추가 개선
- 허브 계좌 관여 세탁 탐지를 못하는 현상 발견햣

## 문제 상황

- 허브 관여 세탁 거래가 GBT 거래단위 피처로는 원천적으로 탐지 불가(F1=0.0000) — GNN 쪽 다중 홉 구조 반영 필요
- HI-Large/LI-Large는 현재 머신 RAM(15.6GB)으로 부족 — out-of-core 도구 전환 필요
