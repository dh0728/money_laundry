## 실적
- HI-Medium+LI-Medium 합성데이터셋 학습테스트결과 LI데이터가 오히려 노이즈가 됨(기각)
- 논문 대비 EDA 수치 격차 재검토 — 일수 격차는 완전 해소, 세탁건수 격차는 일부 잔존(방향성 영향 없음)
- GFP 저비용 구조 피처 2종 추가 — HI-Small XGBoost F1 +8.4%p, 논문 벤치마크 격차 63% 축소
- 위 피처를 (3-way 합성+앙상블+calibration)에 결합 재실행 — 전 조합 개선,권장 모델이 LightGBM→XGBoost로 변경됨

## 문제 상황

- 허브계좌 블라인드 스팟 미해결 — 오늘 피처가 도움되는지 아직 미검증
