## 실적

- 1차 실증 완료 (HI-Small) — 계좌 단위 TransformerGNN으로 무패턴만 학습해보기
- 1차 결과: 무패턴 recall 0.0327 → 0.0523으로 1.6배 올랐으나 AP 0.0967 → 0.0579, 패턴 recall 0.1023 → 0.0769로 전체 성능은 하락 → 현재 설정에서는 순효과 음(-)
- 2차 실증 착수 (HI-Large) — 엣지 단위 지도학습으로 전환, train 거래 45.1M 기준 TransformerConv 2층 학습 중 (epoch 0 valid AP 0.5206)
- 기존 GBT 프로토콜과 동일하게 맞춰 gbt_base / gnn / gbt_emb 3군 비교 설계

## 문제 상황

- 1차 실험은 단일 시드라 결론을 확정할 수 없음
- GNN 엣지 피처를 13차원으로 줄여 GBT와 피처 수가 비대칭 → 임베딩 기여도는 gbt_base와 gbt_emb 비교로만 판단해야 함
