## 실적

- HI-Large 100만 train 구성 4자 비교 — 양성 전량 + 정상 무작위 대량 구성이 최고 (전체 AP 0.882 / 무패턴 AP 0.506), 기준선 0.752 대비 큰 폭 개선
- 무패턴 분포 시각화 EDA 분석
- 무패턴 5:5 클러스터 언더샘플링 기각 — 무패턴 AP 0.017로 현행(0.031)보다 하락, 클러스터 방식도 무작위와 동률

## 문제 상황

- GBT모델은 무패턴거래를 거의 못잡음
