## 실적

- HI-Large 100만건 CSSMC방식으로 추출 train비교 — 양성 전량 + 정상 무작위 대량 구성이 최고 (전체 AP 0.882 / 무패턴 AP 0.506)
- 무패턴 분포 확인 - 송금자 과거 송금 횟수가 잠자는 계좌와 허브로 쌍봉을 이루는 구조 확인
- 무패턴 5:5 클러스터 언더샘플링 기각 — 무패턴 AP 0.017로 현행(0.031)보다 하락, 클러스터 방식도 무작위와 동률

## 문제 상황

- 채택 후보 구성은 valid를 두지 않는 설계라 F1은 참고치임.
- 데이터 셋은 HI-Large로 고정(꼬리부분 제거), CSSMC 다운샘플링으로 학습, train은 다운샘플링X
