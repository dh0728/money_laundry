## 실적

- KYC 조인 오류 발견 — 계좌번호가 전역 유일이 아니고(16,496개가 은행 간 중복) Trans의 은행 ID는 선행 0 문자열이라 raw 조인 매칭률 0%. 숫자 정규화 + (은행ID, 계좌번호) 복합키로 100% 정확 매칭 확보
- 기존 KYC v2는 계좌번호 단독 조인이라 0.78% 계좌의 KYC 속성이 오배정된 상태였음 → 정규화 조인으로 재생성해 재학습 착수
- 엔티티 유형 판별력 분석 — 세탁과 모집단의 유형 분포 편차가 최대 3.3pp(법인)에 그쳐 사실상 무효. 실질 KYC 레버는 raw 유형이 아니라 same_entity·유형쌍 위험도·엔티티 계좌수/다양성 쪽

## 문제 상황

- 복합키 재학습 결과 대기 중이라 대표 수치 갱신 여부는 미확정 (현재 확정본 PR-AUC 0.6256 / F1 0.639 / Recall@1% 0.856)
- 은행코드 크로스워크가 전처리 파이프라인에 정식 항목으로 들어가 있지 않음

## 내일 계획

- 복합키 재학습 결과 확인 후 대표 수치 갱신 여부 결정
- 은행코드 크로스워크 전처리 파이프라인 항목화
- train-only 엔티티 그룹 집계 실험
