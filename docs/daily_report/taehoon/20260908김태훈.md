## 실적

- SAML-D(외부 합성 AML 데이터)를 기존 TGNN 파이프라인 형식으로 전처리·피처 생성·지도학습 베이스라인까지 구축하고, 라벨 비율을 1~100%로 줄여가며 준지도학습 여지를 검증
- SAML-D는 라벨과 무관한 구조·리듬 피처만으로 이미 성능이 높아 준지도학습 이득이 작다고 결론 — SSL의 가치는 무패턴 위장 세탁이 있는 HI-Large류나 초저라벨 구간에 있음
- 보고서를 파이프라인 실행 순서(데이터 이해 → 빌드 → 피처 → TGNN)로 재배치하고, 클래스 불균형 절을 정정 — 최종 TGNN은 다운샘플링 없이 자연밀도 전량 + 손실가중을 쓴다는 점이 부스팅 베이스라인의 결정과 혼재돼 있었음
- 운영 배치 구성 실측 섹션 신설 — 무작위 배치가 일별보다 성긴 그래프인데도 성능이 더 높고, 일별로 채점하면 학습·채점 밀도 불일치로 성능이 떨어짐. 일별 재학습이나 하루 재분할로 맞춰도 자연밀도 무작위에 못 미침
- CSSMC 다운샘플링 재검토 — "양성 비율을 높였는데 성능이 떨어진다"는 지적을 파고든 결과 절반은 내 실수였음. 다운샘플로 양성을 늘린 뒤 손실가중치를 그대로 둬 양성이 이중 과강조된 상태였고, 교정하니 상당 부분 회복
- 다만 교정 후에도 자연밀도 전량 학습에 미달 — 정상을 더 남기는 방향으로 완화 스윕을 돌리니 자연밀도로 단조 수렴할 뿐 넘어서지 못함. GNN에서는 양성 비율을 높인다고 더 잘 찾는 관계가 성립하지 않고, 다운샘플은 밀도·연결성을 훼손함
- pos_weight 외 대안 검토 — 점수·prior 보정은 랭킹 지표에 원리적으로 무효, 전량 그래프 유지 계열은 사실상 다운샘플을 안 하는 것과 동일. 데이터를 줄이면서 자연밀도 성능을 내는 방법은 없다고 정리

## 문제 상황

- 검증셋 성능이 실전을 과대평가하는 구조 — 다운샘플 검증셋으로 판단하면 안 되고 test 자연밀도로만 봐야 함
- 채점 방식(무작위 유지 / 일별 재분할 / 일별 재학습)이 아직 미확정

## 내일 계획

- 채점 방식 최종 확정
- 전량 그래프 유지 + 라벨만 축소 실증으로 라벨 절감 가능성 확인
