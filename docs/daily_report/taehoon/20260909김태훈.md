## 실적

- 일별 재분할 채점을 실측 — 하루치를 학습 그래프 크기로 나눠 채점하면 순수 일별보다는 낫지만 현 확정본인 무작위 순열에는 못 미침. 하루가 시간적으로 뭉쳐 밀도 체제가 달라지는 것이 원인
- 보고서의 월별 건수 오류 정정 — "9월 800만"은 다른 데이터 수치와 혼동한 것이고 실측은 8월 5,947만 / 9월 5,614만 / 10월 5,482만. 9월 gap이 전체의 31%를 통째로 버리는 결정임을 반영
- CSSMC 다운샘플 튜닝 여지 4종을 전부 실측 — pos_weight는 밀도 매칭이 최적이고 과하면 역효과, 양성 비율은 낮출수록 자연밀도로 수렴, 군집수는 무효, 밀도 1%에 pos_weight 상향은 소폭 개선되나 상한 미달. 어떤 조합도 자연밀도 전량 학습을 넘지 못함
- 다운샘플 품질 검증 방법을 정리하고 실측 — KLD·JS·KS와 군집 구성비 보존 기준으로 16개 피처 전부 대표성이 완벽했으나 무작위 추출과 수치가 동률이라 대규모에서 층화의 추가 이득은 없음
- 그 결과 전통적 대표성 검증만으로는 GNN 다운샘플 품질을 잴 수 없다는 결론 — KLD를 통과해도 성능은 예측하지 못하고, 밀도·연결성까지 봐야 병목이 드러남
## 문제 상황

- 채점 방식(무작위 유지 / 일별 재분할 / 일별 재학습)이 아직 미확정
- 다운샘플의 병목이 샘플링 품질이 아니라 밀도 왜곡·그래프 연결성 파괴라 기법 교체로는 해결되지 않음
