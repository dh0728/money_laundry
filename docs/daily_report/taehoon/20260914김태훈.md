## 실적

- HI-Large EDA 보고서 통합 —  일별 양성 수·패턴 거래 수·작전 수와 계좌 컬럼 의미·결측·중복을 보강. 그래프 12개 삽입
- 우리 피처 64종(노드 23+23, 엣지 18)으로 샘플 모델 비교 완료 — 테스트 가중 AP 기준 SMOTE+XGBoost 0.5561 > LightGBM 0.5525 > XGBoost 0.5479
- 피처 41종의 의미·계산식·기여율을 연결한 HTML 시각화 및 분석 - 거래 횟수·자기 이체·왕복·금액을 조작해 피처 값 변화를 직접 확인 가능
- 일별 그래프의 시간 기준 확정 — D일 거래를 당일 마감 후 판정, 문맥은 최근 30일·수신 노드별 최근 10건·2-hop. 2-hop 자체는 미래 누수가 아님을 정리

## 문제 상황

- 모델 비교 결과는 단일 시드 샘플의 가중 추정치이며 전량 평가가 아님.
- 일부 쌍 이력 피처가 당일 마감이 아닌 D일 00시 이전 기준이라 시간 기준이 통일돼 있지 않음
