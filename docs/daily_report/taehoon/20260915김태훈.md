## 실적

- 완전 중복행 제거를 최종 정제 정책으로 확정하고 근거를 문서화 — 중복 컬럼 구분, 계좌 복합키 결합, 통화·꼬리 처리, 시간 분할, 모델 입력·정답 범위까지 명세로 정리하고 선택 파이프라인 진입점 신설
- 중복 제거 모델의 피처 검증 완료 — 스키마·라벨 구분·결측·범위·계산식 등 전 항목 통과. 쌍별 이력 두 피처와 엔티티·자기이체 피처에서 높은 상관 확인
- 순열 중요도를 중복 제거 모델로 재측정 — 과거 중복 유지 모델의 순위를 그대로 쓸 수 없음을 확인(일부 피처의 기여 방향이 뒤집힘)
- 상관·중요도만으로 삭제하지 않고 단일 피처 제거 재학습으로 판단하는 절차 수립. 제거 실험 2건 완료, 1건 진행 중
- 완료된 두 실험 모두 개선 없음 — 특히 순열 중요도가 음수였던 피처도 실제로 빼니 성능이 떨어져, 음수 중요도가 삭제 이득을 보장하지 않음을 실측으로 확인


## 문제 상황

- 중복 제거는 데이터 정책으로 정한 것이고 실제 반복 거래인지 수집 중복인지는 증명하지 못함. 운영에는 라벨이 없어 별도 중복 판별 정책이 필요
- 일 마감 그래프는 같은 날 이후 거래가 판정 문맥에 들어갈 수 있어 실시간 시점 모델과 구분해야 함

## 내일 계획

- 진행 중인 제거 실험 완료 후 기준 모델과 비교
- 필요 시 여러 시드로 차이의 안정성 확인
