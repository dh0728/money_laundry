## 실적

- 전처리 → 피처 추출 → 학습·검증을 독립 실행 노트북 3개로 정리해 팀에 전달 — 공통 설정 저장·재사용, 모델 요약, 진행률·일별 결과 표시 지원. 정제·통화 정규화 근거 문서도 보완
- 계좌 속성 12개의 기여도 검증 — 제거하면 검증 AP가 7.03%p 떨어져 유지가 맞다고 확인(단일 시드)
- 학습·검증 1억 건을 재학습 없이 분석해 시간 범위별 관련 거래 비율 측정 — 정상·패턴 연결 양성·미연결 양성을 구분해 30분 간격으로 비교
- 시간 범위 재학습 — 180분 확대는 개선되지 않아 기존 60분 모델 유지, 30분 실험은 진행 중

## 문제 상황

- 관련 거래 비율에서 정상과 양성의 차이가 30분에서 가장 컸으나, 이 비율만으로 모델의 최적 시간 범위를 확정할 수는 없음
- 재학습 비교가 단일 시드 기준
- 30분 실험 미완이라 시간 범위 최종 선택이 보류 상태

## 내일 계획

- 30분 실험 완료 후 30·60·180분 결과 비교해 시간 범위 확정
