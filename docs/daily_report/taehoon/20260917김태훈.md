## 실적

- 중단된 실험 복구 — 상태 파일의 실행 표시가 실제 프로세스와 달랐고 임시 경로의 전처리 데이터도 사라져 원본에서 복구. 복구본이 기존 산출물과 값이 일치하는지 검증한 뒤 저장된 최고 모델로 재개
- 피처 제거 검증 완료 — 이상치 비율 피처를 추가로 빼니 검증 AP가 1.71%p 하락해 기존 40개 피처 유지를 지지
- 시간 분할을 60/20/20(일수 기준)으로 재구성해 재학습 착수 — 기존 검증 구간을 이미 학습한 모델은 이어받지 않고 처음부터 학습, 전처리·피처는 인과적 이력을 유지한 채 재사용
- 새 분할의 분포를 먼저 비교 — 양성 패턴 8종은 전 구간 유지되나 학습 구간의 패턴 미연결 양성 비중이 줄고, 같은 작전 ID가 학습·테스트에 함께 등장하는 수는 늘어남. 시간순 분할이 작전 단위 독립성을 보장하지 않음을 확인
- SAML-D 상세 EDA 완료 — 결측·변환 오류·완전 중복·라벨 충돌 모두 없음을 확인하고, 품질·불균형·시간대·유형·통화·금액·계좌 활동·거래 쌍까지 분석
- 원본 CSV에서 직접 집계하는 실행형 노트북과 상세 보고서 작성 — 기존 집계 파일 없이도 재현 가능하게 하고, 표·그래프를 셀 단위로 분리·한글화. 집계 검증 전 항목 통과

## 문제 상황

- 피처 제거 비교가 단일 시드이고 입력 차원에 따른 초기화 영향도 있어 통계적 우위는 확정할 수 없음
- 새 분할은 기존 프로젝트에서 이미 분석한 10월을 포함하므로 완전한 미사용 홀드아웃으로 볼 수 없음
- 새 실험과 기존 실험은 검증 기간이 달라 AP를 직접 비교하면 안 됨
- 재학습이 진행 중이라 테스트 결과는 아직 없음

## 내일 계획

- 진행 중인 60/20/20 실험의 조기 종료 여부와 최종 검증·임계값·테스트 결과 확인
- 최종 결과를 새 분할 기준으로 정리하고 기존 실험과의 비교 한계를 함께 기록
