## 실적

- 모델 구조의 효과를 따로 떼어 보기 위해 동일한 피처·거래·시간 분할 위에서 GNN 6종(TGNN·GATv2·GINE·GraphSAGE·GCN·GAT)과 트리 2종(LightGBM·XGBoost) 비교 실험을 구성
- GraphSAGE와 GCN은 거래 피처를 쓸 수 있도록 확장해 구현하고, 트리 모델에는 GNN과 같은 피처를 펼쳐 넣어 추가 피처 없이 조건을 맞춤
- 임시 경로에 있던 중복 제거 데이터가 또 사라져 복구 — 원본 지문과 생성 코드 해시를 확인하고, 복구본의 건수·계좌/패턴 매핑·정규화 통계가 기존 산출물과 일치하는지 검증
- 학습 전 사전검사 수행 — GNN 6종 전부 순전파·역전파 유한값, 문맥 거래 피처 변경 시 출력 반응, 문맥 엣지가 없는 경우 처리, 트리 입력의 계좌 매핑 정확성까지 확
- 이전 전이학습 실험 기록 확인 — 라벨 사용량 전 구간에서 사전학습 후 미세조정보다 처음부터 학습한 모델이 높았고, 데이터셋 간 직접 적용은 공통 피처만으로도 일반화가 되지 않았음

## 문제 상황

- 8종 중 첫 모델이 1에폭 학습 중이라 새 실험의 검증·테스트 결과는 아직 없음
- 초기 관측으로 전체 완료까지 4~8일을 추정했으나 확정 일정이 아니며 1에폭 완료 후 재산정 필요
- 단일 시드 1차 비교이고 GNN 간 파라미터 수와 트리·GNN의 학습 예산 단위가 달라 순위로 단정할 수 없음

## 내일 계획

- 나머지 모델 순차 완료 및 8종 통합 비교표 작성
