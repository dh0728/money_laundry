## 실적

- 기존 TGNN 40개 입력 중 5개를 상수로 고정하고 35개만 받는 입력 축소 후보를 재학습 없이 선정 — 같은 가중치·임계값을 유지한 채 검증 5일 표본으로 평가
- 통과 기준을 미리 정해 적용 — AP 감소 0.5%p 이하, 정밀도·재현율·상위 1% 재현율·미연결 양성 상위 1% 재현율 감소 각 1%p 이하를 합산과 날짜별 양쪽에서 모두 충족. 상수 기준값도 0과 학습 기간 중앙값 두 가지로 검증
- 가중치가 낮은 피처 조합 256개를 탐색해 9개가 통과, 그중 최소 입력 수와 최악 날짜 손실 기준으로 최종안 확정. 성능은 원본과 사실상 동등(소폭 개선은 유의하다고 보지 않음)
- 팀원 피처 31개와 우리 40개를 통합 명세로 정리 — 의미가 같은 6개는 이름 통일, 계산 방식이 다른 1개는 병합 보류, 팀원 고유 25개는 현재 모델이 학습하지 않은 입력이라 채택 보류
- 더 작은 후보(26·25·20개)는 전부 탈락 — 가중치가 낮은 피처를 한꺼번에 빼는 방식이 안전하지 않음을 확인

## 문제 상황

- IG 계산에서 일부 쌍이 수렴 기준에 미달(통과분만 재집계하면 순위 상관은 유지)
- 팀원 IG는 실제 팀원 모델이 아닌 별도 MLP 기준이라 양쪽 IG를 합산해 순위를 매길 수 없음
