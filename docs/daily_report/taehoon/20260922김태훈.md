## 실적

- 피처 조합 비교(12개 구성 × 3시드)를 마치고 기존 35피처에 통화별 금액 표준화 피처 하나를 더한 36피처를 후속 실험의 공통 입력으로 선정 — 세 시드 모두 개선
- 36피처를 고정한 조건에서 GNN 6종 × 3시드 비교 18건 완료 — 평균 검증 AP는 TGNN이 가장 높았고, GAT·Edge SAGE·GCN·GATv2·GINE 순
- 임베딩 기반 오버샘플링 비교 72건 완료 — 학습된 GNN을 고정하고 거래 임베딩 단계에서 반복 추출·SMOTE·WGAN-GP를 대조군과 비교. 모델에 따라 효과가 갈렸고 원시 거래나 그래프를 합성한 실험은 아님
- 다운샘플링 방식 비교 — 클러스터·랜덤 각 18건 완료, 원본 전체 데이터 학습 착수
- 피처 명세를 36피처 기준으로 갱신하고 기존 IG 순위를 정의 옆에 통합 — 추가 피처는 당시 입력에 없어 미계산으로 표시

## 문제 상황

- 같은 검증셋으로 피처와 모델을 반복 비교해 탐색적 검증 성능이며, 이번 비교들에서 테스트 기간은 쓰지 않음
- 36피처 선정은 평균이 개선된 것이고 날짜·시드별로는 하락한 구간도 있음


## 내일 계획

- 원본 전체 데이터 남은 학습 완료 후 클러스터·랜덤·원본 결과를 공통 조건으로 최종 집계
- 최종 구성 고정 후 테스트 평가 범위와 과거 테스트 사용 이력 정리
