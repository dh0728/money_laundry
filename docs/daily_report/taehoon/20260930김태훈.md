## 실적

- 클러스터 언더샘플링 + TGNN에 그래프 구조 인식 기능 3종(Reverse MP·Ego ID·Port numbering)을 추가할 수 있도록 독립 실험 환경을 구성 — 기존 실험은 그대로 두고 동일 조건에서 기능별 영향을 비교하는 구조
- 기존 클러스터 샘플링 방식의 정체를 명확히 정리 — 그래프 커뮤니티 분할이나 선행 기법의 재현이 아니라 정상 거래 특성을 군집화해 뽑는 방식임을 구분하고, 표본 배분·비복원 추출·선택 확률 가중 보정 원리를 문서화
- 샘플링 범위를 손실 계산 대상에만 적용하도록 분리 — 선택에서 빠진 정상 거래도 이웃 문맥으로는 쓰이고, 세탁 거래는 패턴 매칭 여부와 무관하게 전부 학습 대상으로 유지
- 거래 ID가 시간순이 아님을 확인하고 실제 거래 날짜로 학습 대상을 구성하도록 수정
- 구간별 문맥 사용 범위를 확정 — 학습은 학습 구간 그래프, 검증은 학습+검증 그래프, 테스트는 전체 허용 문맥을 쓰되 채점 대상은 테스트 구간 거래로 제한. 문맥 거래의 정답 라벨은 입력에 넣지 않음
- 구조 인식 3종 구현 — 정·역방향에 다른 가중치를 쓰는 메시지 전달, 판정 거래 양 끝 계좌 표시와 거래별 서브그래프 분리, 수취 계좌별 송신자 구분 엣지 피처
- 회귀 테스트와 소규모 통합 테스트로 검증 — 표본 배분·세탁 보존·날짜 정합성·이웃 상한·방향별 전달·Ego 독립성·손실 계산, 그리고 학습부터 저장·재시작·임계값 고정까지의 흐름
- 명세 2종과 단계별 실행 노트북을 작성하고 실험 큐 시작

## 문제 상황

- 기존·신규 모두 기준 모델 학습 단계이고 구조 인식 3종의 학습·비교는 미완
