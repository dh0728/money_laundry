## 실적

- 무패턴 양성(세탁 라벨은 있으나 8종 패턴에 속하지 않는 거래) 탐지 개선에 집중 — 전용 트리 모델의 피처를 정리하고 기존 구성을 기준 모델로 유지
- 무패턴의 성격을 규명 — 패턴 양성은 거의 전부 ACH인 반면 무패턴은 상당 부분이 비ACH(수표·카드·현금)이고, 비ACH 무패턴은 같은 분 안에 여러 상대로 송금하는 경향이 뚜렷
- 동일분 집계 피처를 추가해 후보 모델들을 비교 — 검증에서 고른 모델이 테스트 탐지율·AP 모두 기존보다 높았으나 오탐률이 사전 기준을 근소하게 초과해 사전 규칙대로 기존 모델 유지
- 수신 계좌 fan-in 가설 검증 — 넓게 정의하면 무패턴에 흔하지만 정상에도 흔해서 구분력이 없고, 실시간·지연 판정 두 형태로 피처를 넣어도 개선이 없어 검증 단계에서 중단(기존 피처에 이미 같은 정보가 있다고 판단)
- 놓친 무패턴의 오류 구조 분석 — ACH 미탐은 임계값 바로 아래 몰려 있어 오탐 허용을 조금 늘리면 잡히지만, 비ACH 미탐은 점수가 멀리 떨어져 있고 원본 속성을 더해도 낮은 오탐률 구간에서 분리되지 않음
- 비ACH 무패턴이 거래량 많은 허브에서 나가지만 같은 허브의 정상 거래가 압도적으로 많아 허브 여부만으로는 구분 불가임을 확인. 결제방식별 오탐 예산 분할도 전체 탐지율을 떨어뜨려 기각
- 운영 기준 결합 성능 산출 — V10에 무패턴 모델을 결합해 오탐률 목표별 탐지율·Precision과 일별 경보 건수를 추정. 무패턴 비율이 낮아 오탐률을 고정하면 Precision 상한 자체가 낮다는 구조를 정리
- V10의 양성 판정을 얕은 결정트리로 근사해 시각화하고 대표 사례는 실제 GNN 기여도로 계산 — 패턴 양성은 설명되지만 무패턴은 거의 설명되지 않음
- 자금 출처(오염 전파) 가설 탐색 착수 — 무패턴 거래에서 돈을 받은 계좌가 다시 송금하는 연쇄가 비ACH에서 정상과 뚜렷이 달랐으나, 정답 라벨을 쓴 진단이라 피처로 직접 쓸 수 없음

## 문제 상황

- 비ACH 무패턴은 어느 방법으로도 거의 탐지되지 않음 — 정상 거래와 실질적으로 구분되지 않는 구간
- 운영 지점을 정하려면 하루 처리 가능한 경보 수 또는 최소 Precision이 먼저 정해져야 함
- 테스트 구간을 이전 실험에서 반복 사용해 탐색적 결과이고, 일부 피처는 구간 종료 시점까지 누적된 값이라 엄격한 실시간 성능이 아님
- 모든 실험이 단일 시드

## 내일 계획

- 오염 전파 연쇄 피처를 정답 대신 모델 점수·경보 기반으로 재구성해 비ACH 개선 시도
- ACH 경계 근처 미탐 개선(시드 평균·앙상블)
