## 실적


- 놓친 무패턴을 결제 방식별로 분해 — 경보는 전부 ACH에서 나가고 ACH외 결제수단 무패턴은 거의 못 잡음. ACH외 결제수단은 소수 초대형 허브에 몰려 있어 허브 전용 모델까지 만들어 봤으나 정상과 구별되지 않아 현재 정보로는 탐지 한계로 판단
- ACH 무패턴은 계좌가 넓게 흩어져 있고 미탐 대부분이 임계값 바로 아래 — 최상위 점수 구간 내 순위 품질 문제로 성격 규정
- 현재 모델이 쓰지 않는 신호 발견 — 과거에 무패턴에 관여한 송·수신 계좌는 무패턴 비율이 훨씬 높음. 잘 놓치는 유형도 특정(새 거래 상대, 계좌 많은 소유주의 조용한 단건)
- 캐스케이드의 오탐률별 재현율·정밀도·일별 경보 수를 표로 정리 — 일정 오탐률을 넘으면 넓혀도 얻는 게 적음
- 임계값을 낮춰 무패턴까지 잡으려 하면 오탐이 급증하는 것을 확인 — 무패턴은 전용 캐스케이드를 별도로 붙이는 편이 낫다고 결론
- 맥락 지표 비교 착수 — 거래별로 송·수신 계좌의 최근 30일 이력에 비춘 금액 이상도, 첫 거래 상대 여부, 결제 방식 일관성, 직전 거래 간격, 자금의 즉시 재송금 여부를 계산해 점수 구간별로 무패턴과 정상을 비교

## 문제 상황

- ACH외 결제수단 무패턴은 허브 전용 모델까지 포함해 현재 정보로는 탐지 불가 구간
- 다른 패턴을 파악해야됨, 정상거래와 무패턴거래의 차이

## 내일 계획
