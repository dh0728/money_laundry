## 실적

- FraudGT 실험 조건을 공식 구현 기준으로 정정 — 이웃 추출·공유 그래프·검증 방식을 공식안에 맞추고, 기존 개별 그래프 방식은 비교군으로 유지
- 학습 조건 확정 — V10 입력에 결제방식 추가, 클래스 가중 BCE 손실(논문방식), 지정 4 epoch에서만 검증

## 문제 상황

- 학습 속도가 epoch당 약 15분 소요됨 (예상시간 )
- 개별·공유 그래프 비교 학습이 아직 진행 중이라 목표 성능(정밀도 70%, 재현율 65%) 달성 여부는 미확정

## 내일 계획

- 비교 학습 완료 후 최종 평가로 목표 성능 달성 여부 확인
- SaltGNN 관련 논문 정독후 모델 재현검증
