## 실적

- 채택 41종 모델의 전처리·표본 구성·학습 방법을 진행현황 문서에 정리 — 중복 행 제거와 누락 양성 복원, 라벨·패턴명 입력 제외, 일마감 판정 조건, 41종 합집합과 실제 입력 열 수의 구분, 정상 거래 군집 표본 방식, HGB 3클래스 + GNN 이진분류의 점수 결합까지 명시 (재학습은 아님)
- SALT-GNN 논문 분석 후 후속 실험계획 문서 작성 — 통계 경로와 Attention 경로의 결합 위치를 A0~A3 네 구조로 비교하도록 설계, 짧은 epoch로 1차 비교 후 유망 후보만 연장하는 순서와 채택 기준 확정 (실험은 미실행)
- FraudGT 3종(기본·Port 추가·양방향)의 구조모델 학습중 — 기본 모델 학습 완료, Port 추가 모델 진행 중, 양방향은 대기

## 문제 상황

- 채택 41종은 Val·역사 Test 모두 재현율이 목표(P 70% / R 65%)에 미달하고, 무패턴 재현율은 여전히 10% 수준
- FraudGT 지표는 점수가 산출된 거래만 대상인 조건부 값이고 커버리지가 3분의 1 수준이라, 채택 41종 지표와 직접 비교할 수 없음
- 자동 점검은 서버와 app-server가 떠 있어야 동작하며 재부팅 후 자동 복원되지 않음

## 내일 계획

- Port 추가 모델을 끝까지 학습하며 매시간 속도·메모리·체크포인트 확인
- 완료 후 양방향 모델 실행, 초기 구간으로 실제 소요 시간과 메모리 측정
- 3종의 체크포인트를 고정해 최종 Test 수행, 조건부 지표와 커버리지·재현율 하한을 함께 비교
- SALT 계획은 기준선 재현과 미탐 분석부터 착수
