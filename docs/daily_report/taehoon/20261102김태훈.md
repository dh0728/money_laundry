## 실적

- Multi-FraudGT 284에폭 학습 종료 — 검증 최고 체크포인트(280에폭, F1 75.56%)를 선택하고 진행 중이던 체크포인트는 백업
- 전체 Test 전환 — 10월 하순 전 구간 3,300만여 건을 대상으로 하는 실행 노트북 작성·검증, 일정 배치마다 저장해 중단 후 재개 가능하게 구성
- 전체 Test 실행 중 — 진행률 약 19%, 예상 잔여 8시간대
- 기본·PE·Multi 3종의 구조와 최고 검증 지표를 비교 정리
- 무패턴 탐지 실패 원인 정리 — 정상 거래와의 특징 중첩, 희소한 이웃 신호 누락. 후속 SALT-GNN의 일별 배치·통계 집계로 개선할 방향까지 정리

## 문제 상황

- 표본 Test에서 무패턴 재현율이 0% — 패턴 양성만 잡고 무패턴은 전혀 못 잡음
- 현재 지표는 점수가 산출된 거래만 대상인 조건부 값이고 요청 건의 3분의 1 미만만 점수가 나와, 다른 모델과 직접 비교할 수 없음
- 전체 Test가 끝나지 않아 최종 지표는 미확정

## 내일 계획

- 전체 Test 완료 후 최종 지표 확정 — 미산출 양성을 미탐으로 포함한 전체 재현율까지 함께 보고
- 3종 비교 결과 확정
- SALT-GNN 본학습 진행예정
