## 실적

- FraudGT 추론을 전체 거래 채점으로 전환 — 기존 방식은 전체 Test를 요청해도 약 30%에만 점수가 나왔음을 확인하고 전수 채점으로 변경, 체크포인트·그래프·거래 순서·이웃 샘플링은 그대로 둔 재추론 (재학습 아님)
- 기본형·PE 전수 Test 완료 — 전체 세탁 건수를 분모로 기본형 재현율 52.63%, PE 56.99%로 PE가 우위. 다만 무패턴 재현율은 두 모델 모두 0.2% 수준
- Multi는 전수 Test 진행 중
- 채점 범위 전환 효과 측정 — 동일 분모에서 기본형 재현율 32.52% → 52.63%, 전수 채점 후 TOP-1% 재현율 86.89%
- 수신 계좌 차수별 성능 분석 준비 — 반복 거래는 각각 집계하고 인위적 역방향 간선은 제외, 3종 완료 후 사후 집계 예정
- SALT-GNN 전수 실행본 작성 — 요청대로 정상 거래 다운샘플링과 역확률 가중을 제거하고 클래스 가중 손실만 사용, 일별 누적 그래프와 이웃 샘플링은 유지. 단위 검증과 실제 데이터 순전파·역전파, 중단 후 재개까지 검증
- 통계 경로의 결합 위치를 가르는 4개 구조 비교 설계 확정 (Attention만 / 통계만 / 마지막 층 결합 / 매 층 결합)


## 문제 상황

- 전수 채점으로 바꿔도 무패턴 재현율은 0.2% 수준 — 패턴 양성만 잡히는 구조가 그대로
- Multi 전수 Test 진행률이 낮아 3종 최종 비교는 미확정
- SALT 새 실험은 FraudGT 완료를 기다리는 중이라 아직 학습 미시작이고, 대상 건수가 이전 표본 실험의 수백 배라 전체 소요 시간을 실측하지 못함
- FraudGT는 Test 종료일까지 누적한 그래프, SALT는 대상일 마감 기준 그래프를 쓰므로 두 결과를 그대로 비교할 수 없음

## 내일 계획

- Multi 전수 Test 완료 후 3종 최종 비교표 갱신과 차수별 분석 집계
- SALT는 매 층 결합 구조부터 순차 학습하고 전수 Monitor·Val·Test까지 평가
