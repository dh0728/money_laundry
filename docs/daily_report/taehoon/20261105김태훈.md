## 실적

- SALT-GNN 팀 공유 노트북 갱신 — 환경 준비부터 전처리·입력 생성·학습·평가·스모크 테스트까지 단계별로 정리하고, 실행 소스를 노트북에 내장해 노트북만 복사해도 코드가 복원되도록 구성
- 현재 속도 개선 방식을 공유본에 반영 — 배치마다 반복하던 그래프 탐색·노드 번호 매핑을 GPU 경로로 옮기고 거래 피처 캐시를 GPU에 상주시켜 조회·전송 비용을 줄임. 짧은 구간 측정에서 처리량 약 3.9~5.0배
- 평가 대기 시간 단축 — 핵심 구조의 학습·모니터가 끝나면 다른 모델을 기다리지 않고 바로 Val/Test를 실행하도록 변경
- SALT-GNN + HGB 결합 모델 구현 계획 정리

## 문제 상황

- 속도 개선 배율은 짧은 구간 측정값이고 배치 구성 변경이 공유 문맥과 학습 결과에도 영향을 줄 수 있음
- 결합은 연결 가능성만 확인한 단계 — 전량 구간의 점수 생성과 일부 HGB 입력 준비가 남아 있고, 공유 노트북에 정식 결합 학습기는 아직 미포함

## 내일 계획

- SALT 최종 선택 가중치로 개별 평가 수행
- SALT + HGB 정식 결합 실험 — 전량 점수 생성 → 결합기 학습 → Val 비교·임계값 고정 → 전체 Test
