## 실적

- Multi-FraudGT를 SAML-D 전체 950만 건에 전량 채점 — 가중치를 고정한 평가이며 재학습은 아님. 탐지율 45.69%는 나왔지만 정밀도 0.44% / AP 2.04%로, HI-Large 전체 Test(F1 70.14% / AP 66.88%)
- 결측 입력 진단 — 기본 34종 중 SAML이 같은 정의로 제공하지 않는 11종(계좌 유형·소유관계·국가 정보)이 0으로 채워져 있음을 확인. NaN/Inf는 없고, 미제공을 채운 0과 실제 관측값 0을 구분. 결제방식 Unknown이 31%지만 그것만으로 성능 저하를 설명할 수 없음
- 동일 HI 표본에서 정보를 가린 7조건 대조 — 소유관계 3종만 0으로 바꿔도 F1 72.33% → 17.95%, 오탐 21건 → 2,143건으로 취약성 확인
- 소유관계 대체값 3종 실험(전체 중앙값·차수 구간별 중앙값·유사 계좌) — HI 검증 표본에서는 AP가 58.55% → 67~68%로 회복했으나 SAML에서는 세 방식 모두 악화. 사전 기준대로 **전부 미채택**하고 기존 0 대체를 비교 기준으로 보존
- HI와 SAML의 전체 입력·구조 비교 — 관측 이력 길이, 송신 포트 분포, 학습 사기의 결제방식 구성(HI 학습 사기는 거의 전부 ACH) 등 정보 가용성 외의 차이도 확인
- SAML 패턴별 탐지·오탐 분석 — 사기 17종·정상 11종을 네 입력 조건으로 비교. Structuring은 74% 탐지하지만 Cash_Withdrawal·Smurfing은 네 조건 모두 0건
- 팀 공유 최종 보고서 작성 — 실험 순서대로 구성하고 단독 열람용 HTML까지 제공, 보고서·근거 자료를 Git 공유용 ZIP으로 묶음 (원본 데이터·가중치·개별 예측 제외, 원격 push는 하지 않음)
- 평가 무결성 검증 — 전체 거래 ID 커버리지, 패턴별 합계와 전체 지표 일치, AP 독립 계산 교차 검산, 파일 해시·내부 링크 확인
- 분석 때문에 멈춰 둔 SALT-GNN 핵심 구조 학습 재개 — 저장 지점에서 중복 실행 없이 이어지는 것과 실제 처리량 증가 확인. 직전 5에폭 모니터 지표는 P 71.72% / R 59.56% / F1 65.08% / AP 64.88%

## 문제 상황

- 교차 데이터 적용 실패 — SAML에서 정상 거래 100만 건 이상을 사기로 오판(오탐률 10.7%), 정밀도가 1% 미만이라 그대로는 쓸 수 없음
- 결측을 모사한 HI 표본 AP는 56.80%인데 실제 SAML은 2.04% — 격차가 커서 성능 저하를 원인별 기여율로 분해할 수 없음
- HI 내부에서 유효했던 대체 방식이 SAML에서는 전부 역효과 — 실제 소유관계를 복원한 실험이 아니므로 대체 실패가 결측 영향을 부정하는 근거도 아님
- Cash_Withdrawal·Smurfing은 어떤 입력 조건에서도 한 건도 탐지하지 못하고, 둘이 전체 미탐의 42%를 차지
