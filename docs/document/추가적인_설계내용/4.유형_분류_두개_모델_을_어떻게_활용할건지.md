### 이진/유형 분류 두개 모델 결과를 추론결과를 어떻게 활용할건지? 지금은 그냥 이진분류만 이용해서 Alert를 만들고 있고 나중에 유형분류는 그냥 그 Alert에 유형 분류된거 보고 확률 순으로 나열만 시킬까 하는데 어때 이런식으로만 활용하는게 과연 괜찮은지?

#### 방식 1 이진분류로 Alert를 생성하고, 유형분류(9클래스)는 Alert 내부의 유형을 설명하는 방식

유형분류 모델은 모든 거래가 아니라 이진분류에서 위험 거래로 선정된 씨앗·핵심 거래에만 적용
유형모델에서 정상거래는 제외한다. 정상 여부는 이미 이진분류 모델의 책임이기 때문이다.

다만 유형분류 모델을 
- 이진분류 결과와 관계없이 모든 거래에 유형모델을 실행
- Alert의 정상 연결 거래도 유형분류
- 유형모델 자체도 정상과 자금세탁을 구분
- 유형모델 단독으로도 Alert 후보를 생성
하는경우 10클래스로 해야함(또 하나의 자금세탁 탐지 모델이 되는 느낌)


#### 방식 2 이진분류로 Alert를 생성하고 이 Alert를 유형분류 모델에 넣는 방법

GNN은 예측은 노드 단위, 엣지, 그래프 세개로 나누는데 처음 거래 데이터에서는 그래프를 만들 수 없어서 노드 단위나 엣지 단위로만 예측이 가능함. 근데 이진분류로 서브그래프를 만들고 그걸 유형분류 모델에 넣으면 그래프 단위로 유형분류가 가능해짐
