### episode를 만들수 있는 추가적인 정보, alert 간의 관계를 사용자가 쉽게 확인할 수 있는 정보를 어떤식으로 제공하면 좋은지

현재 단계에서는 설명 가능한 등급 방식

#### 강한 연결
다음 중 하나가 있고 시간적으로 설명되는 경우
- 동일 거래 공유
- 동일 계좌 공유
- 동일 Entity 공유
- Alert A에서 Alert B로 직접 자금 이동
- 시간순으로 이어지는 1-hop 경로

#### 중간 연결
여러 보조 신호가 함께 있는 경우
- 공통 상대방
- 2-hop 연결 강도
- 가까운 발생 시각
- 유사한 금액 흐름
- 동일 은행 또는 연속된 타 은행 이동

#### 약한 연결
다음 정보만 있는 경우
- 같은 경우
- 비슷한 위험 점수
- 비슷한 금액
- 같은 기간
약한 연결은 기본 추천 목록에 올리지 않고 참고 정보로만 사용하는 것이 좋다.

이 정보들을 바탕으로 **Alert 상세화면에 '연결 후보'영역 추가** 화면과 **사용자가 두 Alert를 선택하면 비교 하면**을 제공하는 것

#### Episode 상세에 추가할 정보
- Alert를 노드로 보는 그래프
- 연결 Alert 목록에도 Alert 별로 Episode 연결 근거, 이전 Alert와 시간 차이, 역할 등  컬럼을 추가

Episode 전체
- 대표 계좌·Entity
- 연결 Alert 수
- 고유 거래 수
- 고유 계좌 수
- 공통 계좌 수
- Alert 간 직접 연결 거래 수
- 전체 기간
- 끊어진 그래프 구성요소 수
- 고활동 허브 계좌 경고
- 기존 Episode와의 중복 여부
- 사용자가 선택한 연결 사유
- 시스템 추천 근거와 사용자 판단 구분
