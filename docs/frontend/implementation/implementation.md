# 프론트엔드 구현 문서

대상: 프론트엔드·백엔드 팀원 · 언어: 한국어 · 역할: 문서 안내 허브

**구현 기준 문서는 기존 5개이며, 이 파일은 그 문서로 연결하는 허브다.** 별도의 필수 문서를 추가하지 않는다.

화면 구현에 필요한 레이아웃, 경로, 데이터 규칙, API 요구사항, 검수 기준을 모은 허브다. 아래 다섯 기준 문서를 `fe/work`에서 관리하고 화면이 바뀔 때 함께 갱신한다. 개인 작업 기록에 본문을 복제하지 않는다. 갱신일은 문서를 수정한 날짜이며 화면 구현 완료일이 아니다.

**현재 기준(2026-11-16):** [사용자 원본 Figma](https://www.figma.com/design/eHgUPAyr9bZ2UC7oTZNmwh)의 초안을 바탕으로 실행 가능한 코드를 준비하고, 이후 검수하며 다듬는다. 11월 17일 코드 시연이 목표다. 이전에 만든 Figma 구현 검수본은 팀 논의로 폐기됐으며 새 구현의 기준으로 사용하지 않는다. 폐기 대상은 Figma 검수본이며 코드 전체가 아니다. 기존 기능은 보존·재사용하고, 화면 레이아웃은 사용자 원본 Figma를 기준으로 다시 구성한다. 원본에 없거나 모호한 동작은 임의로 채우지 않고 확인한다. 현재 원본 Figma를 다른 작업자가 수정 중이므로 이 문서 정리 작업에서는 읽기·쓰기를 모두 하지 않는다.

## AI 전용 지침과의 구분

에이전트만 읽는 실행·도구·작업 절차 지침은 영어로 관리한다. 팀원이 읽는 이 구현 문서 묶음에 AI 전용 운영 지침을 섞거나 같은 내용을 이중 관리하지 않는다. 공유 규칙은 한국어 정본을 링크로 참조한다. 독자가 팀원과 AI 모두인 문서는 팀 공유 문서로 분류하고 한국어를 사용한다.
