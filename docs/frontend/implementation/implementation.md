현재 작업 정본은 아래 **2개**다. 이 파일은 링크 안내만 하며 별도 구현 규칙을 두지 않는다.

| 독자 | 정본 | 내용 |
| --- | --- | --- |
| FE 구현 AI | [Frontend implementation guide](frontend-handoff.md) · 영어 | 화면·레이아웃·동작·데이터 표시·검증 기준. API 계약은 아래 한국어 정본을 직접 참조 |
| 지원님·백엔드 팀원 | [API 요구사항](api.md) · 한국어 | 화면별 필요한 데이터와 동작, mock 범위, 미확정 계약 |

[이전 문서와 검증 기록](history/)은 내용을 삭제하지 않고 보존한 이력이다. 현재 필수 읽기 목록이 아니며, 당시 결과를 현재 완료·승인으로 해석하지 않는다.

문서 수를 혼동하지 않도록: [11월 12일 생성](https://github.com/dh0728/money_laundry/commit/c11cd783) 당시 정본 5개와 허브가 있었고, 이후 [인계 기록 2개](https://github.com/dh0728/money_laundry/commit/62c6624f)와 [검수 기록 1개](https://github.com/dh0728/money_laundry/commit/680e5fd6)가 추가됐다. [한국어 정리 커밋](https://github.com/dh0728/money_laundry/commit/7c10f62c)의 **7개는 수정 파일 수**였다. 2026-11-16 사용자 요청에 따라 현재 정본을 위 2개로 통합했다.
