## Global Constraints

- Backend API는 연동하지 않고 모든 상태는 발표용 mock으로 동작한다.
- 선택은 theme 반대 명도의 면 반전, 일반 hover는 theme 반대 명도 edge glow를 사용한다.
- 빨강은 위험·오류·의심 거래 의미에만 쓴다.
- 읽기 전용 card·section에 pointer edge glow를 적용하지 않는다.
- 한 화면에서 같은 정보는 판단·이동에 필요한 예외를 제외하고 한 번만 표시한다.
- Transactions는 내부 가로·세로 scroll을 두지 않고 native page scroll 하나만 사용한다.
- RDR 9000은 `시연용`을 표시하며 실제 chatbot API를 연동하지 않는다.
- 새 runtime dependency를 추가하지 않는다.

- dark/light 선택 항목의 자식 text·badge·link가 모두 선택 foreground를 상속하는지 검증한다.

- [ ] **Step 3: 중복 ID 제거·자체 이체 제외·CYCLE fallback을 포함한 최소 계산을 구현한다.**

```ts
export function moneyMetrics(rows: MetricTx[], representative?: string) {
  const tx = [...new Map(rows.map(row => [row.id, row])).values()]
  const total = tx.reduce((sum, row) => sum + row.usd, 0)
  const external = tx.filter(row => row.from !== row.to)
  const accounts = new Set(external.flatMap(row => [row.from, row.to]))
  const principal = Math.max(
    ...external.map(row => row.usd),
    [...accounts].reduce((sum, account) => sum + Math.max(0,
      external.filter(row => row.from === account).reduce((n, row) => n + row.usd, 0) -
      external.filter(row => row.to === account).reduce((n, row) => n + row.usd, 0)
    ), 0),
    0,
  )
  const netInflow = representative ? external.reduce((sum, row) => sum + (row.to === representative ? row.usd : 0) - (row.from === representative ? row.usd : 0), 0) : null
  return { total, principal, netInflow }
}
```
