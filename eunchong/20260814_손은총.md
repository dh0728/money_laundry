## 내일 계획

- 가장 먼저 할 일 : ### 1. Track B: Structuring 및 고립 이상치 특화 피처 6종 신설 (§3 확장)

GNN이 볼 수 없는 단발성 고립 거래의 판별력을 위해 `PastIndex` 기반 신규 피처를 추가할 것:

  ① `tb_structuring_10k`: $10,000 직전 쪼개기 탐지 (exp(-((amt - 9800)^2) / (2 * 300^2)))

  ② `tb_structuring_50k`: $50,000 직전 쪼개기 탐지 (exp(-((amt - 49000)^2) / (2 * 1000^2)))

  ③ `tb_dormant_burst`: 휴면 계좌 급발진 지표 (log1p(amt) / (prior_cnt + 1) * log1p(account_age_days + 1))

  ④ `tb_round_avoidance`: 끝자리 라운드 넘버 회피율 (amt % 100 != 0 및 amt % 1000 >= 800)

  ⑤ `tb_night_cash_burst`: 야간(00시~06시) 또는 고위험 결제수단(Cash/Cheque) 거래 여부 플래그

  ⑥ `tb_iso_composite`: (Amount_Z + Velocity_Z + Structuring_10k) 복합 비지도 이상 점수

* 통계 산출 시 반드시 train 마스크(is_tr)만 참조하여 누수 원천 차단.



### 2. Track B: 고립 거래(Degree ≤ 2) 정밀 타격 가중치 부스팅 (§8)

  - Track B 학습 시 전체 데이터의 90% 이상을 차지하는 거대 정상 거래에 트리가 매몰되지 않도록, 

    `Degree <= 2`인 고립 거래 표본에 대해 `sample_weight`를 2배로 부여하는 '고립 특화 가중치' 도입.

  - `oop` (패턴 밖 양성 가중치) 스윕 그리드는 {1.0, 3.0, 5.0, 8.0} 유지 (조기종료 왜곡 방지).



### 3. Track B 스코어에 '결정론적 5대 법정 룰 가산점(Rule Prior)' 결합 (§8 후단)

머신러닝 확률만으로 정상 거래와 분간하기 어려운 한계를 극복하기 위해, Track B의 최종 예측 확률(`prob_b`)에 

명백한 규제 회피 거래(Structuring 및 휴면 급발진) 룰 매칭 시 `+0.15 ~ +0.30`의 확률 가산점(Rule Boost)을 부여한 후 백분위 순위화.

  - Rule A: 24시간 내 동일 상대에게 $9,000~$9,999 연속 쪼개기 송금

  - Rule B: 신규/휴면 계좌에서 단발성 고액(상위 1%) 급발진 출금



### 4. 듀얼 예산 라우팅(Dual-Budget Routing) r 스윕 확장 (§9)

  - `dual_budget_hits(score_main, score_b, seg, budget_total, r)`

  - r 스윕 범위를 기존 {0.15, 0.25, 0.35, 0.45}에서 **{0.20, 0.30, 0.40, 0.50}**으로 상향 확장.

  - 선택 규칙: `select_by_rule()` 그대로 사용 (Val PR-AUC ≥ Track A - 0.01 만족 조건 하에서 Val 패턴밖 재현율 최대화).
