데이터 상태 표현

모든 데이터 영역이 같은 문법을 씁니다. 셸·제목·고정 설명은 API를 기다리지 않고 먼저 그립니다. 위 무대의 상태 버튼으로 일부를 미리 볼 수 있습니다.

상태언제표현
초기 로딩그 영역의 첫 응답 전데이터 자리만 낮은 대비 skeleton, 영역 크기 고정
갱신 중이전 데이터 있음이전 데이터 유지 + 얇은 진행 표시, 마지막 갱신 시각
빈 결과200 + 빈 목록조건을 말하는 문장 + 조건 지우기. 로딩과 동시에 띄우지 않음
데이터 없음API가 값을 주지 않음데이터 없음 + 이유(산식 미정·API 없음). 0으로 바꾸지 않음
