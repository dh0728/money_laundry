# Figma v15 수정사항 인벤토리

## 판독 범위와 방법

- **원본:** Figma `AML RADAR · shadcn ui kit` → `Wireframe` → section `v15`예요. 크기는 7592×4585이고, v15 첫 검수 화면 스크린샷과 텍스트 주석 21개가 들어 있어요.
- **읽은 방법:** 2026-09-17에 Chrome의 Figma UI로 읽었고 MCP는 쓰지 않았어요.
  - layers panel에서 텍스트 주석 원문을 모두 뽑았어요.
  - 스크린샷별로 확대해 화살표·빨간 박스가 가리키는 대상과 대조했어요.
- **변경 없음:** Figma 파일은 바꾸지 않았어요.
- **해석 확정:** 해석이 갈리는 항목은 사용자에게 물어 확정했어요. 확정 내용은 `(사용자 확정)`으로 표시했어요.

행별 추가 설명이에요.

- **G3 (사용자 확정):** 계좌·엣지를 선택하면 상세는 그래프 위 오른쪽 drawer로 열려요.
- **G6 (사용자 확정):** 대상은 관계 그래프 엣지예요. 굵은 몸통 끝에 화살촉이 붙은 형태로 그려요.
- **G7 (사용자 확정):** 4·5홉 이웃은 합성해요. 계좌를 선택하기 전에는 전체가 보여요.

G8 Sankey 규칙(사용자 확정)이에요.

- **엣지 선택:** 계좌 A·B 막대 2개 사이를 돈이 양방향으로 오가요. 막대 위쪽은 보냄, 아래쪽은 받음 구간이에요.
- **노드 선택:** 선택한 계좌가 가운데 막대가 되고, 양옆으로 연결된 계좌와 오간 거래가 모두 보여요.
- **띠:** 개별 거래 하나가 띠 하나예요. 두께는 금액이고, 세탁 거래는 빨강이에요. 받는 쪽 끝에 화살촉이 있어요.
