# Figma v14 수정사항 인벤토리

## 판독 범위와 방법

- 원본: Figma `AML RADAR · shadcn ui kit` → `Wireframe` → section `v14`. frame 5개(`설정 수정`, `알림 수정`, `Alerts, Episodes 수정`, `전역 및 대시보드 수정`, `로그인 수정`), 스크린샷 9장, 텍스트 주석 38개.
- 2026-09-17에 Chrome에서 Figma UI로 읽었어요. MCP는 쓰지 않았어요.
- 레이어 패널에서 텍스트 주석 원문을 전부 뽑은 뒤, 스크린샷을 한 장씩 화면에 맞춰 확대했어요. 주석을 화살표·빨간 박스가 가리키는 대상과 대조했어요.
- 해석이 갈리는 항목은 사용자에게 물어서 확정했어요. 확정 내용은 각 행의 `(사용자 확정)`에 적었어요.
- 판독 중 `Alerts, Episodes 수정` frame의 opacity를 실수로 30%로 바꿨다가 바로 100%로 되돌렸어요. 다른 변경은 없어요.

표의 `범위`는 `전역`(여러 화면에 공통) 또는 `화면`이에요. `상태`는 구현 진행 상황이에요.
