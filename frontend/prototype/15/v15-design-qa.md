# v15 브라우저 QA

## 환경

- 2026-09-17, `AML-RADAR-v15.html`을 `python3 -m http.server`로 열어 앱 내장 브라우저에서 검수했어요. Chrome 확장은 `file://`를 열 수 없어서 같은 파일을 로컬 서버로 열었어요.
- 외부 요청: 빌드 파일에 `http(s)://` script·stylesheet 참조가 0건이에요.
- 해상도: 1440×900(기본), 1280×800, 1920×1080, 1050×800, 1080×1920(세로)이에요. 폭별 검사는 같은 origin iframe에 지정 크기로 띄워서 했어요.
- 조작: DOM 이벤트와 실제 마우스(click·drag·hover)를 함께 썼어요. drag와 표시 방식 menu는 실제 마우스로 확인했어요.
- 자동 검증: 테스트 31개(domain·UI 렌더·메모리 회귀·달력)와 TypeScript·production build가 통과했어요.

## 검수 중 발견해 고친 결함

1. 로그인 글래스 blur가 CSS 빌드에서 사라짐 → Tailwind `backdrop-blur-xl`로 교체.
2. 기간 preset이 다른 달을 보고 있을 때 스크롤되지 않음 → popover 애니메이션 영향이 없는 offsetTop 계산과 timeout으로 교체.
3. 알림 row를 누르고 이동하면 읽음 상태가 사라짐 → 메모리 상태를 setter에서 즉시 저장하고 회귀 테스트 추가.
4. 플로팅 모드에서 표시 방식 menu 항목이 선택되지 않음 → portal 이벤트가 header drag를 시작하던 문제를 수정.
5. 좁은 모드에서 이전 대화 목록이 채팅 폭을 밀어냄 → 사용자 지시에 따라 대화창 뒤에서 왼쪽으로 펼쳐지는 구조로 교체.
6. 그래프가 본문 아래로 123px 넘침 → 남은 높이를 재서 채우도록 변경.
7. 계좌쌍 lane이 목록 높이만큼만 그려짐 → 스크롤 밖 기준선으로 이동.
8. 같은 계좌쌍 안의 거래 두께 차이가 1px뿐 → panel 금액 범위 기준 8~40px로 변경.
9. loading·error 상태에서 결과 건수가 보임 → `—` 표시.
10. 기관 전체 차트가 도우미를 열면 넘침 → container query로 전환.
11. 처리 이력 시각이 12시간제로 섞임 → 24시간제로 통일.

## 사용자 지시로 바뀐 사항(검수 중)

- 그래프 시각 문법을 로그인 네트워크와 통일했어요(직선·불투명·점 노드·어두운 바탕·hover 발광).
- 조사 도우미 진입을 header 토글 pill `RDR 9000`으로 바꿨어요(HAL 9000 모티브 렌즈 아이콘).
- 진입 버튼을 옮길 수 있게 만든 뒤 넣었던 시간축·pagination 여백은 필요 없다는 지시로 되돌렸어요.
