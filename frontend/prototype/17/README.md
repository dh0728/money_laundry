# AML RADAR · v17

[단일 HTML 실행](AML-RADAR-v17.html)을 브라우저에서 열면 돼요. React·CSS·아이콘·그래프 데이터가 모두 한 파일에 들어 있고, CDN이나 네트워크 요청 없이 `file://`로 동작해요. 개발 원본은 이 폴더의 `src/`예요.

## 기준

- **수정 정본:** Figma `AML RADAR · shadcn ui kit` → `Wireframe` → section `v14`의 수정 frame 5개, 그리고 v15 첫 검수 결과를 담은 section `v15`예요. 판독 결과와 사용자 확정 사항은 [figma-v14-수정사항-인벤토리](../15/figma-v14-수정사항-인벤토리.md)와 [figma-v15-수정사항-인벤토리](figma-v15-수정사항-인벤토리.md)에 있어요.
- **그래프 데이터:** 모델링 담당 팀원의 `세탁거래_그래프_시각화.html`(IBM AML HI-Small, 계좌 단위)이에요.
- **우선순위:** 현재 사용자 지시 → Figma v14 수정 주석 → 최신 프로젝트 문서 → v14 검토 기록 → v14 코드.
- **출발점:** v16 폴더(`../16`)를 복사해 시작했어요. v16 폴더와 Figma는 수정하지 않았어요.

## v14 이후 바뀐 것

v17은 v16을 복사한 뒤 Figma `v16` 섹션의 수정 주석을 반영한 버전이에요. 반영 내용은 [figma-v16-수정사항-인벤토리](figma-v16-수정사항-인벤토리.md)에 있어요. 아래 목록은 v14 이후 누적 변경이라, v17에서 바뀐 부분은 인벤토리가 우선이에요.

- **로그인:** 노드 네트워크 애니메이션이 화면 전체를 채워요. 로그인 박스는 그 위에 떠 있는 글래스 패널이고, 설명 문구는 삭제했어요.
- **공통 shell**
  - sidebar 여닫기 button, 메뉴 아이콘, avatar를 모두 x=32px 축에 맞췄어요. sidebar를 접으면 알림 수가 bell 뱃지로 남아요.
  - `WORKSPACE` label을 삭제했고, 계정 button은 계정 화면으로 바로 가요. Alert 메뉴 아이콘은 `Siren`이에요.
  - header 왼쪽에 흰색 레이더 로고를 뒀어요. 전역 검색은 Alert·Episode·계좌·알림·화면·설정 항목을 모두 찾아요.
  - 1100px 미만에서는 로고·RDR 9000·back button이 아이콘만 남아요.
  - header 왼쪽의 페이지 이름을 삭제했어요. 상세 화면에서만 `← Alert 목록`이 보여요.
  - `/`·`F11`은 shadcn `Kbd`로 표시하고, 권한은 `L1`로 줄였어요.
  - header 오른쪽 묶음은 조사 도우미와 무관하게 오른쪽 끝에 고정했어요.
- **RDR 9000(조사 도우미)**
  - 떠다니는 진입 버튼을 없애고 전역 검색 오른쪽에 토글 pill을 뒀어요.
  - 아이콘은 HAL 9000과 레이더의 절충이에요. 어두운 원판 가운데 붉은 눈이 있고, 붉은 sweep이 돌아요.
  - 이전 대화 목록은 대화창 뒤에서 왼쪽으로 펼쳐지고 다시 누르면 뒤로 포개져요.
- **목록**
  - 표 위 `총 N건`을 삭제하고 열 간격과 머리글 정렬을 맞췄어요.
  - 위험도와 경과일은 회색에서 순수 빨강까지 10단계로 물들어요. 빨강은 이상거래·오류·고위험에만 써요.
  - 열마다 정렬 아이콘이 `미정렬 → ↓ 내림차순 → ↑ 오름차순 → 미정렬`로 순환해요.
  - 기간 선택기는 이어지는 세로 달력이에요. preset을 누르면 해당 달로 자동 스크롤되고, footer에 초기화가 있어요.
- **Dashboard**
  - 개인 화면의 업무 목록은 바깥 카드 없이 항목별 카드로 나열해요.
  - 기관 전체 화면은 HI-Small 데이터 규모 지표, 패턴별 블록 분포, 세탁 거래 구성, 9종 대표 모양(IBM AML 논문 Figure 2 구조)으로 다시 짰어요.
- **상세**
  - header의 `연결된 Episode`·`검토 의견 작성` button을 삭제했어요. 제목 줄에 ID·상태를 붙이고, 연결 chip과 조회 안내는 오른쪽으로 모았어요.
  - 개요는 일별 금액, 상위 송금 계좌, 결제 수단 또는 연결 Alert 유형, 세탁 거래 모양으로 구성했어요.
  - 검토 의견은 2열이고, 최종 판단 선택지 4종마다 후속 입력과 확정 문구가 달라져요.
- **관계 그래프**
  - 데이터는 팀원 블록이고, 스타일은 로그인 네트워크와 같은 문법이에요. 직선·불투명 선, 모두 점인 노드, 어두운 바탕, hover 발광을 써요.
  - 색은 세탁 여부 1=빨강, 0=무채색이고, 선 굵기는 금액(USD)이에요.
  - `상시 거래 정보 표시` toggle(기본 꺼짐)과 hop 1~5(기본 3)가 있어요.
  - 엣지는 굵은 몸통 끝에 화살촉이 붙은 한 덩어리 모양이에요. 화면 안 금액 범위를 1.2~14px로 나누고, 자기 송금 loop에도 화살촉이 있어요.
  - toolbar는 화면 맞춤(맞춰져 있으면 비활성) → 전체화면 순서예요. 전체화면에는 그래프만 들어가고, 거래 상세는 그래프 위 오른쪽 drawer로 열려요.
  - 좁거나 세로인 화면에서는 거래 상세가 그래프 아래로 내려가요.
  - 시간축 slider, 이전·재생·다음 button, ←/→/Space 단축키가 있어요. 단축키는 그래프에 focus가 있을 때만 동작해요.
- **거래 상세 (Sankey)**
  - 엣지를 선택하면 두 계좌 막대 사이로 양방향 거래를 띠로 그려요. 막대 위쪽은 보냄, 아래쪽은 받음이에요.
  - 계좌를 선택하면 그 계좌가 가운데 막대가 되고, 왼쪽은 보낸 계좌, 오른쪽은 받은 계좌예요.
  - 띠 하나가 거래 1건이에요. 두께는 금액(최대 56px), 세탁 거래는 빨강, 받는 쪽 끝은 화살촉이에요.
- **알림·설정**
  - 알림 카드는 왼쪽 rail(상태 점·되돌리기 button), 본문, 오른쪽 `요약` box로 나뉘어요. 되돌리기는 읽은 알림에서만 활성이에요.
  - 버튼 이름은 `모두 읽음 처리`예요. 읽음 상태는 화면을 이동해도 유지돼요.
  - 설정은 박스 없는 4열(좁거나 세로 화면에서 1열)이고, 선택 즉시 적용돼요.

## 컴포넌트 출처

`src/components/ui/`는 [공식 shadcn/ui](https://ui.shadcn.com) registry 소스예요. v14 구성에 이번에 `shadcn@4.21.0 add kbd`를 더했어요. 차트는 shadcn Chart(Recharts), 아이콘은 Lucide예요.

shadcn에 없는 요소만 직접 만들었어요.

- 계좌 관계 그래프 SVG와 시간축 연동(`Graph.tsx`)
- 거래 상세 Sankey(`Sankey.tsx`)
- 패턴 대표 모양 도식(`PatternGlyph.tsx`)
- 전역 검색 결과 목록(`GlobalSearch.tsx`)
- 로그인 canvas 네트워크(`LoginNetwork.tsx`)
- 로고 레이더 마크(`Brand.tsx`)와 RDR 9000 아이콘(`Agent.tsx`의 `RadarSweep`)

`MiniGraph.tsx`는 이제 쓰지 않지만 삭제 승인 전이라 남겨 뒀어요.

## 데이터와 프로토타입 경계

- `scripts/extract-graph-blocks.py`가 팀원 HTML에서 패턴별 블록 1개씩, 모두 9개(8종 + 패턴 외)를 뽑아 `src/data/graph-blocks.json`을 만들어요.
- **그대로 쓴 값:** 원본 1홉 노드·엣지·계좌번호·은행·소유주·통화·결제 수단이에요.
- **합성한 값(`synthetic: true`)**
  - 2~5홉 이웃
  - 집계 엣지를 건별로 나눈 개별 거래
  - 통화별 고정 환율을 적용한 USD 환산값
  - 연도 이동(2022 → 2026)
- Alert는 탐지 유형이 같은 블록을 보여주고, Episode는 연결 Alert의 서로 다른 블록을 최대 2개까지 이어 붙여요.
- 업무 레코드·담당자·세션·조사 도우미 응답은 예시예요. 인증, 서버 저장, 모델 추론은 연결되지 않았어요. 처리 결과는 실행 메모리에만 남고 새로고침하면 초기화돼요.
- 검수 전용으로 `?state=loading|empty|error|stale`을 붙이면 목록의 예외 상태를 열 수 있어요. 화면에는 시연 control을 두지 않았어요.

## 실행과 검증

Node 22.12 이상에서 이 폴더를 연 뒤 실행해요.

```bash
npm ci
```

```bash
npm test
```

```bash
npm run build
```

그래프 데이터를 다시 뽑을 때는 아래 명령을 써요.

```bash
python3 scripts/extract-graph-blocks.py "../../../../docs/02_data/세탁거래_그래프_시각화.html" src/data/graph-blocks.json
```

`npm run build`는 TypeScript 검사 후 `dist/index.html`을 만들고 `AML-RADAR-v17.html`로 복사해요. 2026-09-18 결과는 테스트 180개 통과, 빌드 통과, 1.52MB예요. 브라우저 검수 결과는 [v17-design-qa](v17-design-qa.md)에 있어요.
