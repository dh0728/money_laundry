# Figma v16 수정사항 인벤토리

## 판독 범위와 방법

- **원본:** Figma `AML RADAR · shadcn ui kit` → `Wireframe` → section `v16`이에요.
  - 사용자가 v16 스크린샷 중 고칠 화면만 남기고 주석을 달았어요.
  - 직접 찍은 Sankey 화면 1장과, 직접 그린 레이아웃 3개(Frame 13 거래 상세, Frame 14 알림 카드, 계정 화면)가 있어요.
- **읽은 방법:** 2026-09-18에 Chrome의 Figma UI로 읽었고, MCP는 쓰지 않았어요.
  - 1920×1080 frame마다 확대해서 노란 주석과 가리키는 대상을 대조했어요.
- **추가 지시:** 채팅으로 두 가지를 더 받았어요.
  - 노드는 연결이 많을수록 커지고, 엣지는 금액이 클수록 확실히 두꺼워져야 해요.
  - 주석이 달린 곳만 고치지 말고, 같은 UI는 전부 같은 규칙으로 처리해요.

## 전역 shell과 로그인

| # | 지적 위치 | 목표 상태 |
|---|---|---|
| S1 | header 로고 | sidebar 안으로 옮기고, 로고 심볼에 hover하면 sidebar 여닫기 아이콘으로 바뀜 |
| S2 | header 검색창 | RDR 9000 버튼처럼 양끝을 둥글게 하고, 최대 폭을 약 420px로 제한 |
| S3 | RDR 9000 버튼 | 아이콘 원과 버튼 끝의 둥근 부분이 같은 중심을 갖도록 위·아래·왼쪽 간격을 같게 |
| S4 | 펼친 sidebar 알림 수 | 접었을 때처럼 빨간 뱃지. 실제 안읽음 수를 따름 |
| S5 | 권한 표기 | `L1 · 1차 검토`는 중복 표현이라 `L1`로 |
| S6 | 계정 button 활성 | 다른 메뉴처럼 흰색으로 채움 |
| L1 | 로그인 로고 | 현재 레이더 로고로 교체 |
| L2 | 로그인 배치 | 가운데를 나누는 요소가 없어 로그인이 오른쪽으로 치우쳐 보임 |

L2는 사용자가 두 방안 중 고르라고 했어요. 제안된 두 방안은 다음과 같아요.
1. 왼쪽 설명을 없애고 로그인을 정중앙에 둔다.
2. 지금 배치를 유지하고 오른쪽 절반 전체를 frosted glass로 덮는다.

2번을 골랐어요. v14 검토에서 왼쪽 문구를 유지하기로 이미 정했기 때문이에요.

| # | 지적 위치 | 목표 상태 |

| T2 | 정렬한 열 머리글 | 아이콘만이 아니라 머리글 칸 전체를 색 반전. 글자는 왼쪽 끝, 아이콘은 오른쪽 끝 |

| T4 | 위험도 점수 badge | 테두리형 대신 채운 형태. 다크 모드에서 빨강이 잘 보이게 |
| D1 | 패턴 대표 모양 | 패턴 종류일 뿐이라 경고로 오해하지 않도록 빨간 원을 흰색으로 채운 원으로 |

| E2 | 조회 안내 문구 | `안분석가` → 받침에 맞춰 `안분석이` |
| E3 | 검토 의견 작성란 | 여백과 작은 크기 조절 손잡이를 없애고 처음부터 크게 |

E1 상세 header는 이렇게 바꿔요.
- **연결 기록:** 연결된 Alert가 3개이므로 제목 옆에 링크 버튼만 둬요. 누르면 3개 선택지가 팝업으로 떠요.
- **ID·상태:** 둘째 줄 맨 앞으로 옮겨요.

## 관계 그래프와 거래 상세

| # | 지적 위치 | 목표 상태 |
|---|---|---|
| G1 | 엣지 | 몸통이 점점 굵어지는 모양은 그라데이션처럼 보여서, 선 하나의 두께를 일정하게 되돌림. 금액이 클수록 확실히 두꺼워짐 |
| G2 | 엣지와 노드 사이 | 노드가 끊겨 보이지 않게 선을 노드 가장자리에 붙임 |
| G3 | 자기 송금 loop | 지나치게 굵지 않게. 시작점은 얇아도 됨 |
| G4 | 노드 크기 | 연결이 많을수록 큼 |
| G5 | 엣지 선택 상세 | Sankey 대신 사용자 레이아웃(Frame 13)으로 |
| G6 | 계좌 선택 Sankey | 여러 계좌를 한 번에 보여주려면 넓어야 함. 폭을 조절할 수 있게 하고, 정보를 띠 위에 표시 |

G5 사용자 레이아웃(Frame 13)의 구성이에요.
- **계좌 lane:** 양 끝에 두 계좌 lane을 둬요.
- **거래 띠:** 그 사이에 전체 폭의 화살표 띠를 양방향으로 그리고, 두께는 금액이에요.
- **거래 정보:** 띠 안에 거래 정보를 적고, 아래 목록은 없애요.
- **정렬 버튼:** 닫기 버튼 아래에 정렬 버튼을 둬요. 금액·시간 기준으로 오름차순·내림차순을 골라요.
