# AML RADAR v17 브라우저 QA

기준은 [figma-v16-수정사항-인벤토리](figma-v16-수정사항-인벤토리.md)예요. 2026-09-18에 Playwright 전용 Chromium으로 1920×1080 화면을 찍어 확인했어요. 테스트는 180개 통과, 빌드 통과, 페이지 오류 0건이에요.

| 영역 | 확인 동작 | 실제 결과 |
|---|---|---|
| header | 768·1024·1280·1440·1920px, 대시보드·상세 화면 | 10개 조합 모두 겹침 0, 가로 넘침 0. 검색창은 1920px에서 420px |
| header 위치 | 뒤로가기 유무 | 처음에는 상세 화면에서 검색창이 49px 옮겨졌음. 양옆 칸을 같은 비율로 둔 grid로 바꾼 뒤 1024px 이상에서 차이 1px 이하. 900px 미만은 왼쪽 정렬 |
| 로그인 | 첫 화면 | 오른쪽 절반 전체가 frosted glass 로그인 영역. 따로 된 로그인 카드는 없음. 로고는 레이더 마크 |
| 목록 | Alert 목록 | 페이지당 20행(설정 기본값) |
| 관계 그래프 | 엣지·노드 | 엣지는 일정한 굵기의 선과 화살촉. 금액 로그 척도 1~12px. 노드는 연결 수에 따라 크기가 다름 |
| 거래 상세 | 엣지 선택 | 양 끝 lane 사이 전체 폭 화살표 띠. 띠 안에 거래 ID·시각·금액·통화. 아래 목록 없음. 정렬 버튼 |
| 거래 상세 | 계좌 선택 | 넓은 panel(기본 560px, 폭 조절). 띠 위에 금액·시각. 처음에는 Sankey가 panel 위쪽 1/4만 차지해서, panel 높이를 재서 채우도록 수정 |
| 알림 | 알림 화면 | 안 읽음·읽음 두 열, 열마다 시간순 정렬 버튼, 필터 없음. sidebar 뱃지는 실제 안읽음 수(10) |
| 계정 | 계정 화면 | 큰 박스 없이 프로필·세션 관리. 역할 `L1`. sidebar 계정 버튼은 흰색 활성 |

**검증 한계**
- 드래그로 폭을 조절하는 동작(RDR 9000 sidebar·이전 대화·플로팅, 거래 상세 panel)은 테스트로 코드 경로만 확인했어요. 실제 마우스 드래그는 확인하지 않았어요.
- 라이트 테마는 확인하지 않았어요.
