# Figma v17 수정사항 인벤토리

## 판독 범위와 방법

- **원본:** Figma `AML RADAR · shadcn ui kit` → `Wireframe` → section `v17`
  - 위치 대략 X 84288, Y 23, 크기 9280×5725
  - 주석이 달린 스크린샷 frame 약 9장 판독(기대 ~13장 중 UI로 확인된 범위). 노란 텍스트 주석 **16개** 전부 확대 후 원문 판독.
- **읽은 방법:** 2026-09-18 Chrome Figma UI만 사용. MCP/API 없음. `Shift+2` 확대, 주석이 밖이면 `Shift+-`. 숫자키(opacity) 미사용.
- **추가 규칙:** 주석이 달린 한 곳만이 아니라 **같은 UI는 전부 같은 규칙**. 빨강은 경고만. 확인 못한 동작은 한계로 명시.

## 명기 미응답 → Fredy 결정 (2026-09-18)

질문 위젯이 응답 없이 넘어가서, 주석 원문·같은 UI 전역 규칙으로 아래처럼 확정했어요.

| # | 결정 | 근거 |
|---|---|---|
| T3 | **(C) 행 높이·폰트만 한 단계 키우고, 패널 높이는 리사이즈에 맡김** | 주석 핵심은 가독성(“정보 확인이 안됨”). G6/G7이 이미 리사이즈를 요구하므로 높이 기본값을 고정하지 않음 |
| G1/G2 | **(A) 출발 계좌 위 · 도착 계좌 아래 한 열 세로 스택** | “세로로 배치”, “위에 가로로 두지 말 것” 주석과 일치 |
| R2 | **(C) 리사이즈 핸들이 없는 텍스트 박스 전부**(RDR 입력 + 검토 의견 등) | “같은 UI는 전부 같은 규칙” |

해석이 분명한 항목과 위 결정을 포함해 병렬 구현 착수.
