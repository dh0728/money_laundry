- B18 관계 그래프 흐름 가독성: 의심 엣지 투명도를 70%→45%로 낮추고 정상 거래에도 반투명 흰 이동 점을 추가. 원본 그래프 화면 맞춤 버튼을 우하단 `− / 배율 / +` 묶음 옆으로 이동. → **Codex 완료(9/19)**: 브라우저에서 선·이동 점 구분과 `− / 배율 / + / 화면 맞춤` 배치 확인.
- B19 상세 흐름 조작부가 그래프에서 떨어져 보임. 카드 우하단 가장자리에 고정하고, 배율·이동 위치가 화면 맞춤 상태이면 맞춤 버튼 비활성화. → **Codex 완료(9/19)**: 브라우저에서 가장자리 배치와 `88% 활성 → 맞춤 → 100% 비활성` 전환 확인.
- B20 RDR 9000 표시 방식의 드롭다운은 클릭이 불필요하게 많음. 상세 거래 패널처럼 헤더 아이콘 한 번으로 `우측 사이드바 ↔ 플로팅`을 직접 전환. → **Codex 완료(9/19)**: 브라우저에서 양방향 한 번 클릭 전환과 드롭다운 제거 확인.
- B21 읽기 전용 카드와 클릭 가능한 카드·표 행의 hover 차이가 약함. 클릭 가능한 넓은 영역만 테두리 전체와 외곽 빛을 강화하고 키보드 focus에도 같은 상태 적용. → **Codex 완료(9/19)**.
- B22 그래프 hop 설정이 범위 밖 노드·엣지를 흐리게만 해 복잡도가 줄지 않음. 선택 계좌의 hop 범위 밖 항목을 완전히 숨기고, 선택 전 slider 비활성 조건과 `연결 단계(hop)` 의미를 문구에 명시. 선택 시 배치가 움직이지 않도록 전체 시뮬레이션 데이터는 고정하고 visibility만 변경. → **Codex 재수정 완료(9/19)**: 브라우저에서 선택 전 비활성, 3 hop `26개/33개` → 1 hop `4개/5개` 축소 확인.

## Codex 인계 · 작업 방식 (Claude → Codex)

- 작업 폴더: `Prototype/20` (v19는 리뷰 전 기록이라 건드리지 않는다). 실행 `npm run dev -- --port 5180`, 산출 `npm run build`(postbuild가 `AML-RADAR-v20.html` 복사), 검증 `npx tsc --noEmit` + `npx vitest run --testTimeout=30000`.
- 테스트 기준선: 실패 6건은 v18부터 있던 테스트-코드 불일치(로그인 glass 2·로그인 패널 1·Agent FAB 1·F11 Kbd 1·textarea 1). 새 실패만 막는다. 의도한 변경과 충돌하는 옛 테스트는 새 규칙으로 고치되 이전 확정 규칙(예: 역할 표기 L1/L2만, 세션 행 bg-muted/40)은 지킨다.
- **UI를 직접 디자인하지 않는다**(명기 반복 지시). 순서: 이미 설치된 shadcn 컴포넌트 → 공식 블록(`npx shadcn@latest view @shadcn/<block>`) → 커뮤니티 레지스트리(registry.directory, Dice UI 등) → npm 표준 라이브러리. 가져온 코드는 데이터·문구만 바꾼다.
- 이미 채택한 것: dashboard-01 section-cards·chart-area-interactive(`src/blocks`), Dice UI data-table(`src/components/data-table`, TanStack Table **v8 고정**, `clientSide` 옵션·`onRowClick`·한국어화는 우리가 추가), react-force-graph-2d(관계 그래프, lazy import), recharts Sankey(상세 흐름), react-rnd(떠 있는 상세 창), react-zoom-pan-pinch(Sankey 확대), nuqs(목록 정렬·페이지 URL).
- shadcn CLI 함정: 레지스트리가 기존 ui 파일 덮어쓰기를 물으면 멈춘다 → 임시 복사본에 `--overwrite`로 설치 후 새 파일만 복사. Dice UI는 import 경로(`@/types`·`@/config`·`@/lib`)를 `@/components/data-table/data-table`로 잘못 바꾼다 → 설치 후 import 확인.
- 호버 체계(index.css 끝 v20 블록 + main.tsx `SHINE` pointermove): 모든 표면은 커서 주변만 옅게 밝아지는 `::before` 층, 입력란은 `background-image`(::before 불가), 버튼은 전체 글로우 + 커서 쪽 테두리 빛. 탭·링크형 버튼 제외. 반짝이 입자·빨간 배경 번짐 금지. 선택자 목록은 CSS 3곳과 SHINE 1곳을 같이 고친다.
- 그래프 규칙: graphData는 전체 모델로 고정하고 계좌 선택 후 hop 범위 밖 노드·엣지는 visibility로 숨김, 드래그만 물리 반응, 화살촉은 도착 끝, 의심 흐름 입자는 빨강·정상 흐름 입자는 반투명 흰색. 상세는 오른쪽 도킹(좁으면 아래) + 떠 있는 창, 글자는 확대 배율 역수로 고정.
- 브라우저 확인 필수: Claude 창이 가려지면 스크린샷이 멈춘다. 로그인 필요한 외부 사이트는 명기에게 로그인을 부탁한다. Figma MCP는 월 예산 규칙상 참고 조회에 쓰지 않는다(UI 경로).
- 명기 선호: 짧은 문장 한 줄 한 가지, 캐주얼 짧은 응답. 수정 목록은 "메모하고 기다려"면 실행하지 않고 인벤토리에만 쌓는다.
