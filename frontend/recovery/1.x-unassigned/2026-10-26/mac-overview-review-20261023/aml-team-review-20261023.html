AML RADAR · 전체 조사 흐름 검토안

2026-10-23 · 문서 검토본. 화면 구현·배포·실제 Backend/AI 검증 완료가 아닙니다. 이 파일은 설명 문서이며 PairView에 넣을 실행 FE를 대신하지 않습니다.

1. 보존할 전체 업무 흐름

대시보드에서 전체/내 업무 맥락 파악 → Alert·Episode 교차 조사 → 관계 그래프·정확한 거래 상세 확인 → 같은 사건 의견·명시 판단 → 결과 재조회·업무 재개.

팀이 숙고한 기존 구조를 폐기하지 않습니다. 요약과 상세의 분리 자체는 결함이 아니며 실제 관찰에서 막힌 연결과 의미 전달을 개선합니다.

화면누가·왜 보나판단과 다음 행동
대시보드조사자의 빠른 업무 맥락 파악대상·기간·상태/담당을 확인하고 Alert 또는 Episode 선택. 다른 단위의 점수를 자동 통합하지 않음.
Alert / Episode 목록단일 탐지 건 / 여러 원본의 묶음 조사조건·담당·경과로 사건 선택. 편입은 의심 확정·업무 완료를 뜻하지 않음.
개요현재 사건을 빠르게 이해핵심 신호·범위·한계 요약 후 그래프·거래표·검토로 이동.
그래프계좌·소유주 관계와 자금 흐름 조사실제 거래 집합/시각/동일 소유주를 대조. 그래프 포함은 GNN 판단 이유나 양성을 뜻하지 않음.
거래표 / 거래 내역원거래 직접 탐색·사실 확인정확 txId·양쪽 계좌/소유주·금액/시각 확인. 조회 확대·연결 사건 조사 후 출발점 복귀.
검토 의견 / 알림확인 사실·판단·변화 기록조사 중 같은 사건 의견 작성. 의견 저장과 명시 판정/종결 분리. 알림은 정확한 사건/이력으로 연결.

2. 관찰에 근거한 개선안

우선확인 문제·근거수정안·책임 경계수용 기준
1 정확성로컬 fixture의 편입 원본 집계와 유효 근거가 다름. 상세 표 소유주 변환 누락.FE: 기존 편입 계약과 fixture/집계를 맞추고 accountId로 당사자 연결. 제외 필터 완화·이름 추측 금지.사건/묶음/거래 내역의 같은 거래·당사자/집계 일치. 제외·참고·공유 중복 구별.
2 업무 맥락대시보드 집계 대상·Alert/Episode 점수 비교의 의미 불명확.FE: 대상/분모·기간·조건 표시. 집계 변경·점수 비교/업무 우선은 팀·BE 결정.무엇의 몇 건인지, 현재 범위와 점수 한계를 설명. 임의 자동 순위 없음.
3 연결·복귀다른 Episode 조사 후 원래 사건 재검색. 검색에 남은 필터를 놓침.FE: 출발/현재 대상·적용 조건·기존 복귀 연결. 구체 배치와 검색 정책은 제안.거래→다른 사건→원래 사건 복귀. 실행 중 의견/문맥 유지. 읽기 탐색으로 업무 명령0건.
4 묶음·관계분리 그룹의 편입 이유·시간 관계를 찾기 어려움.기존 사유/원본 차이·공유 사실 연결. 전문 그래프·표 직행 보존. 없는 관계/간접 경로는 BE 확인.실제 편입 이유와 단순 관계 구별. 나중 입금을 이전 송금의 선행 자금원으로 오인하지 않음.
5 기록·결과의견과 기본 정상 종결 혼동, 알림과 합성 이력 대응 부족.FE: 판정 미선택·명시 확인, 의견만 저장 분리·필수 조건/알림 연결. 실제 저장/권한은 BE 검증.의견 저장만으로 종결0건. 실제 저장은 응답→재조회/이력 확인. 실패/충돌/결과불명 입력 보존.

3. 선택한 방향과 결정할 항목

선택됨: Ant Design 공식 기본 라이트/다크·한국어 UI. 고정 폭 아이콘 사이드바, 별도 여닫기 토글 없음. 메뉴명은 hover/keyboard focus Tooltip과 접근성 이름으로 제공하고 현재 메뉴/페이지 위치를 유지합니다. 터치의 메뉴명 접근도 검수합니다.

기존 전문 그래프를 보존하며 Ant로 대체하지 않습니다. 메뉴를 임의 통합·삭제하지 않습니다. 미결: 조사 중 의견 Drawer/동시 패널 배치, 검색 진입의 필터 처리와 교차 조사 후 복귀 위치. 그래프 렌즈·업무 우선 정책·미제공 API는 기존 OPEN입니다.

5. 현재 증거와 제한

로컬5208의 합성 UI-only 관찰은 FE 개선 근거입니다. 실제 dev/BE/AI 검증으로 바꾸어 부르지 않습니다. 실제 dev https://dev.aiaml.co.kr/ 은 검토자와 사용자가 모두0건을 확인했고 재진입 로딩도 관찰됐으나 원인 미확인입니다. dev 폐기는 미확인이고 핵심 조사 평가는 유보입니다.

Ant 검수 코드는 일부 저장됨. 관련11개 검사 통과 후 전체262개 중261개 통과·1개 시간 초과. 마지막 타입 검사 통과·lint 오류0/기존 경고1. 최종 전체 build 증거 없음. 격리 브라우저는 사건 왕복·정확 거래·다른 Episode 발견/복귀·쓰기 차단·일부 키보드/테마 확인 후 그래프 TooltipProvider 누락 오류에서 중단됐습니다. 전체 검수 완료가 아닙니다.

실제 저장·장기 보존·판정·종결·권한 집행·AI 성능은 미검증입니다. 최종 사용자 검수와 팀 공유 준비 완료가 아닙니다. 현재 추가 제품 구현은 문서 검토 뒤로 보류했습니다.

6. PairView 연결 준비

기존 PairView의 data/links.json·API/evidence 입력과 브리지를 재사용해 완성 FE 요소와 method/endpoint/request/response를 대응시킵니다. 문서를 FE 평면에 대신 넣지 않습니다.

현재 trustedLiveUrl은 localhost 루트 /만 허용합니다. 새 Ant의 /ant-review.html은 그대로 등록할 수 없고 브리지 초기화/DOM 식별자도 미연결입니다. 임의 주소 허용으로 우회하지 않습니다. 완성 화면의 route·실제 좌표·라이트/다크 왕복과 origin/source/channel/nonce 검증, 합성/미연결 표시가 일치해야 연결 완료입니다. PairView 소스/서버는 이번에 바꾸지 않았습니다.

검토 요청과 다음 관문

기존 역할·전체 여정 보존과 변경 이유/데이터 책임을 검토하고 최소 미결 배치·검색/복귀를 결정합니다. 이후 로컬 오류/회귀·전체 검사, 독립 UI·사용자 직접 검수, 실제 연동/AI 증거와 한계, 완성 FE의 PairView 연결 검수를 진행합니다.
