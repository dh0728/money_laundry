# 데이터 특성 메모 — HI-Small

## 라벨 구축

- `HI-Small_Patterns.txt` 세탁 시도 370건 → 거래 3,209행, Trans.csv와 **1:1 전량 매칭** (미매칭 0, 중복 0)
- 10클래스: 0=정상, 1~8=패턴, 9=비패턴 세탁
- 산출물: `data_work/HI-Small_labels_10class.csv` (원본 행 순서 정렬, `label` + `attempt_id`)

## 기간과 꼬리

- 전체 2022-09-01 ~ 09-18, 그러나 **거래의 99.98%가 09-10까지**
- 09-11 이후 꼬리 1,108건 중 세탁 655건 (세탁 비율 최대 59%) → 비현실적 분포
- 팀 합의로 `ts < 2022-09-11`만 사용

## 클래스 분포 (꼬리 제외 전 기준)

정상 5,073,168 / 비패턴 1,968 / G-S 716 / S-G 626 / STACK 466 / FAN-OUT 342 / FAN-IN 318 / CYCLE 287 / BIPARTITE 263 / RANDOM 191

세탁 5,177건 = 전체의 0.10%. 세탁 중 비패턴 38%

## 배경(비패턴) 세탁 — 구조적 난이도

- 꼬리 제외 후 세탁의 43.5%, val 구간 36.6%
- 패턴 세탁 계좌와 접촉률 **1.7%** = 정상 거래의 1.8%와 동일 → 계좌 맥락 경로 없음
- 송금 계좌 1,315개 중 96%가 1~2건 → 이력 축적 전 종료, 그래프 피처 무반응
- 남은 신호: ACH 65%, USD 금액 $767~4,375 중간대역
- run_002 실측: recall 0.7 지점에서 30.3%만 탐지 (패턴은 93.0%)
- val에서 패턴 세탁을 전부 잡아도 전체 recall 상한 63.4%

## 자기거래

- 590,819건 = 11.6%. 라벨은 사실상 전부 정상 (세탁 8건, 리프트 0.015)
- 개입(정제) 실험 후보

## 단건 신호 리프트 (세탁 기본비율 0.089% 대비)

- Payment Format: ACH 7.2배 (세탁의 85%가 ACH). Reinvestment·Wire는 세탁 0건
- 금액: 세탁 중앙값 $5,074 vs 정상 $891. $5천~2만 구간 3.6배
- 금액/통화 불일치(환전 거래) 71,767건: 세탁 **0건** → 배제 신호
- 동일 은행 0.135배, 자기거래 0.015배 → 배제 신호
- 엔티티 유형: Corporation 1.29배, Country 0.38배, 나머지 ~1배 (약함)
