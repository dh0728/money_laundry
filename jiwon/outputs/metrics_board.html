리프 보정값 공식 w = -G/(H+λ) (G=그래디언트 합, H=헤시안 합, λ=lambda_l2) 이 사다리 전체의 배경이다. NORMAL 99.9% 불균형에서 모델이 금방 확신에 도달하면 H 가 0 으로 소멸하고, λ=0 이면 리프 값이 폭주해 점수가 0/1 로 포화된다(run_001). run_003~005 는 이 폭주/무학습을 다른 손잡이로 막으려던 시도다.

무엇인가이 데이터에서의 동작
lambda_l2L2 정규화. 리프 값 분모에 더해지는 상수H 소멸에도 리프 값을 -G/λ 로 유계화 — 폭주를 뿌리에서 차단한 유일한 손잡이(지배적 변인). 클수록 보정이 소극적이라 수렴 라운드 증가(10→87, 100→315). 과하면 분리력 하락(200부터 주지표 꺾임)
min_sum_hessian_in_leaf리프의 H 합 하한 — H 소멸 리프를 아예 만들지 않는 분할 조건같은 병을 다른 각도로 공격하나, 소수 세탁 샘플 영역도 H 가 작아 필요한 분할까지 금지 — λ 만 못함(run_003)
min_data_in_leaf리프의 최소 샘플 수. 통상적 과적합 방지세탁 클래스는 건수 자체가 적어 소수 클래스 분리 분할을 봉쇄 — 사실상 무학습(run_004, PR-AUC 0.0011)
클래스 가중치(역빈도)손실에서 소수 클래스 오차를 빈도 역수만큼 증폭그래디언트·헤시안을 함께 증폭해 폭주를 자극하고, 확률 눈금 왜곡이 순위 평가에 손해(run_005)
조기종료 지표매 라운드 val 성능으로 정지 시점 판단 — 그 기준 지표PR-AUC 는 초기 라운드 분산이 커서 1라운드 오발 정지(run_006). 좋은 평가지표 ≠ 좋은 종료신호

num_threads계산 병렬화만 담당결과 무영향 — 002b 와 이식 검증(4/8/12/14 동일 PR-AUC)으로 2회 확인

  • precision 을 가르는 건 NONPAT 추격. recall 0.5 까지는 패턴 세탁만으로 채워지고(NONPAT 0~14%) 알람 ~540건에 precision 94~97%. recall 0.7 은 NONPAT 26~39% 를 요구해 알람 2.2천 건·precision 30~33%, recall 0.9 는 NONPAT 73%+ → 알람 4.2만+ 건. 개입 실험 1호(배경 세탁 train 행 제거)의 근거.
  • 보조 운영점 P@패턴R0.9 (recall 닻을 패턴 8클래스로 한정, NONPAT 제외): 기준선 011b 는 알람 755건에 precision 79.7% — 패턴 세탁 90% 를 전체 닻 (P@R0.7: 2,204건·33%)보다 훨씬 싸게 잡는다. 업계 규칙 기반 오탐률 85~99% 와 비교하면 매우 정예한 큐. run_005 는 여기서도 완패(6,817건·11%) — 클래스 식별력(D-4)이 순위 품질로 이어지지 않는다는 재확인. 패턴R=1.0 닻은 꼬리가 깊어 무너진다(알람 4.8만) — 닻은 0.9~0.95 가 현실적.
  • 클래스별 탐지(C)는 정상 모델 간 차이가 작다 — R0.7 에서 패턴 탐지율 대부분 86~98%. 기준선들이 이기는 건 같은 recall 을 더 적은 알람으로 달성해서다. 최약 패턴 BIPARTITE(85.7~87.8%), 최강 S-GATHER·FAN-OUT. attempt 단위는 어느 정상 모델이든 94~98%.
  • D-4(OVR PR-AUC)가 피처 방향을 가리킨다. 전 모델 공통 최약 신호 NONPAT(~3), RANDOM(~10), BIPARTITE(~13), FAN-OUT(~23). λ·리프 변인은 이 진단을 거의 못 움직였고, 유일하게 움직인 파라미터는 H하한(011b: FAN-OUT +7.2, FAN-IN +7.5, STACK +6.0). 큰 도약은 피처(features_v2)의 몫. discard 된 run_005(가중치)가 다수 클래스 최고(G-SCATTER 74.2)인 점도 유효 — 클래스 신호와 탐지 성능은 별개 축.
  • 경계 걸침 블록 편향 — run_013(purge)으로 성질 확정. val 패턴 블록의 59% (거래 64%)가 train 에서 이어진 블록. purge(걸침 블록의 train 라벨 535건 제거) 결과: 탐지의 걸침 우위(97.1 vs 92.4%)는 라벨 없이도 유지(95.2 vs 89.5%) — 계좌 이력 피처의 정당한 효과다. 반면 argmax 분류의 걸침 우위(39.3 vs 22.8%)는 라벨 제거로 붕괴(6.4%) — train 에서 답을 본 수법의 지문 재인식이었다. 보고 규율: 탐지 지표는 aggregate 신뢰, 패턴 분류 능력은 포함 블록 기준(011b 22.8%)으로만 주장, keep/discard 판정 시 탐지@R0.7포함 열 교차 확인. purged 학습은 미채택 — 포함 성능까지 하락(조각 = train 패턴 표본의 41%). 실무의 라벨 지연(SAR 확정 수 주~수 개월)을 감안하면 포함 기준이 배포 현실과도 정합. test 로 이어지는 val 블록 92개 — test 개봉 때 같은 규율.
  • 패턴 분류(D)는 탐지(C)와 완전히 다른 그림. run_011b 분류 recall 0~51% (G-SCATTER 51, FAN-IN 45, RANDOM·NONPAT 0). 오분류 최대 목적지는 NORMAL, NONPAT 379건 전원 NORMAL(007c 와 동일 — 세탁점수로만 걸리는 클래스). 011b 는 CYCLE→STACK 혼동(28.8%)이 007c(7.6%)보다 커지는 등 패턴 간 혼동이 재배치됨.
