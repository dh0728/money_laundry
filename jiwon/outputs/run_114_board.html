Ⅷ. 블록 재구성 · 판정 층 — 진행 중 (다음 실험 run_115)

왜: run_114 혼동 분석 — 분류 실패의 55%는 패턴 간 혼동이고 탐지 유출은 2.7%뿐. 결정 증거(BP↔STACK: "수신자가 이후 또 보내는가", RANDOM: 블록 중계율 ~90%)가 거래 하나에는 없고 블록 층위에만 존재 — 거래 단위 argmax 의 원리적 한계. 블록 판정은 사후(조사 시점)라 인과 제약도 없다. 서빙 위치: 추론 서버 배치 잡 → DB block 테이블.
  • 실측 반복 1 — 통념적 "계좌 공유 + 시간창" 연결요소: 기각. attempt 간 계좌 재사용 접점 6만 개(gap 중앙값 1.2일)가 블록 내부 gap 분포(p99 28.8일)와 완전히 겹침 — 최선 pairF1 0.046.
  • 실측 반복 2 — 자금 흐름(체인)·금액 매칭·팬 형제 규칙: 부족. 체인 간선조차 attempt 내부 비율 17.7~30%.
  • 실측 반복 3 — 돌파구: 허브 계좌. 패턴 계좌의 86%는 단일 attempt 소속, 비허브 간 체인 간선 순도 100%(6만 개 전수) — 오염원은 재사용 허브 14%뿐. 단, 허브를 관측 가능 프록시(활동기간 AUC 0.951)로 하드 컷하면 CC 가 전이적으로 취약(F1 0.398 vs 오라클 상한 0.664).
  • 확정 설계: 동일블록 간선 분류기(정답 attempt 16,467개로 지도학습, 후보 간선 ~120만) → 확률 가중 뼈대 CC → 허브 거래 사후 부착. 간선 단위 결정이라 하드 컷의 전이 취약성이 없음. 이후 블록 분류기 사다리(집계 피처 GBT vs 블록 GNN — GNN 첫 투입 지점).
