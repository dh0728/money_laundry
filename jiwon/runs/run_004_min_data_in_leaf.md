## 정정 — 실패가 진단을 확증함

원인은 "샘플 수가 적은 것"이 아니라 **헤시안 질량 소멸**.

- 예측이 0/1로 포화 → 헤시안 `p(1-p)` → 0
- 리프에 샘플 200개를 채워도 전부 헤시안 ≈ 0이면 분모는 여전히 소멸
- `min_data_in_leaf`는 샘플 **개수**만 세고 헤시안을 보지 않음 → 되먹임 고리 못 끊음
- `lambda_l2`(분모에 상수)·`min_sum_hessian`(헤시안 부족 분할 거부)만 고리를 끊음
