# run_006 — 조기종료 지표 multi_logloss → PR-AUC(세탁점수)

상태: 완료(discard)
기준선: run_001
단일 변인: 조기종료 판정 지표를 `multi_logloss` → `1-P(정상)`의 PR-AUC (custom feval)
피처: features_v1
가설: 불균형에서 logloss는 정상 클래스에 지배됨 → 31라운드 조기종료는 과소학습. 세탁 랭킹 지표로 바꾸면 더 오래 학습하며 개선

## 결과 — 가설 빗나감, 다만 진단에 기여

| 지표 | run_001 | run_006 |
|---|---|---|
| PR-AUC | 0.1146 | 0.2721 |

## 해석

- 최적 라운드 = **1**. PR-AUC가 1라운드에서 정점, 이후 30라운드 개선 없어 조기종료
- 과소학습이 아니라 **과학습이 문제였음** — 정규화 없는 설정에서 부스팅을 돌릴수록 포화 되먹임이 누적되어 랭킹 품질이 나빠짐
- 1라운드짜리 모델이 31라운드 기준선보다 PR-AUC 2.4배 → run_001 진단(되먹임 고리) 확증

## 판정: discard

- run_002에 열세
- 단, 정규화가 적용된 상태(run_002 계열)에서는 다시 시험할 가치 있음. 그때는 조기종료가 실제로 더 긴 학습을 허용할 수 있음
