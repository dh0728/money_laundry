# run_008 — 라운드 상한 300 → 1000

상태: 완료(discard)
기준선: run_007c (`lambda_l2` 100, 상한 300, PR-AUC 0.6496 / max-F1 66.21% / P@R0.7 32.96%, best_iter 293)
단일 변인: `num_boost_round` 300 → 1000 (조기종료 30 유지)
피처: features_v1
가설: 007c 는 293/300 으로 상한에 닿아 조기종료가 걸리지 않았다. 즉 val 성능이
아직 오르는 중에 끊겼다. 상한을 풀면 조기종료가 실제로 작동하는 지점까지 가고
주지표 P@R0.7 이 32.96% 에서 더 오른다. 다만 증가폭은 체감할 것으로 본다 —
라운드를 3배 늘려도 부스팅 후반 이득은 작다.
예측: best_iteration 이 300~700 구간에서 조기종료, P@R0.7 33~37%.

반증 조건: best_iteration 이 300 근처에서 멈추면 상한은 병목이 아니었고 007c 의
293 은 우연이다. 성능이 떨어지면 과적합 구간에 이미 들어와 있었다는 뜻.

## 결과 — 예측 절반 적중, 결론은 반대

| 지표 | run_007c (기준선, 상한 300) | run_008 (상한 1000) |
|---|---|---|
| PR-AUC | 0.6496 | 0.6495 |
| max-F1 | 66.21% | 66.35% |
| P@R0.7 | **32.96%** | 32.93% |
| best_iteration | 293 (상한에 닿음) | **315** (조기종료 작동, 345 정지) |
| 학습 시간 | 392s | 554s |

조기종료가 315 에서 실제로 걸렸다. 예측한 300~700 구간 안이지만 하단이고,
성능은 동률이다 — P@R0.7 -0.03%p, PR-AUC -0.0001, max-F1 +0.14%p.

**정정:** "상한을 풀면 P@R0.7 이 33~37% 로 오른다" 는 예측은 빗나갔다. 007c 가
놓친 22 라운드에는 이득이 없었다. **라운드 상한은 병목이 아니었다.**

## 부수 효과 — 007c 오염 우려 해소

007c 를 채택할 때 "293/300 으로 상한에 닿아 λ≥100 비교가 오염됐다" 고 적었다.
λ=100 의 실제 수렴점이 315 로 확인됐으므로 007b(194) 대 007c(293) 비교는
공정했다. 007c 의 기준선 지위는 유지된다.

## 판정: discard

주지표 동률에 학습 시간만 +41%. 기준선 상한은 300 으로 유지한다.
다만 `run_ladder.py` 의 `ROUNDS` 는 남긴다 — λ 를 200/500 으로 올리면 수렴점이
315 보다 뒤로 밀리므로, λ 재탐색은 상한 1000 에서 돌려야 큰 λ 가 막히지 않는다.
