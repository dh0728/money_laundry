# run_009 — lambda_l2 상방 재탐색 (200 / 500)

상태: 완료(discard) — λ=100 최적 확정
기준선: run_008 (`lambda_l2` 100, 상한 1000, PR-AUC 0.6495 / max-F1 66.35% / P@R0.7 32.93%, best_iter 315)
단일 변인: `lambda_l2` 100 → 200(009a) / 500(009b). 상한 1000 고정
피처: features_v1
가설: P@R0.7 이 λ 10→50→100 에서 28.09 → 29.54 → 32.96% 로 단조 상승했고 상방이
아직 안 닫혔다. 그러나 정규화는 어디선가 과해진다 — 리프 값이 지나치게 눌리면
클래스 분리력이 떨어진다. 200 에서 정점 부근(33~35%), 500 에서 하락으로 본다.
즉 이번 실험이 상방을 닫을 것으로 예상한다.

주의: λ 가 클수록 수렴이 느려진다. λ=100 의 수렴점이 315 였으므로 500 은 상한
1000 에 닿을 수 있다. 닿으면 그 결과는 상한에 오염된 것으로 취급한다.

기준선 주석: 사다리 전체의 현 기준선은 run_007c(λ=100, 상한 300)다. 이 실험만
상한을 1000 으로 고정해 λ 를 단일 변인으로 유지하려고 run_008 을 기준선으로 쓴다.
run_008 에서 상한 300 → 1000 이 성능 동률임을 확인했으므로 두 기준선은 호환된다.

## 결과 — 상방 닫힘, 정점 위치는 빗나감

| 지표 | run_008 (λ=100, 기준선) | 009a λ=200 | 009b λ=500 |
|---|---|---|---|
| PR-AUC | 0.6495 | **0.6531** | 0.6490 |
| max-F1 | 66.35% | **66.87%** | 66.30% |
| P@R0.7 | **32.93%** | 30.07% | 30.34% |
| best_iteration | 315 | 493 | **1000 (상한 도달 — 오염)** |
| 학습 시간 | 554s | 676s | 1260s |

주지표 P@R0.7 은 λ=200 에서 하락했다(32.93 → 30.07%). 명세에 적은 대로 009b 는
상한 1000 에 닿아 오염 — 그러나 오염이 유리하게 작용해도 30.34% 로 기준선 미달이라
결론에는 영향 없다.

**정정:** "200 에서 정점 부근(33~35%)" 예측은 빗나갔다. 정점은 λ=100 이다.
"이번 실험이 상방을 닫는다" 는 예측은 적중했다.

부지표는 결이 다르다 — PR-AUC(0.6531)·max-F1(66.87%) 은 λ=200 이 전 실험 최고.
λ 최적점이 지표마다 다르다는 007 관찰의 재확인이다. §7 계약대로 P@R0.7 로 판정한다.

## 판정: 둘 다 discard

λ 사다리 종결: 1 → 13.56 / 10 → 28.09 / 50 → 29.54 / **100 → 32.96(최적)** /
200 → 30.07 / 500 → 30.34(오염). 현 기준선은 run_007c(λ=100, 상한 300) 유지.
남은 후보는 λ 이외의 축 — `min_sum_hessian` 조합, `num_leaves`.
