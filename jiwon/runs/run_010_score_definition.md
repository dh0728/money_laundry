# run_010 — 세탁점수 정의 비교

상태: 완료 — 현행 `1-P(NORMAL)` 유지, 대안 discard
기준선: run_007c 의 현행 점수 `1-P(NORMAL)` (PR-AUC 0.6496 / P@R0.7 32.96%)
단일 변인: 세탁점수 정의. 모델은 run_007c 저장본으로 고정, 학습 재실행 없음
피처: features_v1 (모델 고정이므로 동일)
비교: (a) `1-P(NORMAL)` = 세탁 9클래스 확률 합 (현행)
      (b) `max_k p_k` = 세탁 9클래스 중 최댓값
      (c) argmax 이진화 = 세탁 클래스로 분류되면 알람 (참고용 단일 운영점)
가설: (a) ≥ (b). 합은 패턴들에 분산된 증거를 모으고, 특히 NONPAT 은 특정 패턴에
확률이 몰리지 않아 max 가 불리하다. 차이는 P@R0.7 기준 2%p 미만으로 작을 것.
(c) 는 D-2 에서 역산한 대로 precision ~99.2% / recall ~38.2% 단일점 — recall 0.7
계약을 이행할 수 없음을 확인하는 참고 지표.
§6 미결 "트랙 간 공통 이진화 규칙" 의 근거 실험.

## 결과 — 방향 적중, 격차 예측은 크게 빗나감

| 지표 | (a) 합 `1-P(NORMAL)` | (b) max `max_k p_k` | (c) argmax 이진화 |
|---|---|---|---|
| PR-AUC | **0.6496** | 0.5627 | — (단일점) |
| max-F1 | **66.21%** | 56.40% | — |
| P@R0.5 (알람) | **95.22%** (544) | 61.59% (841) | — |
| P@R0.7 (알람) | **32.96%** (2,203) | 25.55% (2,842) | — |
| P@R0.9 (알람) | 1.95% (47,869) | 1.98% (47,051) | — |
| attempt@R0.7 | **96.8%** | 91.7% | — |
| 단일 운영점 | — | — | P 99.25% / R 38.2% (알람 399, attempt 73.9%) |

**정정:** "차이는 2%p 미만" 예측은 빗나갔다. P@R0.7 에서 7.4%p, P@R0.5 에서는
33.6%p 차이 — 합의 우위는 작지 않고 지배적이다. 세탁 행 순위 상관(spearman)이
0.947 로 높은데도 상위 구간 정밀도가 이만큼 갈리는 것은, 정확히 알람 큐 상단에서
두 정의가 다른 거래를 올린다는 뜻이다.

해석: 합은 패턴들에 분산된 세탁 증거를 모으고, max 는 "가장 유력한 단일 패턴"의
확신만 본다. NONPAT 처럼 확률이 9클래스에 얇게 퍼지는 세탁에서 max 가 체계적으로
불리하다 — 가설의 메커니즘 그대로, 크기만 예상보다 컸다.

(c) argmax 이진화는 D-2 역산과 정확히 일치(P 99.2%/R 38.2%). recall 을 0.38 위로
올릴 수단이 없어 recall 0.7 계약 이행 불가 — 운영 불능 확인.

## 판정

현행 `1-P(NORMAL)` 유지. §6 미결 "트랙 간 공통 이진화 규칙" 에는 이 결과를 근거로
합 방식을 제안한다 — 트랙 간 공통 규칙이므로 확정은 팀 합의 사항.
