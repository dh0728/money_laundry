기준선: run_008 (λ=100, `min_sum_hessian` 1e-3, 상한 1000, PR-AUC 0.6495 / P@R0.7 32.93%, iter 315)
단일 변인: `min_sum_hessian_in_leaf` 1e-3 → 0.1(011a) / 1.0(011b). λ=100·상한 1000 고정
피처: features_v1
가설: 이득 없이 손해만 있을 것. λ=100 이 이미 리프 값을 유계화하므로 H 하한이
막아줄 폭주가 남아 있지 않고, 남는 효과는 run_003 에서 본 부작용 — 소수 세탁
샘플 영역(H 작음)의 분할 금지 — 뿐이다. run_009 에서 추가 정규화(λ↑)가 손해임도
확인됐다. 예측: P@R0.7 이 011a 31~33%(소폭 하락), 011b 28~30%(뚜렷한 하락).
D-4 에서는 소표본 클래스(RANDOM·BIPARTITE)의 하락이 상대적으로 클 것.

기준선 주석: 사다리 전체의 현 기준선은 run_007c(상한 300)다. hessian 하한이
수렴 속도를 바꿀 수 있어 상한 1000 으로 고정하고, 상한 300↔1000 동률이 확인된
run_008 을 기준선으로 쓴다(run_009 와 동일한 논리).

**정정:** "이득 없이 손해만" 예측은 011b 에서 빗나갔다. λ=100 위의 H 하한 1.0 은
주지표 동률에 PR-AUC +0.016, max-F1 +2.6%p — 부지표 전면 개선이다. run_003(λ=0
에서 단독 1.0)이 참사였던 것과 대비하면: λ 가 폭주를 막은 상태에서는 H 하한이
노이즈 리프만 쳐내는 순기능으로 작동한다. **정규화 손잡이의 효과는 다른 손잡이
상태에 의존한다** — 단독 실험의 discard 를 조합에서 재검하는 근거 사례.

D-4 예측("RANDOM·BIPARTITE 하락 클 것")도 빗나갔다. 011b 의 OVR PR-AUC 는
run_008 대비 FAN-OUT +7.2, FAN-IN +7.5, STACK +6.0, CYCLE +4.1, BIPARTITE +3.3
으로 대부분 상승, 하락은 G-SCATTER -4.2, S-GATHER -1.8, RANDOM -0.9 뿐.
약체 클래스(FAN-OUT·FAN-IN·BIPARTITE) 신호가 λ 사다리 내내 정체하다 처음 움직였다.

011a(0.1)는 어중간 — 주지표 -1.0%p, 부지표 소폭 개선. 하한이 약해 노이즈 리프
정리가 덜 되고 분할 금지 부작용만 걸친 것으로 보인다.
