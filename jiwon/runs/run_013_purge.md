# run_013 — 개입: 경계 걸침 블록 purge

상태: 완료(discard — 표준 학습으로 미채택, 진단 가치는 큼)
기준선: run_011b (λ=100, H≥1.0, 리프 31, 상한 1000 — 전체 train 학습)
단일 변인: train 정제(개입). val(09-07) 이후로 이어지는 패턴 attempt 의 train 구간
거래(실측 535건, train 패턴 거래의 41%)를 학습 표본에서 제거. 피처 parquet 은
그대로 둔다 — 거래 자체는 일어난 것이므로 계좌 이력(피처)에는 남기고, 라벨된
학습 표본으로만 쓰지 않는다(López de Prado 의 purge 개념의 번역).
NONPAT 은 attempt 구조가 없어 purge 대상에서 제외.
피처: features_v1
가설: 걸침 블록의 성능 우위(탐지 +4.7%p, argmax 분류 +16.5%p)가 두 효과의 합인데,
purge 는 그중 "같은 수법을 train 라벨로 본 효과"만 제거한다. 예측:
(1) 걸침 블록 argmax 분류 정확도 39.3% → 25% 안팎으로 하락(포함 22.8% 수준으로 수렴).
(2) 걸침 블록 탐지율은 소폭만 하락(97.1 → 94~96%) — 탐지는 라벨 암기보다 계좌
이력 피처가 주도하므로.
(3) 완전 포함 블록 성능은 불변(원래 오염 없음) ± train 표본 41% 감소의 부작용.
(4) 전체 P@R0.7 은 소폭 하락(표본 감소 비용).
판정 기준: 포함 블록 성능이 유지되면 기존 run 간 비교는 신뢰 가능(공통 편향),
걸침 지표만 층화 보고로 관리. 포함 블록 성능까지 크게 변하면 분할 자체 재설계
(embargo)를 팀 안건으로 올린다.

## 결과 — 탐지와 분류가 정반대 판정

| 지표 | run_011b (전체 train) | run_013 (purge) |
|---|---|---|
| PR-AUC | 0.6652 | 0.6264 |
| max-F1 | 68.98% | 63.80% |
| P@R0.7 | 32.94% | 27.67% |
| P@패턴R0.9 (알람) | 79.74% (755) | 36.80% (1,815) |
| 탐지@R0.7 걸침 / 포함 | 97.1% / 92.4% | 95.2% / 89.5% |
| argmax 정답클래스 걸침 / 포함 | 39.3% / 22.8% | **6.4% / 12.7%** |

**핵심 판독 1 — 탐지의 걸침 우위는 정당하다.** purge 후에도 걸침이 포함을
5.7%p 앞선다(95.2 vs 89.5). 라벨을 한 건도 안 보고도 이어지는 수법을 더 잘
잡는다 = 우위의 원천은 계좌 이력 피처(인과적으로 정당한 정보)지 라벨 암기가
아니다. 탐지 계열 지표의 걸침 부풀림은 소폭(~5%p)이고 성질도 무해하다.

**핵심 판독 2 — 분류(패턴 ID)의 걸침 우위는 암기였다.** purge 하자 걸침 분류
정확도가 39.3 → 6.4% 로 붕괴, 포함(12.7%)보다도 낮아져 방향이 뒤집혔다.
011b 의 걸침 분류 39.3% 는 대부분 "train 에서 라벨로 본 그 수법"의 효과.
패턴 식별 능력의 정직한 수치는 포함 기준 ~22.8%(011b)다.

**핵심 판독 3 — 조각은 오염원이기 이전에 희소한 학습 데이터다.** purge 는 포함
블록 성능까지 깎았다(탐지 -2.9%p, 분류 -10.1%p, P@패턴R0.9 반토막). 제거한
535건은 train 패턴 표본의 41% — 신규 수법 일반화에도 쓰이던 정보다.

**정정:** 가설 (2)·(4) 적중, (1)은 방향만 맞고 크기 과소(25% 예상 → 6.4% 붕괴),
(3) "포함 불변" 은 빗나감 — 표본 감소 비용이 뚜렷했다.

## 판정: discard (진단 실험으로만 keep)

purged 학습을 표준으로 삼지 않는다 — train 조각은 시간 규칙(§7) 위반이 아니고
(모두 09-07 이전 실제 거래; 운영에서도 어제까지의 라벨로 학습한다), 제거 비용이
전 지표에서 실재한다. 대신 보고 규율을 확정한다:
- 탐지 계열(P@R, P@패턴R, C 표): aggregate 신뢰 가능. 걸침 효과는 정당한 이력
  신호이며 ±5%p 수준.
- 패턴 분류 능력 주장(D 표): 포함 블록 기준으로만 말한다. aggregate 는 ~1.7배
  부풀려져 있다.
- keep/discard 판정 시 층화 열(탐지@R0.7포함)을 교차 확인한다.
