# run_014 — 9클래스 vs 10클래스 (캐스케이드 1단 검증)

상태: 완료 — 동률 확인, 1단 후보로 유효 (keep)
기준선: run_011b (10클래스)의 패턴 점수 `Σp_패턴8` — P@패턴R0.9 79.74% (알람 755)
단일 변인: 라벨 구성. NORMAL+NONPAT → "패턴아님" 합병(9클래스). 파라미터는 011b
승계(λ=100, H≥1.0, 리프 31, 상한 1000, ES 30, seed 42), 피처·분할 동결
피처: features_v1
채점: 양쪽 모두 패턴 점수(9클래스는 `1-p_패턴아님`)로 패턴 8클래스를 양성 삼아
PR-AUC·P@패턴R0.9 를 비교. 참고로 전체 세탁(ybin) 기준 P@R0.7, 클래스별 OVR,
층화 탐지도 기록
가설: 동률(±2%p). NONPAT 을 별도 클래스로 분리하는 것이 패턴 표현에 주는 보조
신호는 미미할 것 — NONPAT 자체 신호가 D-4 기준 ~3 으로 거의 없기 때문. 합병으로
소폭 개선 여지(NONPAT-정상 구분에 쓰던 용량 회수)와 소폭 악화 여지(패턴 vs
"세탁스럽지만 패턴아님" 경계 정보 소실)가 상쇄될 것으로 본다.
판정 기준: 9클래스가 P@패턴R0.9 에서 동률 이상이면 캐스케이드 1단으로 채택 가능.
-2%p 넘게 밀리면 1단도 10클래스 유지(캐스케이드는 2단 실험 결과에 따라).

## 결과 — 가설 적중: 동률

채점 주의: 이 실험의 비교 점수는 **패턴 점수**(9클래스 `1-p_패턴아님`, 10클래스
`Σp_패턴8`)다. B 표의 P@패턴R0.9(세탁점수 `1-P(NORMAL)` 기준)와 정의가 달라
수치가 다르다.

| 지표 | run_014 (9클래스) | run_011b (10클래스 Σp패턴) |
|---|---|---|
| 패턴 PR-AUC | **0.9580** | 0.9514 |
| P@패턴R0.9 (알람) | 92.82% (641) | **93.09%** (637) |
| 패턴탐지@patR0.9 걸침/포함 | 94.0 / 83.1% | 93.1 / **84.8%** |
| argmax 패턴 정답 | **35.3%** | 33.3% |
| OVR: G-SCATTER / S-GATHER / FAN-IN | **70.4 / 51.0 / 45.0** | 53.6 / 45.9 / 40.5 |
| OVR: CYCLE / BIPARTITE | 32.8 / 13.7 | **35.5 / 15.0** |
| (참고) 전체세탁 P@R0.7 | 21.47% | **26.20%** |

주지표(P@패턴R0.9) 차이 0.27%p — 사전 등록한 동률 범위(±2%p) 안. NONPAT 분리
라벨의 보조 신호는 역시 미미했고, 오히려 합병으로 회수한 용량이 일부 클래스
신호를 올렸다(G-SCATTER +16.8, FAN-IN +4.5). CYCLE·BIPARTITE 는 소폭 하락 —
NONPAT 경계 정보가 약간의 대비 역할을 하던 클래스로 보인다.

## 부수 발견 — 패턴 큐 점수는 Σp_패턴이 맞다

**재학습 없이** run_011b 의 패턴 큐 점수를 세탁점수(`1-P(NORMAL)`)에서
`Σp_패턴8` 로 바꾸기만 해도 P@패턴R0.9 가 **79.7% → 93.1%** (알람 755 → 637)로
뛴다. 세탁점수는 NONPAT 확률까지 실어 패턴 큐 순위를 흐리기 때문. 두 큐 서빙
설계에서 패턴 큐는 Σp_패턴, 배경 큐는 p_NONPAT — 점수를 분리하는 것이 옳다.
(B 표의 P@패턴R0.9 열 정의를 Σp_패턴 기준으로 바꿀지는 §7 지표 정의 문제 —
바꾸면 과거 run 소급 재계산 필요.)

## 판정: keep — 캐스케이드 1단으로 9클래스 유효

동률 + 분류 진단 소폭 우위. 단 채택 확정은 2단 실험(전용 이진 vs `p_NONPAT`,
run_015 예정)이 캐스케이드의 존재 이득을 보여줄 때. 2단이 지면 "10클래스 평면
+ 두 점수 서빙(Σp_패턴 / p_NONPAT)"으로 충분하다.
