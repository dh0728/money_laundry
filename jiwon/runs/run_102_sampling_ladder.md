# run_102~105 — NORMAL 다운샘플링 방법 사다리

- 상태: 완료 — 102 keep(분산 자), 103·105 완료(동치 확인), 104 discard. **RUS 유지 확정**
- 기준선: run_101 (RUS 100:1, 시드 42 — PR-AUC 0.6798, P@R0.7 33.88%)
- 단일 변인: **train NORMAL 표본 추출 방법** (비율 100:1·모델 011b 승계·평가 계약 전부 고정)
- 피처: features_v1 61개 (Large 이식판)
- 배경: 팀 서베이(클러스터 기반 언더샘플링, CSSMC 논문) 검토 — 전부 실측 비교로 판정.
  KNN 계열·K-means*/K-medoids* 원형은 규모상 실행 불가로 사전 제외
  (근거: 2026-08-27 논의 — k=표본수 군집은 ~10^18 FLOPs, KNN은 O(N²)).

| run | 방법 | 요지 |
|---|---|---|
| 102 | RUS 시드 42→43 | **분산 자**: 방법 간 차이가 노이즈인지 판정할 척도 |
| 103 | CSSMC k=15, 비례 할당 | MiniBatchKMeans(표준화 그래프 52) + 군집 비례 층화 + 후보 3개 중 KLD 최소 선택 |
| 104 | CSSMC k=15, 균등 할당 | 군집당 동수 추출(소수 군집 과대표집 — 논문 "골고루" 해석). 유일하게 RUS 와 분포가 실질적으로 달라지는 변형 |
| 105 | K-prototypes 근사 k=15, 비례 | 군집 공간에 범주형 one-hot(fmt 7 + entity 6×2) 추가 — kmodes 미설치로 one-hot 근사임을 명시 |

- 군집 적합은 train NORMAL 5% 부표본(±500만 행)으로, 배정은 전량 스트리밍.
- KLD: 표준화 피처별 50-bin 히스토그램, 모집단(train NORMAL 전량) 대비 52피처 합.
- CLARA-medoids 근사는 보류 — 103~105 에서 클러스터 계열이 신호를 보이면 추가.

## 가설 (실행 전)

1. 102(시드) 차이 = 판정 노이즈 규모. P@R0.7 기준 ±수십 bp 예상.
2. 103(비례 CSSMC)은 run_101 과 노이즈 범위 내 동률 — 표본 970만이면 비례 층화는
   RUS 와 수렴한다(2026-08-27 논의의 핵심 주장, 여기서 실측 검증).
3. 104(균등 할당)만 유의미하게 다를 수 있음 — 방향은 불확실: 희귀 NORMAL 과대표집이
   경계 학습을 돕거나(정밀도↑), 다수 NORMAL 과소표집으로 오경보가 늘거나(정밀도↓).
4. 105 는 103 과 유사할 것 — 범주형이 군집을 크게 바꾸지 않는다고 예상.

판정: P@R0.7 주지표, 개선이 102의 노이즈 폭을 넘고 복잡도 비용을 정당화할 때만 채택.

## 결과 (val 전량, run_101 포함 비교)

| run | 방법 | train행 | PR-AUC | P@R0.7 | P@패턴R0.9 | P@포함패턴R0.9 |
|---|---|---|---|---|---|---|
| 101 | RUS 시드42 (기준선) | 9,816,874 | 0.6798 | 33.88% | 95.17% | 93.58% |
| 102 | RUS 시드43 | 9,810,915 | 0.6798 | 33.50% | 95.44% | 93.88% |
| 103 | CSSMC k15 비례 | 9,815,542 | 0.6795 | 33.67% | 95.25% | 93.41% |
| 104 | CSSMC k15 균등 | 9,395,950 | **0.6660** | **31.59%** | 92.09% | 92.01% |
| 105 | K-proto 근사 비례 | 9,815,542 | =103 | =103 | =103 | =103 |

- **노이즈 자(101 vs 102)**: P@R0.7 ±0.38pp, PR-AUC ±0.0003 — 방법 판정의 최소 유의폭.
- **가설 2 확증(강한 형태)**: 비례 할당 CSSMC 는 RUS 와 통계적 동치를 넘어
  **알고리즘적 동치** — 선택 확률이 전 군집 동일해 군집 배정이 추출에 무영향.
  군집이 쓰이는 유일한 지점(KLD 후보 선택)도 후보 3개가 KLD 0.00024 로 동률
  (970만 표본이면 어떤 무작위 표본도 사실상 완벽 대표). 103 은 사실상 "시드 52 RUS".
- **105 = 103 완전 동일**: 표본 파일 일치(np.array_equal). 군집 공간을 바꿔도(one-hot
  추가) 비례 할당에선 추출이 동일 — 위 동치의 직접 증거.
- **104(균등 할당)만 실질적으로 다른 분포**였고, 결과는 **악화**: P@R0.7 −2.3pp
  (노이즈의 ~6배), PR-AUC −0.014, P@패턴R0.9 −3.1pp. 소군집(0.2M) 과대표집 +
  대군집 과소표집 = 모집단 왜곡 비용. 훈련행도 목표 미달(96.7% — 소군집 전량 소진).
  P@R0.9 만 +0.23pp 로 미미하게 우세(채택 근거 안 됨).
