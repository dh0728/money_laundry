## 혼동 구조 분석 (val 패턴 29,814행)

- 패턴 argmax 정확 42.4%. **탐지 유출(→패턴아님)은 2.7%뿐** — 실패의 55%는
  **패턴 간 혼동**. 즉 "패턴임"은 아는데 "어느 패턴인지"를 못 가른다.
- 혼동의 두 축:
  1. **STACK 블랙홀**: BIPARTITE→STACK 47.7%(1,203), RANDOM→STACK 36.0%,
     CYCLE→STACK 33.9% — 중계형 4클래스의 국소 간선이 서로 동일(bp_stack 분석의
     앨리어싱이 전 중계형으로 일반화).
  2. **복합↔단순 대칭**: FAN-OUT↔S-GATHER(739), FAN-IN↔G-SCATTER(629) —
     G-S/S-G 의 gather·scatter 국면 거래는 FAN-IN/OUT 과 원리적으로 같은 모양.
- 클래스별 argmax 재현율: S-G 54.1 / STACK 53.7 / G-S 52.7 / FO 44.6 / FI 40.0 /
  CYCLE 24.4 / BP 14.2 / **RANDOM 10.1**.
- NONPAT(원라벨) 행은 99.7%가 패턴아님으로 — 병합 의도대로 동작.
- **시사점**: 거래 단위 argmax 의 원리적 한계가 지배 요인. 다음 개선의 본선은
  피처 추가가 아니라 **블록 재구성 후 블록 단위 패턴 판정**(이월 미결 레이어).
