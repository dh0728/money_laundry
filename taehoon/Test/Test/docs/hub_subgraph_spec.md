- 근거 실험: HI-small v2 실측 (G31 기준). 설계안 §10의 위임 항목에 대한 모델팀 응답

  - 관여 세탁 라벨 점유 **12.23%** (설계안 10.8~25.6%)
  - 2-hop 탐색 비용의 **98.8%** (설계안 97.7~99.2%)
- DB 부착점: 계좌 등록부 `is_hub` 플래그 컬럼 (설계안 D-2) — 최초 등록 시 차수 임계값(예: 1,000) 또는 시드 리스트로 설정

## 2. 처리안 선택: **C (허브 플래그 특징 + 샘플링 상한)** — 상한 K=64

| 처리안 | 2-hop 비용 p95 / p99 / mean | 판정 |
|---|---|---|
| 무상한 (현状) | 4,614,575 / 7,639,326 / 598,492 | 페이로드 예산 초과 |
| A 완전 제거 | - | **기각**: 세탁 12.2% 판정 포기 + H-2 발견(아래) |
| B 샘플링 상한 (K=64) | 19,037 / 30,948 / 6,918 | 유효하나 허브 정보 자체를 버림 |
| **C 플래그+상한 (K=64)** | 19,037 / 30,948 / 6,918 (B와 동일 비용) | **채택**: 비용 동일, 허브 여부를 피처로 보존 |
| D 메시지 전달만 차단 | 18,715 / 30,655 / 6,438 | 비교 실험 항목으로 보류 |

- 채택 근거: ① B와 비용이 같으면서 허브 신호(플래그·방향·통화)를 모델 입력으로 보존 ② 허브 정체가 추정이 아닌 차수 절벽으로 확인된 사실이라 피처화가 정당 ③ H-2 발견(아래 §4)으로 허브 관여 탐지가 실제 성능 구멍임이 확인됨
- 비교 실험 항목: D (허브 경유 메시지 차단) — 비용 미세 우위, 2-hop 관계 신호 손실과 트레이드오프. GNN 서빙 도입 시 A/B/C/D 회귀 비교

## 3. 서브그래프 추출 명세 (백엔드 조회기 구현용)

| 항목 | 값 |
|---|---|
| hop 수 | 2 (1-hop: 직접 상대, 2-hop: 상대의 상대) |
| 방향 | 무방향 확장, 방향은 엣지 피처로 보존 |
| 허브 팬아웃 상한 | **K=64** (허브의 이웃 조회는 최근 거래 64건만, 시각 내림차순) |
| 비허브 팬아웃 상한 | 512 (가드 값 — HI-small 비허브 최대 차수 394라 실제로는 미적용, 폭증 대비 상한 존재 보장용) |
| 허브 1-hop 포함 | 포함 — 허브 노드 자체는 서브그래프에 남기고 `is_hub` 노드 피처 부여 (펼침만 상한) |
| 페이로드 예산 (엣지 수/타깃) | p50 ≈ 5,200 / p95 ≈ 19,000 / p99 ≈ 31,000 / max ≈ 170,000 (비허브 체인 한계) |
| 시간 규율 | 이웃 조회는 타깃 거래 시각 이전(과거)만 — 롤링 누수 방지. 시간창 제한은 사용하지 않음(설계안 §10 제약 ②) |
| 판정 커버리지 | 허브 관여 거래(전체의 8.92%)도 1단계 스코어링 대상에 포함 (제약 ① 준수) |

## 4. UI 허브 가드 (설계안 확정 사항 재확인)

- 조사 화면 관계 그래프에서 허브 노드는 **펼치지 않고 요약 표시** (연결 건수·기간 집계만). 펼치기 요청 시에도 K=64 상한 적용

## 5. H-2 주요 발견: 1단계 모델의 허브 탐지 구멍

- G31(HI-small 최종 모델)의 test 분리 평가:
  - 허브 관여 (97,496건, 세탁 129건): **AP 0.0017 / F1 0.0 — 세탁 129건 전부 누락**
  - 비허브 (918,386건, 세탁 1,669건): AP 0.8158 / F1 0.7801
- 해석: 허브 거래의 그래프 피처(사이클·자금통과 등)가 거대 이웃에 희석되어 신호 소실. 세탁의 12.2%가 허브 경유라 실질 탐지 구멍
- 후속 과제(모델팀): **허브 피처 보강 재학습 실험(G40 후보)** — is_hub_involved, 허브 방향(입금/출금), 허브 통화 매칭, 허브 거래 금액 분位 등 피처 추가 후 허브 관여 AP 회복 측정. C안의 "플래그 특징"이 이미 이 방향을 포함
- 백엔드 영향: 없음 — 서브그래프 명세(§3)는 피처 보강과 무관하게 동일

## 6. 미결·조정 조건

- K=64는 HI-small 기준 합리값이며, EC2↔GPU 페이로드·지연 실측(설계안 §11 통신 테스트) 후 32/128로 조정 가능 — 조정은 서브그래프 조회기 파라미터 변경만으로 가능(회귀 시험: 페이로드 p99 재측정)
- Medium/Large 적용 시 허브 ID·차수는 스케일에 따라 재산정 필요 (탐지 로직은 동일: 차수 절벽 + is_hub 플래그)
